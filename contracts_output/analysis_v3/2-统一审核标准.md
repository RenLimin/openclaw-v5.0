# 统一审核标准

> 依据《中华人民共和国民法典》合同编、最高人民法院《合同编通则司法解释》及相关行业规范，制定本合同审核标准。
>
> **适用范围**：技术服务合同  
> **审核标准数**：35 项  
> **制定时间**：2026-09-02 19:35

---

## 审核标准总览

| 类别 | 标准数 | 覆盖要点 |
|------|--------|----------|
| 主体信息 | 5 | 双方名称完整且与营业执照一致；地址完整（省市区门牌）；联系方式明确；统一社会信用代码 |
| 合同标的 | 2 | 服务内容清晰可衡量；交付物清单完整 |
| 价款与报酬 | 4 | 金额大小写一致；含税/不含税明确；付款节点清晰；发票条款 |
| 履行期限 | 1 | 起止日期明确一致 |
| 履行地点 | 1 | 地点明确 |
| 履行方式 | 1 | 方式明确 |
| 验收标准 | 3 | 标准可量化；流程明确；不合格处理 |
| 违约责任 | 3 | 违约金合理；双方责任对等；救济方式明确 |
| 争议解决 | 2 | 方式明确；管辖有效 |
| 知识产权 | 2 | 成果归属明确；许可范围明确 |
| 保密条款 | 2 | 范围明确；期限合理 |

| 格式条款 | 2 | 无不合理加重责任；提示说明义务 |
| 其他 | 3 | 项目联系人明确；生效条件明确；合同份数 |

**1. 双方名称完整且与营业执照一致**（§470，🔴 高风险）
