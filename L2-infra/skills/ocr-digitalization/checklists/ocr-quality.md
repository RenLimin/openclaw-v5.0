# OCR 质量检查清单

> 用于验证 OCR 数字化结果的质量，确保后续流程（审核、解析、归档）的数据可靠性。
> 检查方式：人工抽查 + 自动化校验结合。

---

## 1. 文本准确率

**目标**：OCR 输出的文字与原文一致，关键字段无错误。

| # | 检查项 | 检查方法 | 合格标准 | 结果 |
|---|---|---|---|---|
| 1.1 | 首部标题正确 | 对比原文标题与 OCR 输出首段 | 完全一致（允许 1 个标点差异） | ☐ |
| 1.2 | 甲乙方名称正确 | 找到"甲方""乙方"所在行，对比公司全称 | 完全一致（关键字不能有错字） | ☐ |
| 1.3 | 合同金额正确 | 找到金额条款，对比大小写金额 | 数字和大写金额均准确 | ☐ |
| 1.4 | 日期格式正确 | 抽查 3 处日期（签订日、生效日、到期日） | 年月日数字正确 | ☐ |
| 1.5 | 关键条款可读 | 抽查违约责任、争议解决等重要条款 | 无整段缺失、无乱码 | ☐ |

**抽查要求**：至少抽查 3 处不同位置的文本，与 PDF 原图对比。

---

## 2. 印章检出率

**目标**：合同中的红色公章/合同章全部被检测到。

| # | 检查项 | 检查方法 | 合格标准 | 结果 |
|---|---|---|---|---|
| 2.1 | 甲方印章检出 | 翻到签署页，对比实际印章与检测结果 | 甲方公章被检出 | ☐ |
| 2.2 | 乙方印章检出 | 同上 | 乙方公章被检出 | ☐ |
| 2.3 | 印章数量一致 | 人工清点 PDF 中印章数 vs 检测数 | 数量差 ≤ 1（骑缝章可不计） | ☐ |
| 2.4 | 印章截图完整 | 打开签名目录下的 seal 截图 | 印章完整在框内，无截断 | ☐ |

**常见漏检情况**：黑色印章、骑缝章、印章被文字大面积覆盖。

---

## 3. 签名截图范围

**目标**：签名截图包含完整的签署要素，便于后续人工复核。

**每个签名截图应包含：**

| # | 检查项 | 说明 | 结果 |
|---|---|---|---|
| 3.1 | 签字标签 | "甲方签字" / "乙方签字" / "法定代表人" 等标签文字 | ☐ |
| 3.2 | 手写签名 | 实际的手写签字区域 | ☐ |
| 3.3 | 签署日期 | 签字下方或旁边的日期栏 | ☐ |
| 3.4 | 上下留白 | 截图边缘与内容有适当留白，不紧贴 | ☐ |

**检查方法**：打开 `signatures/` 目录下的 sig 开头图片，目视确认。

---

## 4. 坐标一致性

**目标**：截图的 bbox 坐标与 PDF 实际位置对应，便于上层引用。

| # | 检查项 | 检查方法 | 合格标准 | 结果 |
|---|---|---|---|---|
| 4.1 | bbox 与截图一致 | 取一个 signature 的 bbox，在渲染图上画框对比 | 框住区域与截图内容一致 | ☐ |
| 4.2 | OCR 行坐标对齐 | 取一行 OCR 结果的 bbox，在原图上定位 | 位置偏差 < 5 像素 | ☐ |
| 4.3 | 页码对应正确 | 签名的 page 字段与实际所在页一致 | 完全对应 | ☐ |

**验证方法**：用 `pdf_to_images` 渲染同 DPI 图片，用 PIL 根据 bbox 裁剪后与截图对比。

---

## 5. 页码完整性

**目标**：OCR 处理了 PDF 的所有页面，没有丢页。

| # | 检查项 | 检查方法 | 合格标准 | 结果 |
|---|---|---|---|---|
| 5.1 | 页数一致 | PDF 总页数 vs OCR 结果 meta.pages | 完全相等 | ☐ |
| 5.2 | 首页有内容 | OCR 输出第 1 页非空 | 有文字行 | ☐ |
| 5.3 | 末页有内容 | OCR 输出最后一页非空 | 有文字行（空白页除外） | ☐ |
| 5.4 | 页码标注正确 | Markdown 中页分隔标注与实际页数对应 | 连续且无重复 | ☐ |

**快速校验命令：**

```bash
# 数 PDF 页数
python -c "import pymupdf; print(pymupdf.open('合同.pdf').page_count)"

# 数 OCR 输出页数
grep -c "第.*页" 合同.md  # 或查看 ocr_result.json 中 meta.pages
```

## 6. 综合评分

| 类别 | 权重 | 得分（0-100） |
|---|---|---|
| 文本准确率 | 40% | |
| 印章检出率 | 20% | |
| 签名截图范围 | 15% | |
| 坐标一致性 | 15% | |
| 页码完整性 | 10% | |
| **综合** | 100% | |

**判定标准**：
- ✅ **合格**：综合 ≥ 90 分，且文本准确率 ≥ 90%
- ⚠️ **有条件合格**：综合 70-89 分，需要人工复核关键字段
- ❌ **不合格**：综合 < 70 分，或存在整页丢失、金额错误等严重问题
