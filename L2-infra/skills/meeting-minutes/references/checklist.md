# 交付前自检清单

## 内容
- [ ] 抬头表完整：时间、形式、主题、参会（按公司分列）、记录人
- [ ] 职务/身份未杜撰（不明则不写或标注待确认）
- [ ] 无寒暄、等待、重复、口误、语气词、跑题
- [ ] 口语指代已还原；同名异义已区分
- [ ] ASR 错误的人名/专名/数字已校订或标注
- [ ] 散落信息已重组为完整机制 / 因果链
- [ ] 有争议处如实写"争论中/待定"，未写成定论
- [ ] 会后确认材料已并入，且与会上口头信息冲突时**以会后确认为准**

## 术语与篇幅
- [ ] 全文术语统一；用户指定用词已替换
- [ ] `grep -c "废弃词" file` = 0
- [ ] 篇幅符合用户档位（精简/标准）；对比与排期已表格化

## 待办与结论
- [ ] 每条待办有负责人 + 时间 + 状态
- [ ] 根因是可验证的因果链
- [ ] 结论 3–5 条，覆盖根因/推进层次/风险状态

## 交付
- [ ] 文件为合法 UTF-8（必要时带 BOM）
- [ ] 已提供用户可达副本（~/Downloads 或 Desktop），不只留沙箱路径
- [ ] 需要时提供 HTML/PDF，且各格式内容一致
- [ ] 对外发送已经用户确认
