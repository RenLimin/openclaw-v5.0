## 1. 总体计划

### 1.1 阶段划分

| 阶段 | 名称 | 主要目标 | 预计工时 | 交付物 |
|---|---|---|---|---|
| Phase 1 | 核心服务化 MVP | 可独立部署的知识库服务，支持常见格式文档导入和查询 | 80h | 可用服务 + 核心文档 |
| Phase 2 | 生产增强 | 生产级知识库，质量体系完善，性能优化 | 120h | 生产可用版本 + 完整文档 |
| Phase 3 | 企业级智能化 | 企业级部署，自动优化，多实例联邦 | 150h | 企业版 + 高级特性 |

### 1.2 前置条件

- Python 3.11+ 开发环境
- SQLite 数据库（默认）/ PostgreSQL（可选）
- 本地 Embedding 模型（默认）或 API Key
- Git 版本控制

## 6. 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|
| 文档解析质量不达预期 | 中 | 高 | 优先实现 80% 常见格式，特殊格式走人工处理；预留调优时间 |
| 本地 Embedding 效果差 | 中 | 中 | 支持多种 Embedding 后端，可切换；提供效果对比工具 |
| 检索准确率不达标 | 中 | 高 | 多路召回 + 重排序逐步提升；建立测试集量化评估；快速迭代 |
| 性能不达预期 | 低 | 中 | 提前做性能测试；预留优化时间；可升级向量数据库 |
| 安全防护绕过 | 低 | 高 | 纵深防御，多层防护；定期渗透测试；快速响应机制 |
| 工程量超预期 | 中 | 中 | MVP 优先，Phase 1 只做核心；非核心功能延后到后续版本 |
