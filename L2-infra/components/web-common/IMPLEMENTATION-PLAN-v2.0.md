## 10. 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|
| Playwright 在 macOS 下不稳定 | 中 | 高 | 备选方案：直接用 Chrome headless + Pillow 截图对比 |
| 动态内容导致视觉测试误报率高 | 高 | 中 | 加强 Mask 机制，提高默认阈值 |
| 71 页面走查发现问题远超预期 | 中 | 中 | 先修复 P0，P1/P2 分批处理 |
| 组件库规范化引入回归 | 中 | 高 | 每个组件修改后跑视觉回归测试 |
| 暗色主题覆盖不全 | 中 | 中 | 走查时重点检查，逐个修复 |
