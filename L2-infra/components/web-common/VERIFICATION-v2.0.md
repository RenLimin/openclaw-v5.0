## 1. 验证策略

采用 **三层验证** 确保 v2.0 升级质量：

1. **单元验证**：Design Tokens / 组件 / 测试框架各自独立验证
2. **集成验证**：与现有 L3/L4 组件集成验证，确认不破坏现有页面
3. **全量验证**：71 个页面逐一视觉回归验证

## 5. 黄金基准

### 5.1 基准图管理规则

- 基准图存储在 `tests/visual/golden/<component>/<page>.png`
- 基准图必须经过人工确认后才能合入
- 每次设计变更需同步更新基准图
- 基准图纳入 Git 版本控制

### 5.2 基准图更新流程

```
提交 UI 变更 PR
  → CI 运行视觉回归测试
  → 有差异 → 生成 diff 报告
  → 开发者确认是预期变更 → 更新基准图
  → Reviewer 确认 → 合入
```
