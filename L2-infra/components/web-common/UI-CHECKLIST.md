# UI-CHECKLIST — UI 验收检查清单

> web-common v2.0 · 用于 UI 走查和验收，按类别组织，每项都必须检查

## 1. 布局对齐类（L1-L6）

| # | 检查项 | 检查方法 | 结果 | 备注 |
|---|---|---|---|---|
| L1 | **栅格对齐**：所有内容块对齐到统一间距网格，不随意调整间距 | 像素测量 + 视觉走查 | ⬜️ | |
| L2 | **左右边距一致**：同类型页面左右留白对称一致，不随意变化 | 像素测量 | ⬜️ | |
| L3 | **卡片间距统一**：同级别卡片间距使用相同 Token，不硬编码 | 代码审查 + 视觉走查 | ⬜️ | |
| L4 | **响应式断点**：各断点下布局不溢出、不错落、不重叠 | 调整窗口大小多尺寸检查 | ⬜️ | |
| L5 | **内容不溢出**：文字不超出容器，表格不溢出视口，滚动正常 | 不同内容长度测试 | ⬜️ | |
| L6 | **空状态布局**：空状态内容垂直居中，有合理留白，不顶边 | 空数据场景测试 | ⬜️ | |

## 验收流程

1. 开发完成，功能自测通过
2. 生成新截图，运行视觉回归测试，确认无意外差异
3. 按本 Checklist 逐项检查，记录结果
4. 修复发现的问题，重新检查
5. 更新黄金基准图（如果变更符合预期）
6. 交付

## 使用技巧

- 首次走查一个新项目，可以复制这个清单到走查报告，逐项勾选
- P0 问题必须修复才能交付，P1 尽量修复，P2 可以后续迭代
- 严重程度分级：
  - **P0**：影响使用（内容溢出/布局错乱/文字看不见）
  - **P1**：明显影响美观（间距不对/对齐错/颜色不对）
  - **P2**：细微瑕疵，可以接受
