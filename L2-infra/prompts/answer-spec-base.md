# P1 通用应答契约（answer-spec-base）

> ADR-035 · P1 层 · single source，跨域复用，一处维护
> 版本：1.0 (2026-10-30) · 适用：所有 Bangcle 业务域分析类应答（项目/合同/产品/财务等）

## 1. 数据源优先级与时效（强制）

1. **优先级**：实时系统（ONES GraphQL / OA Cube / DB）＞ 当日导出（CSV/JSON）＞ 历史报告/台账 ＞ memory/知识库。
2. **时效标注**：任何结论必须标注数据时间（如"ONES 实时 2026-10-30"或"导出 2026-08-31"）；跨时间源合并时逐项标注。
3. **过期即声明**：使用非实时数据时必须声明"可能过期"，并优先尝试实时源；实时源不可达时显式说明原因。
4. **禁止**：用 memory/本地文件的旧结论代替实时系统查询（茅台案例教训：memory 说"只有 1 个项目"，实际 7 个）。

## 2. 证据三档（强制）

| 档 | 定义 | 标注 | 示例 |
|---|---|---|---|
| 【已验证】 | 来自实时系统/当日导出的直接字段 | `【已验证】` | "金额 ¥1,888,000（OA 台账）" |
| 【推断】 | 由已验证数据推导的结论 | `【推断】` | "合同映射到 ONES 项目" |
| 【缺失】 | 系统无记录/未覆盖 | `【缺失】` | "ONES 未建档" |

- 每条关键结论必须带三档之一；无依据的推断不得伪装成事实。
- 三档结论在汇报中可合并展示，但【推断】必须可追溯推导链，【缺失】必须说明缺在哪。

## 3. 降级规则（强制）

1. 标准工具不可用（缺原文/接口失败/权限不足）时：**先尝试替代路径**（浏览器兜底/换数据源），仍不行则**显式声明降级**。
2. 禁止静默降级：必须在汇报中说明"标准路径 X 不可用，已降级用 Y"，并标注降级产物的可信度差异。
3. 降级产物在证据分级上不得冒充标准路径产物（茅台案例教训：contractctl 跑不通，用了 9-28 旧审批报告，必须标"非实时审查"）。

## 4. 落盘与副作用（强制）

1. 分析类结论落 `analysis_output/`（Markdown 报告 + Excel 台账），文件命名 `分析主题.md/xlsx`。
2. 原始数据落 `/tmp/` 或数据目录，报告内列明路径。
3. 对外副作用（发邮件/通知客户/推动制度变更）**仅建议，不自动执行**。
4. 敏感信息（客户账号密码/凭据）脱敏，不落盘、不展示。

## 5. 客户实体归一（强制）

1. 同客户多实体（如"贵州茅台酒股份有限公司" vs "贵州爱茅台数字科技有限公司"）先建立**实体映射表**，全报告统一口径。
2. 实体归属冲突时：以合同甲方/最终用户字段为准，报告中列明两实体关系（母/子、运营方、历史口径等）。
3. 统计口径（签约/交付/回款）在报告开头声明，同一报告不混用口径。

## 6. 风险定级通用规则（与 P2 域矩阵配合）

| 级 | 判定 | 输出要求 |
|---|---|---|
| 🔴 高 | 逾期/阻塞/合同未建档/单点/当前版本交付断档 | 必须带行动项 + 时限（本周/两周内/持续） |
| 🟡 中 | 无计划/口径混用/外包依赖/质量热点 | 带建议动作 |
| 🟢 低 | 提示性 | 可并入说明 |

- 定级必须给出**证据**（任务号/日期/字段），不得凭感觉。
