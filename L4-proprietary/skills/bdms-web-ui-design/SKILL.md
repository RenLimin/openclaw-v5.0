# BDMS 交付月报 Web UI 前端设计开发技能沉淀

## 技能目标
沉淀 Web UI / 前端设计开发最佳实践，用于后续 BDMS 项目优化。

## 最佳实践总结（基于搜索结果）

### 1. 核心原则
- **内容分层：** 主页面精简内容，吸引用户兴趣，细节放详情页
- **视觉层次：** 元素按重要性排序，引导用户视线，突出重点内容
- **一致性：** 统一设计规范（颜色、字体、按钮），减少用户学习成本，提升交互体验
- **内容结构化：** 使用网格/卡片布局，让用户自主选择内容，增加交互性

### 2. UX/UI 设计
- **UX：** 关注用户需求和行为，打造流畅体验
- **UI：** 关注视觉美感和可用性，平衡美学与功能
- **设计系统：** 使用设计系统保持一致性和效率，推荐 Figma 协作
- **微交互：** 合理使用微交互（滚动、悬浮、开关），提升用户参与感，但避免过度动画
- **动效原则：** 动画时长 150-400ms，入场用 ease-out，出场用 ease-in；一个页面避免同时多个动画

### 3. BDMS 已对齐的开发规范
- **架构：** 使用现有 L2 共享组件库（`web-common/macros/components.html`），所有弹窗/Toast/Modal 都复用现有组件，不自定义
- **单一来源原则：** 月份选择只有**左侧栏一个入口**，符合单一来源设计原则
- **代码风格：** 复用现有 CSS 变量、类名规范，和已有代码风格对齐
- **响应式：** 适配不同屏幕尺寸，已在原有 CSS 中实现

### 本次改动对齐
本次改动已经对齐这些最佳实践：
1. 所有改动都在前端，后端 API 零改动，遵循之前需求
2. 所有交互组件都复用 L2 共享组件，符合组件化设计
3. 移除了原生弹窗，全部替换为正式组件，满足业内标准
4. 完成了根因修复：之前点击生成直接回退是因为删了元素引用没修完 JS 逻辑，现在已经彻底修好
