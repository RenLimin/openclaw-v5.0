## 1. 开发目标

按设计文档交付可运行的 Bangcle 产品知识库，满足合同标的比对和产品知识问答核心需求。

## 2. Phase 拆分与工时估算

| Phase | 内容 | 预估工时 | 交付物 | 状态 |
|---|---|---|---|---|
| **Phase 0** | 基础设施对齐 | 1h | 目录结构 + requirements.txt + README.md + 空表 DDL | 待执行 |
| **Phase 1** | IO 模块开发 | 3h | 价格表导入 + 文档扫描 + 文件解析 + OCR 兜底 | 待执行 |

## 3. 依赖说明

- 所有依赖都是现有组件，不需要新增外部依赖
- L2 持久化组件提供 SQLite 基础封装
- L2 记忆检索提供 embedding 能力
- L2 OCR 提供扫描版文档抽取能力

## 4. 验收节点

- 每个 Phase 完成后自测，全部完成后提交整体 E2E 验收
- 按交付验收 7 步法执行：独立审计 → 契约对齐 → 全入口执行 → 黄金基准 → 幂等测试 → 调用点扫描 → 回归锁定
