# Bangcle产品专家培养方案

## 目标

培养具备以下能力的Bangcle产品/服务专家：
1. **精准的产品/服务介绍、解答**：能快速准确回答产品相关问题
2. **跨产品/服务的综合能力提供**：能针对客户需求整合多个产品
3. **综合解决方案的制定**：能输出完整的客户解决方案

## 能力框架

### 1. 基础认知层
- 产品体系掌握：熟悉8条产品线/37个分类/193款产品/385个SKU的完整体系
- 文档深度阅读：掌握1046份官方文档中的产品规格、技术参数、应用场景
- 知识关联记忆：通过知识库的混合搜索（关键词FTS+向量语义搜索）训练关联能力

### 2. 核心能力层

| 能力要求 | 训练方法 | 工具支撑 |
|---|---|---|
| **精准产品介绍解答** | 定期做产品信息抽问测试，要求1分钟内给出完整准确的产品介绍 | 使用  接口做关键词检索训练，对比结果修正认知 |
| **跨产品综合能力** | 按客户行业/场景做产品组合训练，要求覆盖该场景下所有相关产品 | 使用知识库做多产品关联检索训练 |
| **综合方案制定** | 针对典型客户需求，制定完整解决方案，包含产品组合、服务配套、报价参考 | 利用知识库的文档检索获取方案模板、技术参数做支撑 |

## 训练路径

### Phase 1：基础熟悉（2周）
1. 通读产品价格表，掌握产品线分类和基础产品信息
2. 每天做10次关键词搜索训练，逐步记住核心产品的核心信息
3. 整理每个产品线的思维导图，梳理产品关系

**验收**：能说出每个产品线包含哪些产品，准确率80%以上

### Phase 2：精准训练（3周）
1. 针对每个产品，能独立输出：
   - 产品定位与核心价值
   - 主要功能与技术参数
   - 适用场景与客户群体
   - 常见问题解答
2. 每周做一次闭卷测试，对比知识库结果修正

**验收**：随机抽选任意产品，能在1分钟内给出准确介绍（准确率≥95%）

### Phase 3：综合能力训练（持续）
1. 跨产品线组合训练：按行业/场景整理产品包
   - 金融行业：包含哪些产品组合？
   - 政企客户：安全需求对应哪些产品？
   - 移动应用：全生命周期安全方案
2. 模拟客户咨询，训练快速检索+精准回答能力

**验收**：给出客户需求场景，能在5分钟内输出完整产品组合方案（覆盖≥90%相关产品）

### Phase 4：方案制定能力（持续）
1. 收集典型客户需求案例
2. 训练输出完整解决方案文档：
   - 需求分析
   - 产品选型推荐
   - 服务配套建议
   - 报价参考
3. 对比实际方案修正认知

**验收**：能针对复杂客户需求，输出完整解决方案文档，包含产品选型、服务配套、报价参考
