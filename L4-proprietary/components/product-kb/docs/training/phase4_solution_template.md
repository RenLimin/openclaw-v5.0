# Bangcle 综合解决方案模板（Phase 4 训练教材）

> 生成时间：2026-10-17 21:44:53

## 方案结构（六段式）

### 1. 客户需求分析
- 客户行业/规模/业务类型
- 安全现状与痛点（来自沟通/调研）
- 核心诉求提炼（3-5 条）

### 2. 方案总体思路
- 安全理念（如"端到端全渠道防护"、"全生命周期安全"）
- 覆盖范围（渠道/资产/阶段）
- 方案架构图（产品分层）

### 3. 产品选型推荐
按需求匹配产品线：

| 需求点 | 推荐产品/服务 | 产品线 | 类型 | 销售状态 | 定位 |
|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... |

**选型原则**：
- 同一需求点优先选"正常销售"产品（受控/报备需提前确认）
- 产品+服务配套（软件+维保/实施/培训）
- 国产化/信创场景优先鸿蒙NEXT系列 + 信创版服务器

### 4. 服务配套建议
- 实施类：本地安装部署服务、定制化部署实施、国产化适配
- 运营类：驻场运营外包、生产数据分析和策略优化高级服务
- 赋能类：安全专题培训、合规评估能力赋能培训

### 5. 报价参考
- 从 SKU 表查询标准单价（`sku.unit_price`）
- 按授权模式（按应用数/按年/按台）标注
- 标注受控/报备销售的议价空间

### 6. 风险与注意事项
- 受控销售产品的报备流程
- 硬件类产品的交付周期
- 维保/升级服务的续费提醒

## 快速检索口诀

| 客户关键词 | 首选产品线 | 代表产品 |
|---|---|---|
| 银行/支付/证券 | 安全保护 | 可信安全键盘、梆梆密盾、应用加固 |
| 监管/通管局 | 内容安全 | 移动应用监管平台、渠道监测 |
| 车企/车联网 | 物联网服务 | 汽车信息安全测试平台、检测渗透 |
| 互联网APP | 安全监测+安全保护 | 监测平台、加固、API安全 |
| 出海/合规 | 安全服务 | 合规评估、GDPR检测、隐私编写 |
| 政务/信创 | 安全检测+安全产品 | 测评、合规、信创服务器 |
