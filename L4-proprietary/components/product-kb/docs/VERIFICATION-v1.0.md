## 3. 人工操作手册（附录 B）

### 测试环境准备

```bash
# 进入项目目录
cd L4-proprietary/components/product-kb

# 创建数据库
python -m product_kb.cli init --db product_kb.db

# 导入价格表
python -m product_kb.cli import-price --xlsx "/Users/bangcle/Bangcle Workspace/07. Bangcle Prod/梆梆_产品价格查询-2026-09-08.xlsx"

# 扫描文档目录
python -m product_kb.cli scan --root "/Users/bangcle/Bangcle Workspace/07. Bangcle Prod/"

# 构建索引
python -m product_kb.cli build-index

# 数据质量检查
python -m product_kb.cli check
```

# 准备输入CSV: 格式: 产品名称,型号,数量,单价
