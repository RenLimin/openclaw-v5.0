# PRD-v1.0.md — 收入确认自动化模块

## 1. 项目背景

当前收入确收依赖手工 Excel 汇总计算，存在以下问题：
- 人工计算容易出错，需要反复核对
- 汇总步骤多，耗时久（单期需要数小时）
- 结果无法自动化验证，难追溯计算过程
- 缺少历史数据持久化存储，不利于分析

本模块旨在用自动化流程替代手工计算，消除人工错误，提升效率。

## 2. 目标用户

- 财务分析师：需要生成月度/季度确收报表
- 数据分析师：需要查看确收历史数据和趋势
- 开发维护者：需要扩展或调整确收规则

## 3. 功能清单

1. **Excel 数据导入**：从手工确收报表中读取计划确收底稿和预算执行数据，导入到 SQLite 数据库。
2. **SQLite 数据持久化**：结构化存储原始数据，支持查询和追溯。
3. **确收汇总计算**：按期间×分类自动聚合新签和递延确收，计算月度明细、履约维度汇总、重拆履约分析。
4. **Excel 报表导出**：生成与手工报表结构一致的自动化确收报表，包含多个 Sheet。
5. **结果自动验证**：自动对比自动化生成报表与手工报表，输出差异报告。
6. **完整流程编排**：一键执行初始化→导入→计算→导出→验证全流程。

## 4. 验收标准

1. 所有核心功能可正常运行，无运行时错误。
2. 134 项单元测试全部通过，代码覆盖率满足要求。
3. 自动生成结果与手工报表完全匹配（数值差异 ≤ 0.01）。
4. 生成报表结构与手工报表完全一致，可直接用于汇报。
5. 支持版本化隔离，适配未来年度报表结构变化。

## 5. 约束条件

1. 依赖手工 Excel 作为输入数据源，不支持直接从业务系统对接取数（v1 版本）。
2. 仅支持当前版本的手工报表结构，结构变化需要更新配置。
3. 使用 Python + SQLite 实现，不依赖外部数据库服务。
4. 输出为 Excel 文件，不支持直接推送到其他系统。
