# DESIGN-OUTLINE-v1.0.md — 收入确认自动化模块

## 1. 概述

构建自动化确收计算流程，从手工 Excel 导入数据，经结构化存储、聚合计算后，生成标准确收报表，并自动对比验证结果一致性。

## 2. 模块划分

1. **配置模块**：定义文件路径、列映射关系、Sheet 名称、汇总月份等常量。
2. **数据接入模块**：负责 Excel 数据读取、清洗，导入到 SQLite 数据库。
3. **存储模块**：管理 SQLite 连接，创建表结构，提供数据访问能力。
4. **计算引擎模块**：实现核心汇总计算逻辑，包括新签递延汇总、月度明细、履约汇总、重拆履约。
5. **导出模块**：将计算结果按格式写入 Excel，生成最终报表。
6. **验证模块**：对比自动生成报表与手工报表，输出差异验证报告。
7. **主入口模块**：编排初始化、导入、计算、导出、验证全流程。

## 3. 核心依赖

- `openpyxl`：Excel 文件读写。
- `pytest`：单元测试。
- `SQLite`：Python 标准库，数据持久化存储。
- 上层 BDMS 交付管理框架：遵循通用 CLI / 目录结构规范。

## 4. 关键决策点

1. **存储选型**：选择 SQLite 而非 CSV / Pandas DataFrame，因为支持 SQL 聚合查询，零运维，并发读友好。
2. **版本化设计**：按版本划分子包（v1），适配年度报表结构变化，实现平滑迁移。
3. **测试策略**：单元测试中 mock openpyxl，聚焦计算逻辑正确性，测试运行快速确定。
4. **容错设计**：数值比较设置容差（0.01），空值与零等价，跳过 Excel 公式错误单元格。
