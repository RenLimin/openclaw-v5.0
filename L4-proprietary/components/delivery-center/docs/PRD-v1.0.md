# PRD-v1.0.md — BDMS 交付月报系统产品需求文档

## 1. 项目背景

当前交付团队月报依赖手工汇总数据，存在以下问题：
- 手工从 OA、ONES、合同库多个来源导出粘贴，耗时平均 2-4 小时/月
- 格式不统一，不同交付经理产出的月报结构和样式差异大
- 异常识别滞后，缺工时、超额、进度偏差等问题不能及时发现
- 没有历史记录管理，追溯历史月报数据不便

需要一个自动化工具解决上述问题，实现一键生成标准化月报，解放交付经理精力。

## 2. 目标用户

- 交付经理：生成月度交付报告
- PMO：查看多团队交付汇总数据
- 部门负责人：掌握全部门月度交付状态

## 3. 功能清单

| 编号 | 功能 | 说明 |
|------|------|------|
| 1 | 多源数据采集 | 从 OA 导出的合同 Excel、ONES 导出的工时 Excel 中抽取数据，自动清洗 |
| 2 | 合同数据处理 | 合同信息抽取、金额、周期、负责人映射对齐 |
| 3 | 工时数据处理 | 工时按项目/人员/月份汇总，计算人天 |
| 4 | 项目状态追踪 | 自动识别项目当前状态：进行中/已交付/已暂停/风险 |
| 5 | 异常识别 | 自动识别缺工时、超额工时、进度偏差等异常 |
| 6 | 交接管理 | 管理项目收入/验收交接记录，匹配目标月份 |
| 7 | 多维度评分 | 根据合同额、进度、异常等多维度对交付质量加权评分 |
| 8 | 多源关联映射 | 人员/项目/合同多维度数据关联映射，统一口径 |
| 9 | Excel 月报生成 | 生成多 Sheet 标准化 Excel 月报，含汇总、统计、明细 |
| 10 | 异步任务管理 | 月报生成异步执行，Web/CLI 不阻塞，支持查看进度 |
| 11 | 元数据存储 | SQLite 存储生成任务和报告元数据，支持历史追溯 |
| 12 | CLI 入口 | 命令行工具支持生成、查看、列表、迁移等操作 |
| 13 | Web UI 入口 | 可视化页面支持列表查看、生成、预览、下载 |
| 14 | v1→v2 迁移 | 支持从旧版 v1 数据迁移到新版 v2 架构 |

## 4. 验收标准

- 所有核心功能实现，单元测试通过率 ≥ 99%（排除 Web 测试导入问题）
- 基于真实历史数据，生成的月报和手工数据对比零误差
- 支持 v1/v2 双版本并存，可渐进迁移
- 生成一份月报耗时不超过 2 分钟
- 三个入口（CLI/Web/Python API）均可正常使用
- 文档齐全，满足可维护性要求

## 5. 约束条件

- 技术约束：基于 Python 3.10+ 开发，依赖 pandas、openpyxl、FastAPI 等主流库
- 架构约束：作为 L4 专有组件，依赖 L3 DMS 框架能力
- 数据来源：当前支持从 OA、ONES 导出文件采集，不支持 API 实时拉取（后续演进支持）
- 存储约束：元数据存储在 SQLite，报告文件存储在本地文件系统
