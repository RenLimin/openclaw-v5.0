# DESIGN-OUTLINE-v1.0: Bangcle PPT 模板系统

## 1. 概述

构建基于梆梆安全官方 VI 规范的 PPT 模板生成引擎，通过 DSL + 模板引擎 + 渲染器注册模式，实现一键生成符合品牌规范的演示文稿，支持浅色/深色双主题，易于扩展新页面类型。

## 2. 模块划分

| 模块 | 职责 |
|------|------|
| `theme` | 主题系统模块，管理设计常量（配色/字体/尺寸）和主题切换，提供 Theme 对象 |
| `base` | 基类模块，定义 RendererBase 抽象基类，所有页面渲染器都继承该类 |
| `dsl` | DSL 定义模块，使用 Pydantic v2 定义所有页面类型的 Schema，提供严格校验 |
| `engine` | 模板引擎核心模块，负责模板加载、渲染器注册、PPT 生成流程控制 |
| `renderers` | 页面渲染器模块，每个页面类型对应一个渲染器，实现具体绘制逻辑 |
| `templates` | 预置模板模块，34 个 YAML 模板（浅色 19 + 深色 15） |
| `cli` | 命令行入口模块，提供模板列表、验证、生成等命令行功能 |
| `web` | Web UI 模块，提供 Flask Web 服务和可视化界面（可选） |

## 3. 核心依赖

- **L2 底层依赖**：无（直接依赖第三方 Python 库）
- **第三方依赖**：
  - `python-pptx`：PPT 文件生成
  - `pydantic` v2：DSL Schema 校验
  - `pyyaml`：YAML 模板加载
  - `flask`：Web UI（可选依赖）
- **被依赖**：`office-business` 模块使用该组件作为 PPT 模板渲染引擎

## 4. 关键决策点

1. **架构选型**：选择 DSL + 渲染器注册模式，而非硬编码模板，便于扩展维护
2. **主题切换**：通过 Theme 对象管理配色，复用相同布局的渲染器，减少代码重复
3. **Schema 校验**：使用 Pydantic v2 做严格类型校验，提前发现 DSL 定义错误
4. **入口设计**：同时支持 Python API / YAML / CLI / Web UI，覆盖不同使用场景
5. **模板管理**：YAML 文件存储模板，便于版本控制和协作修改
