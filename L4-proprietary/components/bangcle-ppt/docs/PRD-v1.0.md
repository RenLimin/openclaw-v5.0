# PRD-v1.0: Bangcle PPT 模板系统

## 1. 项目背景

梆梆安全有统一的官方 VI 设计规范，PPT 演示文稿制作需要严格遵循该规范。手工制作 PPT 存在以下问题：
- 手工排版效率低，重复劳动多
- 难以保证每一份 PPT 都严格对齐品牌规范
- 新人需要花时间学习模板使用，培训成本高
- 多人协作时风格不一致，影响品牌形象

因此需要一套自动化工具，基于官方 VI 规范，一键生成符合品牌要求的 PPT，提高制作效率，保证品牌一致性。

## 2. 目标用户

- 产品经理：撰写产品方案、需求文档演示
- 研发工程师：技术方案分享、项目汇报
- 市场销售：项目推介、客户汇报
- 运营：活动策划、数据分析汇报
- 设计师：快速产出符合规范的演示文稿初稿

## 3. 功能清单

1. **主题系统**：支持浅色/深色两套官方主题，一键切换配色方案
2. **设计常量管理**：统一管理官方 VI 配色、字体、间距、画布尺寸等设计规范
3. **DSL 驱动模板定义**：使用 YAML 定义模板数据，Pydantic v2 做 Schema 校验，版本可控易维护
4. **可扩展渲染器注册**：新增页面类型只需要新增 Schema + 渲染器 + 注册，遵循开闭原则
5. **预置模板**：提供 34 个预置模板（浅色 19 + 深色 15），覆盖 25+ 页面类型
6. **三入口支持**：Python API / YAML 规格文件 / CLI 命令行 / Web UI 四种使用方式
7. **完整测试覆盖**：所有模板、渲染器都有自动化测试，保证稳定性

## 4. 验收标准

1. 所有 34 个预置模板都能通过 Schema 校验并成功渲染
2. 生成的 PPT 严格遵循官方 VI 规范（配色、字体、间距、尺寸）
3. 支持浅色/深色主题切换，所有页面都能正确应用对应主题配色
4. 扩展新页面类型流程清晰，新增一个页面只需要 3 步（Schema + Renderer + 注册）
5. 所有测试用例通过（249/250）
6. 提供使用文档、示例代码、常见问题排查

## 5. 约束条件

1. **技术约束**：基于 python-pptx 库开发，能力受限于 python-pptx（不支持图表数据导入，仅占位图表）
2. **业务约束**：仅支持梆梆安全官方 VI 规范，不支持自定义品牌色/字体
3. **环境约束**：Python 版本要求 3.10+
4. **依赖约束**：依赖 Pydantic v2、PyYAML、python-pptx，Flask（Web UI 可选）
