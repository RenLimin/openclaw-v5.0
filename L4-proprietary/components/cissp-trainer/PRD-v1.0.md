# 产品需求文档 PRD-v1.0

## 1. 项目背景

CISSP (Certified Information Systems Security Professional) 是 (ISC)² 颁发的信息安全领域顶级认证，考试考察范围广、知识点多，需要大量刷题练习才能掌握。传统刷题方式存在以下痛点：
- 复习无规划：不知道该先学什么、后学什么，知识点之间依赖关系不清晰
- 薄弱点不清晰：做完题只知道对错，无法统计哪些知识点掌握不好
- 缺乏模拟考试环境：无法提前熟悉考试节奏、时间压力
- 记忆效率低：不懂得根据记忆规律安排复习，容易遗忘

现有 CISSP 学习资料主要侧重知识点讲授，缺乏智能练习系统。本模块提供智能刷题、学习路径规划、模拟考试、知识图谱四大核心能力，帮助考生高效备考。

## 2. 目标用户

- 备考 CISSP 认证的考生
- 需要巩固信息安全知识体系的信息安全从业人员

## 3. 功能清单

1. **结构化题库管理**：支持题目/知识点/学习记录结构化存储，支持 YAML/JSON 格式题库导入。
2. **多种出题模式**：随机出题、到期复习、薄弱点强化、模拟考试抽题四种模式，满足不同学习场景。
3. **间隔重复算法**：简化 SM-2 算法，自动安排复习时间，提升记忆效率。
4. **知识点掌握度追踪**：基于指数移动平均（EMA）计算知识点掌握度，精准反映学习状况。
5. **学习统计分析**：总体正确率、分领域正确率、薄弱知识点排名、进度曲线。
6. **学习路径规划**：提供 3 条预设学习路径（入门/强化/冲刺），支持里程碑解锁、动态调整、每日计划生成、智能推荐。
7. **模拟考试引擎**：完整模拟考试流程，支持自定义题量/时长/领域，支持暂停/跳转/标记，考试后自动评分、生成错题解析、成绩对比。
8. **知识图谱服务**：内置 137 条知识点关系，支持前置依赖查询、后继推荐、薄弱点传播分析、可视化热力图。
9. **CLI 交互接口**：13 个子命令覆盖全部功能，方便终端快速使用。
10. **Web UI 接口**：提供完整的 Flask Web 界面，支持浏览器交互。

## 4. 验收标准

- 所有核心功能实现并通过单元测试：155 个测试用例全部通过。
- CLI 命令覆盖所有功能点，交互流程顺畅。
- Web UI 所有页面和 API 可正常访问，功能正常。
- 数据模型设计满足 8 域 1000+ 题目存储需求。
- 间隔重复算法、掌握度计算、知识图谱传播等核心算法逻辑正确。
- 学习路径动态调整、模拟考试暂停/继续等边界场景处理正确。

## 5. 约束条件

- 技术约束：Python 3.10+，依赖 SQLAlchemy 2.0+ 和 PyYAML，不依赖外部数据库（使用 SQLite）。
- 业务约束：当前版本只支持单用户，不支持多用户数据隔离。
- 题库约束：当前只提供 52 道样例题，完整题库需要后续从 cissp-learning 迁移。
- 架构约束：属于 L4 专有业务层，依赖 L2 基础设施层规范，不反向依赖 L3/L4 其他组件。
