# 模拟考试使用指南

> 用真实考试节奏检验学习成果，找出薄弱领域，针对性突破

---

## 为什么做模拟考试？

- **适应节奏**：真实 CISSP 考试 2-4 小时、100-150 题，提前适应长时间考试
- **查漏补缺**：通过分域评分，精确找到薄弱领域
- **建立信心**：稳定考到 70+ 分，上考场不慌
- **对比进步**：每次考试都有记录，清楚看到自己的进步

---

## 考试规则

### 默认参数

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 题目数量 | 100 题 | `-n / --count` 可调 |
| 考试时长 | 180 分钟（3 小时） | `-t / --time` 可调 |
| 及格线 | 70 分 | 与 (ISC)² 官方一致 |
| 题型分布 | 按域权重抽题 | 参考官方考试大纲权重 |
| 题目来源 | 当前题库所有题 | `-d / --domain` 可指定领域 |

### 8 域权重分布

| 域 | 名称 | 权重 |
|----|------|------|
| 1 | 安全与风险管理 | 15% |
| 2 | 资产安全 | 10% |
| 3 | 安全架构与工程 | 13% |
| 4 | 通信与网络安全 | 13% |
| 5 | 身份与访问管理 | 13% |
| 6 | 安全评估与测试 | 12% |
| 7 | 安全运营 | 13% |
| 8 | 软件开发安全 | 11% |

> 💡 题目数量不足的领域会按比例减少，其他领域补足。

## 使用方法

### 开始考试

```bash
# 默认 100 题、3 小时、全领域
cissp-trainer exam start

# 自定义：50 题、2 小时
cissp-trainer exam start -n 50 -t 120

# 指定领域：只考域 1 和域 3
cissp-trainer exam start -d 1 3
```

### 考试操作

考试是交互式的，操作命令：

| 操作 | 说明 |
|------|------|
| `A` / `B` / `C` / `D` | 作答（单选） |
| `A,B` / `A,C,D` | 作答（多选，逗号分隔） |
| `True` / `False` | 作答（判断题） |
| `f` | 标记/取消标记当前题（回头检查用） |
| `#5` | 跳转到第 5 题 |
| `p` | 暂停考试（剩余时间保留） |
| `q` | 提前交卷 |

### 暂停与继续

- 考试随时可以暂停，剩余时间会保留
- 暂停后可以关闭终端，下次再继续
- 暂停状态不扣时间

> ⚠️ 当前 CLI 版本暂不支持 `resume` 命令直接恢复考试（可通过 API 调用）。

### 交卷方式

1. **答完所有题自动提示交卷**
2. **输入 `q` 主动交卷**
3. **时间到自动交卷**（超时的部分不计分）

---

## 评分与分析

交卷后立刻看到完整成绩报告：

### 成绩概览

- ✅/❌ 通过状态
- 📊 得分（百分制）
- ✅ 正确题数 / 总题数
- ❌ 错题数

### 分领域得分

每个领域单独计算正确率，低于 70% 的会标记为 ⚠️ 薄弱。

示例：
```
  域1 安全与风险管理    ████████████░░░  80.0% (8/10)
  域2 资产安全          ████████░░░░░░░  53.3% (4/6)  ⚠️ 薄弱
```

### 薄弱领域

正确率低于 70% 且题数 ≥ 3 的领域，会被单独列出。这些是你下一步重点突破的方向。

### 错题解析

前 5 道错题会直接展示，包含：
- 题目所属领域
- 题干（前 50 字）
- 你的答案 vs 正确答案
- 解析

查看全部错题用 `exam detail` 命令。

## 历史记录与分析

### 考试历史

```bash
cissp-trainer exam history
```

显示最近 N 次考试的成绩，一眼看到趋势。

### 考试详情

```bash
cissp-trainer exam detail <exam_id>
```

完整查看某场考试：
- 基本信息（时间、时长、分数）
- 与上次考试对比
- 进步最大的领域
- 退步最大的领域
- **完整错题列表**（每题都有解析）

### 进步对比

每次 `exam detail` 会自动和上一次考试对比：

- 📈 总分差值（+5.2 分）
- 📊 各领域变化
- 🏆 进步最大的领域
- ⚠️ 退步最大的领域

## 有效的模拟考试方法

### 1. 严格按照真实考试条件

- 找一个安静的环境
- 不要查资料、不要翻书
- 一次做完，不要中途长时间暂停

### 2. 考后分析比分数重要

- 花 1-2 小时认真看错题
- 把错题对应的知识点搞懂
- 薄弱领域专项复习

### 3. 定期模考，保持节奏

| 阶段 | 频率 | 目的 |
|------|------|------|
| 入门期 | 每月 1 次 | 了解水平、建立基准 |
| 强化期 | 每 2 周 1 次 | 检验学习效果、调整重点 |
| 冲刺期 | 每周 1-2 次 | 适应节奏、查漏补缺 |

### 4. 关注趋势，不纠结单次

- 偶尔一次考差很正常
- 看 3-5 次的趋势比单次分数更有意义
- 每次错题都搞懂，分数自然上去

---

## 考试成绩同步

每次模拟考试的答题结果会**自动同步到学习系统**：

- ✅ 更新题目统计（出现次数、正确次数）
- ✅ 更新知识点掌握度（EMA 算法）
- ✅ 更新 SM-2 间隔重复状态
- ✅ 计入学习路径进度

所以模拟考试不只是"模拟"，也是有效学习的一部分。

---

## 注意事项

1. **题库有限，分数会虚高**：目前只有 52 道样例题，做几次就记住了。真实考试要难很多。
2. **重在查漏补缺**：不要沉迷于分数，关键是找到不会的知识点。
3. **考试中不要强制退出**：虽然系统支持暂停，但强制终止可能导致数据异常。
4. **时间管理**：平时练习就要注意时间，平均每题不超过 2 分钟。
