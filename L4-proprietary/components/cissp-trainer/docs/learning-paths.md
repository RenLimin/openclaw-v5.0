# 学习路径使用指南

> 从"能刷题"到"有体系地学" — 用学习路径规划你的 CISSP 备考之旅

---

## 为什么需要学习路径？

CISSP 有 8 大领域、上千个知识点，如果只是盲目刷题，很容易：

- 学了后面忘了前面
- 薄弱的地方一直薄弱
- 不知道自己处于什么阶段
- 缺乏成就感和持续动力

学习路径解决这些问题：
- 🎯 **明确目标**：每个阶段有清晰的里程碑
- 📅 **每日计划**：今天该学什么、做多少题，系统告诉你
- 📈 **进度可见**：完成度百分比、里程碑解锁，成就感满满
- 🔄 **动态调整**：表现好就加量加难度，表现差就降难度巩固
- 🧭 **智能推荐**：根据你的水平推荐最合适的路径

---

## 三条预设路径

### 🌱 入门路径（beginner）

- **时长**：30 天
- **每日题量**：10 题
- **难度**：1-3
- **目标**：建立 CISSP 8 大领域知识框架，达到 60% 正确率
- **适合**：零基础、第一次接触 CISSP、久疏复习

**5 个里程碑**：

| 阶段 | 名称 | 解锁条件 |
|------|------|---------|
| 1 | 安全基础入门 | 域 1、2 正确率 ≥ 50% |
| 2 | 技术核心入门 | 域 3、4 正确率 ≥ 50% |
| 3 | 身份与运营入门 | 域 5、7 正确率 ≥ 50% |
| 4 | 测试与开发入门 | 域 6、8 正确率 ≥ 50% |
| 5 | 入门完成 | 全部 8 领域正确率 ≥ 60% |

### 🌿 强化路径（advanced）

- **时长**：60 天
- **每日题量**：20 题
- **难度**：2-5
- **目标**：全面深度学习，8 领域达到 80% 正确率
- **前置**：完成入门路径
- **适合**：有一定基础、想系统掌握全部领域

**5 个里程碑**：

| 阶段 | 名称 | 解锁条件 |
|------|------|---------|
| 1 | 风险管理精通 | 域 1 掌握度 ≥ 80% |
| 2 | 架构与网络精通 | 域 3、4 掌握度 ≥ 80% |
| 3 | 身份与运营精通 | 域 5、7 掌握度 ≥ 80% |
| 4 | 测试与开发精通 | 域 6、8 掌握度 ≥ 80% |
| 5 | 全面精通 | 全部 8 领域 ≥ 80% |

### 🔥 冲刺路径（sprint）

- **时长**：14 天
- **每日题量**：50 题
- **难度**：3-5
- **目标**：模拟考试稳定 70+ 分，消除薄弱知识点
- **前置**：完成强化路径
- **适合**：考前冲刺、查漏补缺

**4 个里程碑**：

| 阶段 | 名称 | 解锁条件 |
|------|------|---------|
| 1 | 首次模拟考 | 完成第一次完整模考，达 60 分 |
| 2 | 薄弱点扫荡 | 所有薄弱知识点掌握度提升至 70% |
| 3 | 模拟考通关 | 连续 2 次模拟考 ≥ 70 分 |
| 4 | 冲刺完成 | 平均正确率 75%+，准备上考场 |

## 使用方法

### 1. 选择路径

```bash
# 查看所有可用路径
cissp-trainer path list

# 让系统推荐
cissp-trainer path recommend
```

### 2. 开始路径

```bash
# 开始入门路径
cissp-trainer path start beginner
```

> ⚠️ 强化路径和冲刺路径有前置要求，需要先完成前置路径才能解锁。

### 3. 查看进度

```bash
# 当前路径状态 + 里程碑进度
cissp-trainer path status
```

输出包含：
- 总进度百分比 + 进度条
- 每个里程碑的完成情况
- 当前阶段名称和目标

### 4. 每日学习

```bash
# 今日学习计划
cissp-trainer path today
```

输出包含：
- 🎯 今日题量目标
- 🎮 推荐练习模式（random / weak / review）
- 📍 当前里程碑
- 🔍 今日重点知识点（薄弱点）
- 💡 学习建议
- 直接复制粘贴就能开练的命令

### 5. 开始练习

根据 `path today` 的建议执行：

```bash
# 例如：random 模式 10 题
cissp-trainer start --mode random --count 10
```

## 动态调整机制

系统会根据你最近的答题表现自动调整路径难度和题量：

### 表现好 → 加量加难度

触发条件：
- 连续 3 天正确率 > 85%

调整内容：
- 难度上限 +1（最高 5）
- 每日题量 +5（最高 50）

### 表现差 → 降量降难度

触发条件：
- 连续 3 天正确率 < 50%

调整内容：
- 难度下限 -1（最低 1）
- 每日题量 -3（最低 5）

### 薄弱领域预警

如果某个领域答题 ≥ 5 道但正确率 < 50%，系统会标记为薄弱领域，并在每日计划中重点提醒。

## 进度计算方式

### 总完成度

```
总完成度 = （8 领域平均正确率 / 最终里程碑目标掌握度） × 100%
```

上限 100%，基于当前路径最后一个里程碑的掌握度阈值。

### 当前里程碑

按顺序检查每个里程碑：
1. 取该里程碑涉及的所有领域
2. 计算这些领域的平均正确率
3. 达到阈值 → 解锁，检查下一个
4. 第一个未达到的里程碑就是"当前里程碑"

### 每日目标计算

- 入门阶段（<30%）：random 模式，全面铺开建框架
- 中期阶段（30%-70%）：weak 模式，针对性强化薄弱点
- 后期阶段（>70%）：review 模式，间隔复习巩固记忆

---

## 小贴士

1. **循序渐进**：不要跳级，每条路径的设计都有梯度，按顺序来效果最好
2. **每天坚持**：连续学习比突击效果好得多，10 分钟也比不学强
3. **关注薄弱点**：薄弱知识点是提分最快的地方，优先攻克
4. **定期看里程碑**：每解锁一个里程碑，给自己一个小奖励
5. **路径是工具不是枷锁**：觉得太简单或太难，可以调整——系统也会自动调
