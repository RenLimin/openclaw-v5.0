## 1. 背景与目标

### 1.1 业务背景

Rex 的家庭理财需求：全本地、零外部依赖、数据自主掌控。市面理财产品（随手记/挖财等）均需云端同步，数据不可控。

### 1.2 产品目标

1. **全本地运行**：SQLite 单文件 DB，零外部 API 调用
2. **专业记账**：借贷记账法（资产=负债+权益恒等式），Decimal 精度杜绝浮点误差
3. **六大理财能力**：核算/贷款/保险/投资/利率/建议（继承 L3 引擎）
4. **12 页面 Web UI** + CLI（finctl）+ OpenClaw skill 三通道
5. **银行流水导入**：招行/工行/支付宝/微信 4 格式，智能规则分类 + 自动去重
6. **三大报表**：资产负债表/利润表/现金流量表，Excel + Word 导出

### 2.2 用户角色

单家庭用户（Rex），预留多家庭切换（v1.1 用户鉴权）。

### 2.3 验收标准

1. ✅ 全部测试通过（当前基线 189/189）
2. ✅ 借贷恒等式：任意操作后 资产=负债+权益 成立
3. ✅ 金额全程 Decimal，无浮点误差
4. ✅ 三通道一致：Web UI / CLI / skill 操作同一 DB
5. ✅ 导入去重：同一流水重复导入不产生重复记录
6. ✅ 备份恢复：备份→修改→恢复后数据回到备份点

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 数据主权 | 全本地，零外发（银行/券商不连接） |
| L4→L3 继承 | 通过 sys.path 注入 import L3 引擎，反向依赖禁止 |
| 精度 | 金额 decimal.Decimal |
| 部署 | Docker / systemd / launchd 三方式 |
