## 更新方式

1. 启动本地开发服务：`make run`
2. 打开浏览器访问对应页面
3. 截取屏幕（建议宽度 1200px 左右）
4. 保存为 PNG 格式，文件名见上表
5. 压缩优化后替换本目录对应文件

> 提示：可用 `pageres` 或 `shot-scraper` 等工具自动生成截图。
