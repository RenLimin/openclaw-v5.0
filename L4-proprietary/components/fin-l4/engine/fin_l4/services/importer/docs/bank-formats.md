# 银行格式清单

当前支持 4 种银行/支付格式。所有模板均为 YAML 配置驱动，可扩展。

| 银行/支付 | 模板 ID | 格式 | 编码 | 典型来源 |
|-----------|---------|------|------|----------|
| 招商银行 | `cmb` | CSV | 多编码自动检测 | 网银/APP 导出 |
| 工商银行 | `icbc` | CSV/Excel | GBK/UTF-8 | 网银导出 |
| 支付宝 | `alipay` | CSV | UTF-8 | 支付宝账单下载 |
| 微信支付 | `wechat` | CSV | UTF-8 | 微信支付账单导出 |

## 1. 招商银行 (cmb)

### 典型表头
```
记账日期,交易时间,交易金额,币种,余额,收支,对方户名,对方账号,摘要
```

### 字段映射

| CSV 列 | 目标字段 | 说明 |
|--------|----------|------|
| 记账日期 | date | 交易日期 |
| 交易时间 | time | 交易时间 |
| 交易金额 | amount | 带正负号的金额 |
| 币种 | currency | 币种代码 |
| 余额 | balance | 交易后余额 |
| 收支 | direction_text | "收入"/"支出" |
| 对方户名 | counterparty | 对方账户名称 |
| 对方账号 | counter_account | 对方账号 |
| 摘要 | description | 交易摘要 |

### 金额方向规则
- `收支 = "收入"` → 收入
- `收支 = "支出"` → 支出
- 否则根据金额正负判断

### 识别关键字
`记账日期` + `交易金额` + `收支` + `对方户名` 中出现 ≥ 3 个

## 2. 工商银行 (icbc)

### 典型表头
```
交易日期,交易时间,收入金额,支出金额,余额,对方户名,对方账号,交易场所,摘要,备注
```

### 字段映射

| CSV 列 | 目标字段 | 说明 |
|--------|----------|------|
| 交易日期 | date | |
| 交易时间 | time | |
| 收入金额 | income_amount | 收入时的金额 |
| 支出金额 | expense_amount | 支出时的金额 |
| 余额 | balance | |
| 对方户名 | counterparty | |
| 对方账号 | counter_account | |
| 摘要 | description | |
| 备注 | memo | |

### 金额方向规则
- 收入金额 > 0 → 收入
- 支出金额 > 0 → 支出

### 识别关键字
`交易日期` + `收入金额` + `支出金额` + `对方户名` 中出现 ≥ 3 个

## 3. 支付宝 (alipay)

### 典型格式
支付宝导出的 CSV 有头部说明行（前 5 行跳过），表头从第 6 行开始。

```
支付宝（中国）网络技术有限公司  电子客户回单
--------------------------------------------
账号: 1234567890
起始日期: 2026-09-01
终止日期: 2026-09-30
交易创建时间,付款时间,最近修改时间,交易来源地,类型,交易对方,商品名称,金额（元）,收/支,交易状态,服务费（元）,成功退款（元）,备注,资金状态
```

### 字段映射

| CSV 列 | 目标字段 | 说明 |
|--------|----------|------|
| 交易创建时间 | date + time | 拆分为日期和时间 |
| 金额（元） | amount | 金额数值 |
| 收/支 | direction_text | "收入"/"支出" |
| 交易对方 | counterparty | 对方名称 |
| 商品名称 | description | 商品/服务描述 |
| 交易状态 | status | 过滤"交易成功" |

### 金额方向规则
- `收/支 = "收入"` → 收入
- `收/支 = "支出"` → 支出

### 识别关键字
`交易创建时间` + `金额（元）` + `收/支` + `交易对方` 中出现 ≥ 3 个

### 特殊处理
- `skip_rows: 5` — 跳过头部 5 行说明
- 仅导入 `交易状态 = "交易成功"` 的记录

## 4. 微信支付 (wechat)

### 典型格式
微信支付账单也有头部说明行（前 16 行跳过）。

```
微信支付账单明细
微信昵称：[昵称]
起始时间：[起始]
终止时间：[终止]
导出时间：[导出]
--------------------
共 100 笔记录
--------------------
交易时间,交易类型,交易对方,商品,收/支,金额(元),支付方式,当前状态,交易单号,商户单号,备注
```

### 字段映射

| CSV 列 | 目标字段 | 说明 |
|--------|----------|------|
| 交易时间 | date + time | |
| 交易对方 | counterparty | |
| 商品 | description | |
| 收/支 | direction_text | |
| 金额(元) | amount | 带 ¥ 符号 |
| 支付方式 | pay_method | |
| 当前状态 | status | |
| 交易单号 | txn_id | |

### 金额方向规则
- `收/支 = "收入"` → 收入
- `收/支 = "支出"` → 支出

### 识别关键字
`交易时间` + `交易对方` + `收/支` + `金额(元)` 中出现 ≥ 3 个

### 特殊处理
- `skip_rows: 16` — 跳过头部 16 行说明
- 金额字段含 `¥` 符号，自动清理
