## 1. 快速入门

### 1.1 启动服务

FIN-L4 支持三种部署方式，`deploy.sh` 自动检测环境并选择最优方式。

```bash
# 一键启动（自动检测 Docker，无则回退裸机）
cd finance-engine
./deploy.sh

# 强制 Docker 部署
./deploy.sh --docker

# 强制裸机部署（Linux systemd / macOS launchd）
./deploy.sh --bare
```

**环境变量**（可在命令前设置，或写入 `.env` 文件）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `FIN4_PORT` | `8500` | 服务监听端口 |
| `FIN4_FAMILY_ID` | `default` | 家庭 ID（多家庭隔离） |
| `FIN4_DB_DIR` | `~/.fin-l4` | 数据目录（SQLite 存放位置） |
| `FIN4_HOST` | `127.0.0.1` | 监听地址（容器内为 `0.0.0.0`） |
| `FIN4_IMPORT` | `0` | 部署后导入演示数据（`1`=是） |
| `FIN4_DEBUG` | `0` | 调试模式（`1`=开启） |

### 1.2 访问系统

启动成功后，在浏览器打开：

```
http://localhost:8500
```

生产环境如修改了端口，替换为对应端口号（如 `http://localhost:8510`）。

### 1.3 查看状态

```bash
./deploy.sh --status
```

输出示例：
```
[INFO] Docker 部署: 容器 fin-l4 状态 = running
[INFO] 访问: http://localhost:8500
```

### 1.4 停止服务

```bash
./deploy.sh --stop
```

### 1.5 卸载（保留数据）

```bash
./deploy.sh --uninstall
```

> ⚠️ Docker 部署的 `--uninstall` 会删除数据卷 `fin4_data`，数据将丢失。裸机部署保留数据目录。

## 2. 功能模块操作指南

系统共 **12 个页面**，左侧导航栏统一入口。

### 2.1 Dashboard（仪表盘）

**用途**：家庭财务总览，一眼看清资产负债、现金流、资产分布。

**操作步骤**：
1. 登录后默认进入 Dashboard
2. 顶部卡片展示：净资产、总资产、总负债、资产负债率
3. 中部图表：资产分布饼图、月度现金流柱状图
4. 底部列表：账户余额 Top、最近 10 笔交易
5. 点击账户名可跳转至「账户管理」详情

### 2.2 Accounts（账户管理）

**用途**：管理所有资产/负债账户，设置期初余额。

**操作步骤**：
1. 点击左侧「账户」进入
2. 点击「新建账户」→ 选择账户类型、填写名称、期初余额
3. 支持 5 大类账户：资产 / 负债 / 权益 / 收入 / 费用
4. 点击账户查看明细与余额变动历史

### 2.3 Transactions（记账）

**用途**：日常收支记录，支持借贷记账法。

**操作步骤**：
1. 点击左侧「记账」进入
2. 选择交易日期（默认今日）
3. 填写：借方账户、贷方账户、金额、备注、分类
4. 点击「保存」，系统自动双分录记账
5. 列表支持按日期范围、账户、分类筛选

> **原则**：每笔交易必须有借方和贷方，保证会计恒等式平衡。

### 2.4 Budget（预算管理）

**用途**：按月设置各类别预算，监控执行情况。

**操作步骤**：
1. 点击左侧「预算」进入
2. 顶部切换月份（默认当前月）
3. 点击「设置预算」→ 选择分类、填写预算金额
4. 进度条展示：已用金额 / 预算金额
5. 超预算时进度条变红，并在 Dashboard 告警

### 2.5 Loans（贷款管理）

**用途**：房贷、车贷、消费贷等负债的管理与模拟。

**操作步骤**：
1. 点击左侧「贷款」进入列表
2. 点击「新增贷款」→ 填写金额、利率、期限、开始日期、还款方式
3. 点击具体贷款查看：
   - 还款计划表（每期本金/利息/剩余本金）
   - 汇总信息（总利息、月供、剩余期数）
   - 提前还款模拟：输入金额 → 查看节省利息
4. 「提前还款」按钮：实际执行提前还款
5. 「结清贷款」按钮：标记贷款已结清

### 2.6 Insurance（保险管理）

**用途**：保单管理、现金价值测算、保障缺口分析。

**操作步骤**：
1. 点击左侧「保险」进入保单列表
2. 点击「新增保单」→ 填写险种、保额、保费、缴费期、保障期
3. 点击具体保单查看：
   - 保单基本信息
   - 现金价值表（逐年）
   - 「退保测算」按钮：模拟退保能拿回多少钱
4. 顶部「保障缺口分析」标签页：
   - 按险种对比当前保额 vs 建议保额
   - 计算保障缺口金额

### 2.7 Portfolio（投资组合）

**用途**：股票、基金、债券等投资持仓管理与分析。

**操作步骤**：
1. 点击左侧「投资」进入组合列表
2. 点击「新建组合」→ 命名（如"养老组合"、"教育金"）
3. 点击组合详情：
   - 持仓列表（代码/名称/份额/成本价/现价/盈亏）
   - 资产配置饼图（股票/债券/现金占比）
   - 再平衡建议（偏离目标配置的调仓建议）
   - 收益率曲线（累计收益率走势）
4. 「买入」「卖出」按钮：调整持仓
5. 「更新价格」按钮：手动更新最新市价

### 2.8 Advise（理财建议）

**用途**：财务健康体检 + 智能理财建议。

**操作步骤**：
1. 点击左侧「理财建议」进入
2. 输入月收入、月支出（或取系统自动计算值）
3. 点击「开始体检」，系统输出：
   - 财务健康评分（0-100）
   - 应急储备金是否充足
   - 负债比率是否健康
   - 保障是否到位
   - 资产配置合理性
4. 每项问题附带改进建议

### 2.9 Report（财务报表）

**用途**：生成标准财务报表。

**操作步骤**：
1. 点击左侧「报表」进入
2. 选择报表类型：
   - **资产负债表**：总资产、总负债、净资产（时点数据）
   - **利润表（收支表）**：本期收入、支出、结余
   - **现金流量表**：月度现金流趋势（近 6/12 个月）
3. 支持导出 Excel / Word（点击右上角「导出」）
4. 支持按时间范围筛选

### 2.10 Rates（利率管理）

**用途**：市场利率快照，供贷款、投资计算引用。

**操作步骤**：
1. 点击左侧「利率」进入
2. 查看当前各期限利率（LPR、存款利率、国债收益率等）
3. 点击「手动录入」→ 新增利率快照
4. 历史曲线：查看利率走势
5. 利率数据供贷款计算、保险定价、投资对比引用

### 2.11 Import（数据导入）

**用途**：CSV 批量导入交易数据，支持银行/券商账单格式。

**操作步骤**：
1. 点击左侧「导入」进入
2. 选择 CSV 文件（UTF-8 编码）
3. 预览数据 → 字段映射（日期/金额/对方/分类）
4. 选择导入规则模板（或自定义规则）
5. 点击「确认导入」
6. 导入完成后查看：成功条数 / 失败条数 / 失败原因

**CSV 格式要求**：
- 必须包含列：日期、金额
- 建议包含列：对方账户、备注、分类
- 金额正数=收入，负数=支出（或按导入规则映射）

### 2.12 Settings（设置）

**用途**：系统配置、家庭信息、数据管理。

**操作步骤**：
1. 点击左侧「设置」进入
2. 家庭信息：家庭名称、成员管理
3. 分类管理：自定义收支分类
4. 数据管理：手动备份 / 恢复 / 清空
5. 外部系统链接：只读跳转（不存凭据）

## 3. 数据录入指南

### 3.1 期初余额录入

**首次使用时**，需要设置各账户的期初余额：

1. 进入「账户管理」→「新建账户」
2. 选择账户类型（资产类为正余额，负债类为负余额）
3. 填写「期初余额」字段（截至某个日期的实际余额）
4. 系统会在该日期创建一笔初始余额记录

**推荐的初始账户列表**：

| 类别 | 账户示例 | 类型 |
|---|---|---|
| 资产 | 工资卡、现金、余额宝、股票账户、房产 | 资产 |
| 负债 | 房贷、车贷、信用卡 | 负债 |
| 权益 | 初始净资产（轧差用） | 权益 |

### 3.2 手动记账

日常消费/收入建议每日录入，保持数据新鲜度。

**典型场景**：

| 场景 | 借方 | 贷方 | 金额 |
|---|---|---|---|
| 工资到账 | 工资卡（资产） | 工资收入（收入） | 10,000 |
| 超市购物 | 餐饮支出（费用） | 信用卡（负债） | 200 |
| 信用卡还款 | 信用卡（负债） | 工资卡（资产） | 3,000 |
| 买入股票 | 股票持仓（资产） | 证券账户（资产） | 5,000 |

### 3.3 CSV 批量导入

适合导入银行月度账单、信用卡账单等批量数据。

**流程**：
```
CSV 文件 → 字段映射 → 分类规则匹配 → 预览确认 → 执行导入
```

**内置导入规则**：
- 支付宝账单格式
- 微信支付账单格式
- 招商银行信用卡账单格式
- 自定义规则（在「设置 → 导入规则」配置）

## 4. 账户体系说明

### 4.1 五大类账户

FIN-L4 采用标准**借贷记账法**，账户分为 5 大类：

| 类别 | 英文 | 余额方向 | 说明 |
|---|---|---|---|
| **资产** | Asset | 借方（+） | 你拥有的东西：现金、存款、投资、房产、车辆 |
| **负债** | Liability | 贷方（+） | 你欠别人的：房贷、车贷、信用卡、借款 |
| **权益** | Equity | 贷方（+） | 净资产 = 资产 - 负债；期初余额、本期结余 |
| **收入** | Income | 贷方（+） | 本期流入：工资、投资收益、兼职收入 |
| **费用** | Expense | 借方（+） | 本期流出：餐饮、交通、住房、医疗 |

### 4.2 会计恒等式

```
资产 = 负债 + 权益 + (收入 - 费用)
```

每笔交易同时影响至少两个账户，恒等式始终成立。系统会自动校验试算平衡。

### 4.3 账户层级

支持二级账户（父账户 → 子账户），便于归类汇总。例如：

```
资产类
├── 流动资产
│   ├── 现金
│   ├── 工资卡（招行）
│   └── 余额宝
├── 投资资产
│   ├── 股票账户
│   └── 基金账户
└── 固定资产
    └── 自住房产
```

## 5. 日常操作流程

### 5.1 每日记账流程

1. 打开系统 → 进入「记账」页面
2. 录入当日所有收支交易
3. 检查 Dashboard 账户余额是否与实际一致
4. （可选）核对分类是否准确

**建议**：每天花 5 分钟记账，数据越完整报表越准。

### 5.2 每月结账流程

每月初建议执行以下操作：

1. 核对上月所有账户余额（银行 app 对比）
2. 检查信用卡账单是否全部入账
3. 查看「预算」页面，分析超预算类别
4. 查看「报表 → 收支表」，了解当月结余
5. 导出月度报表存档（Excel / PDF）

### 5.3 贷款管理流程

**新增贷款**：
1. 放款日当天录入贷款（本金、利率、期限）
2. 系统自动生成还款计划表

**每月还款**：
1. 银行扣款后，在「记账」录入一笔还款交易
2. 借：贷款账户（减少负债）+ 利息支出
3. 贷：银行存款（减少资产）

**提前还款**：
1. 进入贷款详情页 → 填写提前还款金额
2. 点击「模拟」查看节省利息
3. 确认后点击「执行提前还款」

### 5.4 保险管理流程

**新购保险**：
1. 进入「保险」→「新增保单」
2. 填写险种、保额、保费、缴费期、保障期
3. 系统自动计算现金价值表

**年度检视**：
1. 进入「保障缺口分析」
2. 查看各险种当前保额 vs 建议保额
3. 根据缺口调整保障配置

## 6. 运维操作

### 6.1 数据备份

**自动备份**（推荐配置 cron）：

```bash
# 备份脚本（保留最近 14 份）
./deploy/backup.sh

# 备份到指定目录
./deploy/backup.sh /path/to/backups
```

**手动备份**（SQLite 热备）：

```bash
sqlite3 ~/.fin-l4/fin_l4.db ".backup ~/fin_l4_backup_$(date +%Y%m%d).db"
```

**Docker 卷备份**：

```bash
docker run --rm -v fin4_data:/data -v $(pwd)/backups:/backup \
    alpine tar czf /backup/fin4_data_$(date +%Y%m%d).tar.gz -C /data .
```

**建议备份频率**：
- 每日自动备份（cron 定时）
- 重大操作前手动备份（升级、批量导入）
- 异地备份（同步到云盘 / 另一台机器）

### 6.2 数据恢复

```bash
# 1. 停止服务
./deploy.sh --stop

# 2. 覆盖数据库文件
cp backups/fin_l4_20260904_220000.db ~/.fin-l4/fin_l4.db

# 3. 启动服务
./deploy.sh
```

> ⚠️ 恢复操作不可逆，恢复前务必备份当前数据。

### 6.3 系统升级

**Docker 部署**：

```bash
cd finance-engine
git pull          # 拉取最新代码
docker compose build && docker compose up -d
```

**裸机部署**：

```bash
cd finance-engine
git pull
./.venv/bin/pip install -r fin_l4/requirements.txt
# systemd:
sudo systemctl restart fin-l4
# 或 launchd:
launchctl unload ~/Library/LaunchAgents/com.finl4.web.plist
launchctl load ~/Library/LaunchAgents/com.finl4.web.plist
```

### 6.4 日志查看

**Docker 部署**：

```bash
docker logs -f fin-l4       # 实时查看
docker logs fin-l4 --tail 100   # 最近 100 行
```

**systemd 部署**：

```bash
journalctl -u fin-l4 -f          # 实时
journalctl -u fin-l4 --since today  # 今日
```

**launchd 部署**：

```bash
log show --predicate 'process == "python"' --last 1h
```

### 6.5 修改端口

**临时修改**：

```bash
FIN4_PORT=8510 ./deploy.sh
```

**永久修改**：

在项目根目录创建/编辑 `.env` 文件：

```env
FIN4_PORT=8510
FIN4_HOST=0.0.0.0
```

然后重启服务：

```bash
./deploy.sh --stop && ./deploy.sh
```

## 7. 常见问题 FAQ

### Q1：忘记了服务地址怎么办？

运行 `./deploy.sh --status` 查看部署状态和访问地址。

### Q2：Docker 容器启动失败，如何排查？

```bash
docker logs fin-l4    # 查看容器日志
docker ps -a          # 查看所有容器状态
```

常见原因：端口被占用、数据卷权限问题、镜像构建失败。

### Q3：数据存在哪里？可以直接编辑吗？

- 裸机：`~/.fin-l4/fin_l4.db`
- Docker：命名卷 `fin4_data`，位于 `/var/lib/docker/volumes/fin4_data/_data/`

**不建议直接编辑数据库**。应通过系统界面操作，或使用 `sqlite3` 命令行在**备份后**谨慎修改。

### Q4：怎么把数据迁移到另一台机器？

1. 在旧机器上备份：`./deploy/backup.sh`
2. 把备份文件复制到新机器
3. 在新机器上部署系统
4. 停止服务 → 覆盖数据库 → 启动服务

### Q5：系统支持多用户吗？

当前版本为单家庭单用户设计，无登录鉴权。如需多家庭成员使用，建议通过家庭共享账号 + 反向代理鉴权的方式。

### Q6：CSV 导入失败怎么办？

1. 检查文件编码：必须是 UTF-8
2. 检查必填列：日期、金额列不能缺失
3. 检查日期格式：支持 `YYYY-MM-DD`、`YYYY/MM/DD`
4. 检查金额格式：数字即可，支持负号
5. 在导入预览页面查看具体错误提示

### Q7：资产负债表不平怎么办？

1. 检查是否有单边录入的交易（理论上系统不允许）
2. 运行试算平衡：「报表 → 试算平衡」
3. 若期初余额录入有误，在「账户管理」中调整
4. 可使用「权益 → 本期结余」账户轧差

### Q8：贷款提前还款后，月供会变吗？

默认**期限不变、月供减少**。如需月供不变、期限缩短，可在贷款详情页切换提前还款模式。

### Q9：保险现金价值怎么算出来的？

基于保单类型和行业通用的现金价值计算模型（定期寿险/重疾险/年金险各有不同）。实际值以保险公司合同为准，系统值为估算参考。

### Q10：系统安全吗？会不会泄露我的财务数据？

FIN-L4 的设计原则是**全本地、零外连**：
- 数据全部存在本地 SQLite，不上传任何云端
- 不连接银行/券商 API，不自动同步
- 外部系统链接为只读跳转，不存储凭据
- 默认监听 `127.0.0.1`，仅本机可访问

### Q11：移动端可以用吗？

当前版本为桌面端 Web 设计，移动端未做适配。手机浏览器可访问但布局可能拥挤。移动端适配在规划中。

## 8. 故障排查清单

### 8.1 服务无法启动

| 现象 | 可能原因 | 排查命令 / 操作 |
|---|---|---|
| 端口占用 | 其他程序占了 8500 | `lsof -i :8500` 或换端口 `FIN4_PORT=8510` |
| 权限不足 | 数据目录无法写入 | 检查 `~/.fin-l4/` 权限 |
| Python 版本低 | 低于 3.12 | `python3 --version`，升级 Python |
| 依赖缺失 | 依赖未安装 | `pip install -r fin_l4/requirements.txt` |
| Docker daemon 未启动 | Docker 没运行 | `docker info` 检查 |

### 8.2 页面打不开

| 现象 | 可能原因 | 排查操作 |
|---|---|---|
| 连接被拒绝 | 服务未启动 | `./deploy.sh --status` |
| 404 Not Found | URL 路径错误 | 检查地址，根路径 `/` |
| 500 Internal Error | 代码异常 | 查看日志，确认数据库文件正常 |
| 样式错乱 | 静态文件加载失败 | 检查浏览器 Console，确认 `/static/` 路径可访问 |

### 8.3 数据异常

| 现象 | 可能原因 | 排查操作 |
|---|---|---|
| 余额不对 | 漏记/错记交易 | 逐笔核对，或调整期初余额 |
| 报表不平 | 数据库损坏/手动修改 | 运行 `sqlite3 fin_l4.db "PRAGMA integrity_check"` |
| CSV 导入乱码 | 文件编码非 UTF-8 | 用 `iconv -f GBK -t UTF-8 input.csv > output.csv` 转换 |
| 分类错误 | 自动分类规则不准 | 在「设置 → 分类规则」中添加自定义规则 |

### 8.4 升级后异常

1. 先**回滚**到上一个版本（`git checkout <prev-tag>`）
2. 确认旧版本正常
3. 查看新版本 CHANGELOG，是否有破坏性变更
4. 检查数据库 schema 是否需要迁移
5. 联系开发人员获取支持
