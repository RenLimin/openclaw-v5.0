### 0.2 反推出的固定结构（三段式）

```
请 <PM> 负责，参考<POC项目|签约项目|提前实施项目>：
[单行式] <编号>（<状态>，授权/维保至<YY.MM>）。
[列表式]  1. <编号>（<状态>，<授权说明>）。
          2. <编号>（<状态>）。
注：<风险提示，含多项目隔离 / 归档日期 / 追认 / 增购区分>
```

- 状态词表：`已结项` / `已交付已验收` / `可结项` / `已交付未验收` / `已交付未关联签约合同`
- 授权期限：取 ONES 授权结束日期。格式：区间跨度 ≥ 365 天（满一年）→ `YY.MM`（如 `27.08`）；不足一年保留日 `YY.MM.DD`（如 `26.12.11`、`26.11.30`）。校准自 4 个 Rex 样本（886362/886448/886314/886404）
- 「#1」= 参考列表第 1 项；「增购」= 同产品追加授权

## 1. 目标

把「分配项目经理」节点的人工判断固化为**只读资产**：

> 输入 OA 单（916/815/820）→ 输出 ①参考项目清单（编号/状态/授权期限）
> ②风险注（多项目隔离 / 归档日期 / 追认 / 增购区分）③PM 路由建议
> → 供 Rex 直接粘贴到 OA 批注。

## 5. 非目标

- 不做 OA 写操作（人工闸，沿用 757 口径）
- 不做合同原文审查（属 `oa-approval`）
- 不做 PM 自动指派（只给建议，人填）

## 6. 风险

- ONES 授权期限仅在【云端】license 任务描述中，私有化/维保项目可能【缺失】→ 不阻断
- 项目名匹配为模糊（`name_match`），须人工确认是否本期新项目 → 输出标注「候选」
- 757 权限按单变化 → 必须支持单级降级
