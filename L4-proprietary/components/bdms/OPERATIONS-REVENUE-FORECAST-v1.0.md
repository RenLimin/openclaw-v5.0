# OPERATIONS — 实时动态确认收入预估（Revenue Forecast）v1.0

| 项 | 值 |
|---|---|
| 所属 | BDMS / revenue_forecast |
| 版本 | v1.0 |
| 日期 | 2026-11-08 |

> 本手册描述 v1.0：基于**已提供的上一账期财报**（收入预算执行表）计算。Part B（ONES 实时动态）尚未接入，页面显示"待接入"。

---

## 1. 安装与启动

模块随 BDMS 主包安装，无新增第三方依赖、无额外服务。

### 1.1 初始化数据库

首次使用自动建表（`forecast_period/line/monthly/totals`），也可显式执行：

```bash
python -m bdms.cli forecast init
# → ✅ forecast 表就绪
```

### 1.2 启动 Web

```bash
python -m uvicorn bdms.web.main:app --host 127.0.0.1 --port 8000
```

侧栏「确认收入管理」→「收入预估」（`/forecast`）。

---

## 2. 操作指南（Web）

### 2.1 上传财报（月度/账期例行）

1. 进入「收入预估」，点「上传财报」；
2. 选择当期 `计划确收&实际确收对比表.xlsx`，填写账期（如 `202609`）与年度 `2026`；
3. 提交后异步解析，页面显示**实时进度条**（解析→关联→计算→落库）；
4. 完成后自动切换为当前账期。旧账期保留，可在顶部下拉回看。

> 上传失败（文件错/缺 Sheet）会明确报错，并**继续保留上一账期**，不会切到半成品。

### 2.2 查看概览

| 区块 | 含义 |
|---|---|
| 锁定预算 | 已提交公司/财务、本年不可调的 2026 预算 |
| 动态预估 | 按项目经理可调"预估交付完成日期"的最新快照 |
| 实际发生 | 当期 1–9 月实际确收 |
| 差异 | 动态 − 锁定（正=项目提前） |

均拆「新签 / 递延」。

### 2.3 查看月度分布

- 「锁定」视图：12 个月锁定预算柱状（来自财报逐月列）；
- 「动态」视图：有日期项按动态交付月分布；`已提交资料` 项在 **pipeline 桶**（无确定未来月份）；
- 下钻 IN_PIPELINE 某项 → 可看其在锁定口径下的逐月安排（对照用）。

### 2.4 明细与清单

明细表支持按分类（DUE_2026/IN_PIPELINE/FUTURE_YEAR/异常/终止…）、是否计入、新签递延筛选 + 分页。
风险提示区列出：跨年、异常、终止、未立项、日期缺失项。

### 2.5 导出

点「导出 Excel」→ 含 汇总 / 锁定逐月 / 动态逐月 / 明细 / 风险清单 多 Sheet。

### 2.6 Part B 状态

页面右上角数据源状态恒显示「ONES：待接入」。接入后此处变为可用，动态口径改由 ONES 实时驱动。

## 4. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 上传报"缺少 Sheet" | 财报被改名或缺工作表；用原始导出文件 |
| 恒等式校验警告 | 财报内 col27/逐月或 col40/41/42 被人工改动；核对差异行清单，与财务确认 |
| 某行落入"日期缺失" | col2 空或非标准日期；补标准日期后重传 |
| Part B 点了无数据 | 属预期，ONES 未接入；状态区显示 not_configured |
| 新账期数字与手工表对不上 | 先核对账期/年度是否选对，再看是否混入跨年项；以黄金基准逐项对 |

---

## 5. 数据与权限

- 仅读取上传的财报文件，写入本地 BDMS SQLite；
- v1.0 不访问 ONES、不发任何外部请求、不写回业务系统；
- 历史账期版本保留，重算只在同一账期内幂等重建。
