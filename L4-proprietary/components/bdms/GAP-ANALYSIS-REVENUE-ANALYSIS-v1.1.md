## 3. 根因（6 类）

1. **单位口径层缺失**：内部存元、导出分析层未转万元（设计 §10 已要求 `#,##0.00` 万元）
2. **透视引擎缺失**：差异分析 / 重拆履约 / 产线展开依赖 group-by 原因类别·合同·产线，builder 只出扁平快照
3. **历史台账逻辑缺失**：月度/履约记录是按期 append、去重重算的时序台账，现实现只出当期
4. **实际确收列未利用**：golden col29–42 有实际数，导入器只映射计划列 → 实际完成恒 0
5. **趋势行映射错位**：trend_builder row_index 与 golden 19 行模板偏移
6. **账期透传 bug**：202606 的履约记录被标 202609；差异标题写死 09
