# DESIGN-OUTLINE: CISSP 知识点学习训练引擎 - v1.0

## 1. 设计目标

轻量化 CLI 学习训练工具，支持 CISSP 八大领域知识点管理、随机抽题、错题复习、学习统计，帮助考生针对性强化薄弱知识点。

## 2. 架构原则

- **纯逻辑层**：L3 层只做核心逻辑，不负责持久化（可被上层调用）
- **零副作用**：所有 IO 操作隔离，核心逻辑可单元测试
- **最小依赖**：仅依赖 Python 标准库，可选第三方美化 CLI
- **可扩展**：领域、知识点、题目结构设计为可扩展，支持后续新增领域或题目类型

## 3. 整体架构

```
cissp-learning/
├── __init__.py                # 模块入口
├── cissp_engine.py            # 核心引擎
├── models.py                  # 数据模型
├── cli.py                     # CLI 交互入口
├── importer.py                # 导入导出工具
├── tests/                     # 单元测试

├── PRD-v1.0.md

├── DESIGN-DETAIL-v1.0.md

```

## 4. 模块划分

### 4.1 数据模型模块 (`models.py`)
定义核心数据结构：
- `KnowledgePoint`：知识点（领域ID、名称、描述、难度）
- `Question`：题目（知识点ID、题干、选项、正确答案、解析、难度）
- `AnswerRecord`：答题记录（题目ID、用户答案、是否正确、时间戳）
- `UserStats`：用户统计（各领域掌握情况、练习统计）

### 4.2 核心引擎模块 (`cissp_engine.py`)
提供核心业务逻辑：
- 加载知识库
- 随机抽题（支持领域过滤、难度过滤、错题仅）
- 提交答案，记录结果
- 更新统计数据
- 获取错题列表
- 生成统计报告

### 4.3 CLI 交互模块 (`cli.py`)
提供命令行交互入口：
- 主菜单
- 开始新练习
- 复习错题
- 查看统计
- 导入导出数据
- 退出程序

### 4.4 导入导出模块 (`importer.py`)
处理外部数据导入导出：
- 从 JSON 导入知识点和题目
- 从 CSV 导入批量题目
- 导出错题到 CSV
- 导出统计到 CSV

### 4.5 单元测试 (`tests/`)
覆盖核心逻辑：
- 抽题逻辑测试
- 统计计算测试
- 错题收集测试
- 导入导出测试

## 5. 依赖关系

### 5.1 内部依赖
- 无 L2 强制依赖，可选使用 L2 持久化模块（未来演进）
- 当前版本：数据存储使用 JSON 文件，纯标准库实现

### 5.2 外部依赖
- 强制依赖：Python 3.8+（标准库）
- 可选依赖：`rich`（美化 CLI 输出）

## 6. 演进方向

- 未来接入 L2 持久化模块，使用 SQLite 存储数据
- 支持多用户
- 支持 Web UI
- 支持答题卡导出打印
