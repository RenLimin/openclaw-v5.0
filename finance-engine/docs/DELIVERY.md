## 5. 已知限制

| 项 | 说明 | 优先级 |
|---|---|---|
| 无登录鉴权 | 当前版本无用户体系，建议前置 Nginx + Basic Auth | 高（上公网前必须） |
| L3 旧测试失败 | `test_fin001.py` 试算不平衡（模拟数据期初权益问题） | 中（不影响 L4） |
| 移动端未适配 | 桌面端优先，移动端可用但非最优 | 低 |
| 无多家庭切换 UI | 支持多家庭数据，但 Web 端需通过 API 切换 | 中 |
