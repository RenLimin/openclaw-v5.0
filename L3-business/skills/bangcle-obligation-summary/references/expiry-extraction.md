# 授权/维保到期日期提取规则

## 数据来源优先级（按可信度）

1. 子交付/子验收任务 `descriptionText` 中的明确日期区间
2. 授权开通类工作项（标题含"授权/license/账号开通"）的文本明细
3. 评论中的交付信息（如"授权文件…请提供客户本地使用" + 附件 .lic）
4. 附件文件名（license 文件、授权书等）

## 关键词清单

- 授权：`授权`、`license`、`Lic`、`账号`、`有效期`、`到期`、`起止`
- 维保：`维保`、`维护`、`服务期`、`质保`、`SLA`
- 版本相关（用于关联到期范围）：`版本`、`V5.`、`SP`

## 日期识别规则

- 区间写法：`YYYY-MM-DD ~ YYYY-MM-DD` / `YYYY-MM-DD 至 YYYY-MM-DD` / `X月X日-X月X日` → 取**结束日**为到期日。
- 单点写法：`到期：YYYY-MM-DD`、`截止 YYYY-MM-DD` → 直接取。
- 相对写法：`一年期/年付费` 无起止 → 标【缺失】，不推算。
- 多个日期并存：优先取授权/维保语义最近的日期；仍歧义则并列展示并注明。

## 输出格式

- 到期日统一 `YYYY-MM-DD`；附 `来源工作项 #编号 + 原文摘录（≤40字）`。
- 未提取到 → `【缺失】`；禁止用创建时间/计划时间冒充到期日。
- 标记：90 天内到期 ⚠️；已过期 ❌；>90 天 ✅。
