# 目标实现矩阵参考

> 本文件定义目标实现状态的映射规则与受限词表。
> 实现等级**仅可由规则映射**，不接受自由文本等级。

---

## 1. 目标实现等级（受控枚举）

| 等级 | 条件 | 适用 |
|---|---|---|
| 已实现 | 维保方向 done/total 全覆盖且工单闭环 | 维保类 |
| 基本实现 | 完成、仅 1 项集成类在途 | 维保类 |
| 部分实现/推进中 | 研发完成、系统测试多在途 | 维保类 |
| 能力已落地 | 采购类 部署+授权 done，验收手续在途 | 采购新建类 |
| 能力已建成 | 采购类 部署+授权 done，验收完成 | 采购新建类 |
| 往年已达成 | 能力建于 prior 周期、本周期仅维护 | 全类 |

## 2. 两类目标凭证

| 类型 | 方向 | evidence 来源 |
|---|---|---|
| 维保类 | 安全监测、合规检测、安卓/SDK 加固、应用安全测评、小程序加固、H5/API 安全 | 该方向 inPeriod 服务事项 done/total |
| 采购新建类 | 鸿蒙 NEXT 加固 | 「部署/授权」履约义务 `statusCategory=done` 记录 |

## 3. 映射规则

```
if direction in PROCUREMENT_DIRECTIONS:
    if done >= 2 and no in_progress: → 能力已建成
    elif done >= 1: → 能力已落地
    else: → 部分实现/推进中
else (维保类):
    if ratio >= 1.0 and no in_progress: → 已实现
    elif ratio >= 0.9 and len(in_progress) <= 1: → 基本实现
    else: → 部分实现/推进中
```

## 4. 在途归并

- 在途事项按方向归并，写**当前进展 + 处理安排**。
- **不编造承诺日期**。
- 在途事项单列，不混入已完成明细。
