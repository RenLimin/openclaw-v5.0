# 客户级 Program（项目集）治理操作手册

## 触发规则

- 同一客户 12 个月内 ≥2 个同类 POC，或长期 0 签约但持续投入 → 自动触发 Program 立项（PMO）。

## 四步落地

1. **建实体**：在 ONES 建"客户项目集"，挂入该客户全部相关项目；任命 1 名项目集经理（对结果负责）。建统一客户台账（决策链、规模口径、历次 POC 结论、累计投入、待办）。
2. **联合治理小组**：商务 Owner（决策链/价格/签约时点）+ 项目集经理（合并计划、资源闸门）+ 产研接口（适配工作量纳入产品路线）。
3. **合并作战计划**：交付物去重形成单一交付基线；里程碑对齐客户采购节奏（技术验证→遗留收口→商务锁价→签约转正式项目）；统一成本/收益视图。
4. **固化制度**：重复 POC 自动触发 Program；纳入 PMO 周/月报复盘直到签约或终止。

## 新 POC 立项闸门（答不上来不立项）

1. 相比上一次，本次新增的决策推进是什么？
2. 客户是否已明确签约路径与时间点？
3. 投入的适配工时谁买单 / 是否计入签约成本？

## 最小启动

- PMO 建 Program 并挂项目、任命经理；
- 开 1 次 30 分钟联合治理会，产出《统一作战计划+成本收益账》与《是否启动下一轮 POC 的决议》。
