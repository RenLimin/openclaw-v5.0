# health-management — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

为个人健康档案管理提供结构化管理能力，覆盖健康档案、体检、用药、指标、风险评估、健康计划六大领域。解决健康数据分散、长期跟踪困难、风险预警缺失的问题。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 健康档案 | 个人基本信息、生活方式、家族病史、过敏史 | 档案完整 |
| F2 | 体检管理 | 体检记录管理 | 记录可追溯 |
| F3 | 用药管理 | 药品名、剂量、频次 | 用药安全 |
| F4 | 指标跟踪 | 血压/心率/血糖等 | 趋势分析 |
| F5 | 风险评估 | 基于指标的风险评估 | 风险预警 |
| F6 | 健康计划 | 个性化健康计划 | 计划可执行 |

## 3. 用户故事

- **个人用户**: 创建档案 → 记录体检 → 跟踪指标 → 查看风险 → 执行计划
- **医生**: 查看患者档案 → 评估风险 → 调整计划

## 4. 验收标准

- 6 大领域全部覆盖
- Pydantic 数据验证
- 多租户隔离（tenant_id）
- 软删除机制
- Repository 模式封装

## 5. 依赖

- Python 3.12+
- Pydantic（数据验证）
- SQLite（默认存储）

## 6. 演进方向

- 短期：完善 6 大领域实现
- 中期：与 health-engine 计算引擎打通
- 长期：支持多存储后端
