# finance-engine — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

纯函数式理财计算引擎，覆盖复式记账、贷款核算、保险测算、利率服务、投资组合、理财建议六大领域。作为 L3 通用层，为 L4 专有业务（fin-l4）提供可复用的计算能力。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 复式记账 | 借贷记账、科目余额、试算平衡 | 借贷平衡 0 误差 |
| F2 | 贷款核算 | 4 种还款方式 + 提前还款模拟 | 还款计划 100% 正确 |
| F3 | 保险测算 | 现金价值/IRR/红利演示 | 计算精度 0.01% |
| F4 | 利率服务 | LPR/基准利率/利率转换/本地缓存 | 利率数据实时更新 |
| F5 | 投资持仓 | 收益/配置/再平衡 | 收益率计算正确 |
| F6 | 理财建议 | KPI 诊断/资产配置/债务优化 | 建议逻辑合理 |

## 3. 用户故事

- **L4 开发者**: 调用 fin001-006 引擎 → 获取计算结果 → 展示给用户
- **理财顾问**: 输入客户数据 → 获得诊断报告 → 给出建议

## 4. 验收标准

- 6 大引擎全部可用
- 纯函数式设计（零副作用）
- 单元测试全部通过
- L4 fin-l4 可正常调用

## 5. 依赖

- Python 3.12+
- 无外部 IO（除利率缓存外）

## 6. 演进方向

- 中期：增加更多金融计算模块
- 长期：支持实时数据源接入
