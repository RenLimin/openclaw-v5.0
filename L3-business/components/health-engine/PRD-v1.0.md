# health-engine — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

为健康管理提供纯函数式计算引擎，覆盖健康评分、生命体征、运动记录、营养摄入、睡眠数据、压力评估六大领域。作为 L3 通用层，为 health-management 等组件提供计算能力。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 健康评分 | 综合健康评分计算 | 评分逻辑合理 |
| F2 | 生命体征 | BMI/血压/心率分析 | 医学标准对照 |
| F3 | 运动记录 | 运动消耗计算 | 卡路里计算正确 |
| F4 | 营养摄入 | 营养成分分析 | 营养素统计正确 |
| F5 | 睡眠数据 | 睡眠质量评估 | 睡眠评分合理 |
| F6 | 压力评估 | 压力水平评估 | 评估逻辑合理 |

## 3. 用户故事

- **L4 开发者**: 调用 hlt001-006 引擎 → 获取计算结果 → 展示给用户
- **健康顾问**: 输入客户数据 → 获得健康评估 → 给出建议

## 4. 验收标准

- 6 大引擎全部可用
- 纯函数式设计（零副作用）
- 单元测试全部通过
- health-management 可正常调用

## 5. 依赖

- Python 3.12+
- 无外部 IO

## 6. 演进方向

- 短期：完成 hlt001_score 和 hlt002_vitals 的基础实现
- 中期：补齐六大模块的计算逻辑
- 长期：与 health-management 数据打通
