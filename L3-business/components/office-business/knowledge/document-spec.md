# 通用 Office 文档规范

## 1. 页面设置

### 1.1 页边距（A4）

| 边距 | 推荐值（厘米） | 说明 |
|---|---|---|
| 上边距 | 2.5 | 预留页眉空间 |
| 下边距 | 2.5 | 预留页脚空间 |
| 左边距 | 2.8 | 预留装订空间 |
| 右边距 | 2.5 | |

### 1.2 纸张方向
- 默认：纵向
- 宽表格/流程图：横向

## 2. 字体规范

### 2.1 中文字体
- **正文字体**：微软雅黑 (Microsoft YaHei)
- **标题字体**：微软雅黑加粗
- **特殊字体**：需要嵌入文件时标注，不使用小众字体

### 2.2 英文字体
- 默认：Times New Roman
- 代码：Consolas

### 2.3 字号

| 元素 | 字号推荐 |
|---|---|
| 一级标题 | 二号（22pt） |
| 二级标题 | 三号（16pt） |
| 三级标题 | 四号（14pt） |
| 正文 | 小四号（12pt） |
| 页眉页脚 | 小五号（9pt） |
| 表格注释 | 五号（10.5pt） |

## 3. 标题层级

| 层级 | 格式 | 编号示例 |
|---|---|---|
| 一级标题 | 居中，加粗 | 1 某某某 |
| 二级标题 | 左对齐，加粗 | 1.1 某某某 |
| 三级标题 | 左对齐，加粗 | 1.1.1 某某某 |
| 四级标题 | 左对齐 | （1）某某某 |

## 4. 段落规范

- **行间距**：固定值 22 磅（小四号字）
- **段前间距**：一级标题段前 1 行，二级标题段前 0.5 行
- **段后间距**：一级标题段后 1 行，二级标题段后 0.5 行
- **首行缩进**：正文首行缩进 2 字符

## 5. 列表规范

### 5.1 项目符号列表
- 一级：实心圆点 `•`
- 二级：空心圆点 `○`
- 三级：实心方块 `■`

### 5.2 编号列表
- 一级：`1.`
- 二级：`(1)`
- 三级：`①`

## 6. 表格规范

- **表头**：背景浅灰色，字体加粗，文字居中
- **表格线**：外框粗线（1.5磅），内框细线（0.5磅）
- **单元格内边距**：上下 0.1 厘米，左右 0.2 厘米
- **文字对齐**：表头居中，内容左对齐，数字右对齐
- **跨页表格**：每页重复表头

## 7. 页眉页脚

- **页眉**：文档标题/公司名称，居左
- **页脚**：页码居中，格式 `第 X 页 / 共 Y 页`
- **首页不同**：首页不显示页眉页脚

## 8. 图片规范

- **图片格式**：PNG（透明背景/截图）、JPG（照片）
- **图片分辨率**：不小于 96 DPI
- **图片对齐**：居中对齐，下方标注图号和说明
- **图号格式**：图 1-1 说明文字
