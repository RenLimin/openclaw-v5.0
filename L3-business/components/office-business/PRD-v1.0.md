# PRD-v1.0 — L3 企业办公模板库 (office-business)

> 层级：L3 业务通用能力
> 版本：v1.0
> 创建：2026-09-29

## 1. 需求背景

企业日常办公产出大量文档（合同、报表、项目汇报、会议纪要等），不同业务部门格式不统一、命名不规范，协作效率低。需要一套标准化的模板库，涵盖通用办公场景，满足团队协作统一规范。

## 2. 功能清单

| 功能 | 说明 | 优先级 |
|---|---|---|
| 分类模板体系 | 按文档类型/业务场景分类，覆盖 常见办公文档类型 | P0 |
| 统一格式规范 | 统一字体、页边距、标题样式、页眉页脚 | P0 |
| 版本化管理 | 模板更新有版本记录，兼容旧版 | P1 |
| 适配企业 VI | 内置企业 logo、配色、品牌元素占位 | P1 |

## 3. 约束与边界

- **范围**：仅模板资产，不包含生成引擎（生成逻辑由 L2 office-generation 提供）
- **类型**：docx/xlsx/pptx 原生 Office 格式
- **分类**：业务文档类（合同/协议、财务报表、项目交付）、通用办公类（会议纪要、项目周报、立项申请）

## 4. 验收标准

1. ✅ 至少覆盖 8 类常见办公文档
2. ✅ 所有模板符合统一格式规范
3. ✅ 分类索引清晰，可快速检索
4. ✅ 文档头包含版本变更记录占位
