# office-business — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

为办公业务提供标准化模板与角色定义，覆盖合同、报告、方案、演示文稿四大类文档模板，以及业务分析师、文档工程师两类 Agent 角色。解决文档风格不统一、Agent 角色边界模糊的问题。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 合同模板 | 销售合同、服务合同 | 2 个模板 |
| F2 | 报告模板 | 周/月/季/年度报告 | 4 个模板 |
| F3 | 方案模板 | 项目方案、技术方案 | 2 个模板 |
| F4 | 演示模板 | 项目状态、会议纪要 | 2 个模板 |
| F5 | 业务分析师角色 | IDENTITY + SOUL + AGENTS | 三件套完整 |
| F6 | 文档工程师角色 | IDENTITY + SOUL + AGENTS | 三件套完整 |
| F7 | 模板索引 | `index.json` 机器可读 | 11 个模板索引 |
| F8 | 变量系统 | 模板变量定义 | 变量可替换 |

## 3. 用户故事

- **销售**: 使用合同模板 → 快速生成合同 → 减少起草时间
- **项目经理**: 使用报告模板 → 统一报告格式 → 减少排版时间
- **Agent 开发者**: 使用角色定义 → 快速切换 Agent 人设

## 4. 验收标准

- 11 个模板完整（合同 2 + 报告 4 + 方案 2 + 演示 2 + 其他 1）
- 2 个角色三件套完整
- `index.json` 包含所有模板元信息
- 变量系统可正常工作

## 5. 依赖

- 纯 Markdown，无运行时依赖

## 6. 演进方向

- 短期：补齐 11 个模板
- 中期：增加角色库
- 长期：支持变量自动填充
