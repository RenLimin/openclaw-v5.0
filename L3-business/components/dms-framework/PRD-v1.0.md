# dms-framework — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

通用交付管理框架引擎，覆盖项目管理、里程碑、交付物、风险、RACI 等通用模块。在 delivery-management-framework 基础上扩展 SaaS 多租户、Web UI、Schema 管理等企业级能力。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 模块注册引擎 | 自动发现模块、解析依赖、管理生命周期 | 7 个业务模块自动注册 |
| F2 | 状态机引擎 | 显式状态定义和转移规则 | 12 种状态流转 |
| F3 | 事件总线 | 发布/订阅模式，模块间解耦通信 | 12 个订阅者 |
| F4 | RACI 责任矩阵 | Responsible/Accountable/Consulted/Informed 角色分配 | 4 角色完整覆盖 |
| F5 | SaaS 多租户 | TenantContext、AuthProvider、TenantRouter | 租户隔离验证 |
| F6 | Web UI | Jinja2 + 原生 CSS/JS 开箱即用 | 12 页面可访问 |
| F7 | Schema 管理 | 版本/diff/migrate 命令 | 迁移幂等测试通过 |
| F8 | 统一 CLI | 命令自动注册，`dms.py` 统一入口 | 14 子命令 |

## 3. 用户故事

- **项目经理**: 创建项目 → 分配成员 → 跟踪进度 → 管理交付物
- **团队成员**: 查看任务 → 更新状态 → 提交交付物
- **PMO**: 查看全局仪表板 → 监控进度 → 生成报告

## 4. 验收标准

- 7 个业务模块自动注册
- 12 种状态流转正确
- 12 个订阅者正常通信
- 租户隔离验证通过
- 14 个子命令全部可用
- 228 个测试全部通过

## 5. 依赖

- Python 3.12+
- Jinja2（Web UI）
- SQLite（默认存储）

## 6. 演进方向

- 短期：完善核心引擎稳定性
- 中期：扩展更多业务模块
- 长期：支持 PostgreSQL 存储后端
