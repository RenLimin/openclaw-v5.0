## 3. 人工操作手册（附录）

### 使用步骤

1. 安装依赖: `pip install jinja2`
2. 启动 CLI: `python3 dms.py --help`
3. 创建项目: `python3 dms.py project create`
4. 访问 Web UI: 启动后访问对应端口
