# PRD: CISSP 知识点学习训练引擎 - v1.0

## 1. 需求概述

### 1.1 背景
为 CISSP 考生提供结构化知识点梳理、随机抽题训练、错题复习、知识点统计的轻量化学习训练工具，帮助考生针对性强化薄弱知识点，提高备考效率。

### 1.2 目标
- 提供结构化的 CISSP 八大领域知识点存储与检索
- 支持随机抽题（按领域/难度筛选）
- 支持错题记录与复习
- 提供学习统计（掌握率、练习次数、薄弱领域）
- 纯 Python 实现，依赖少，易扩展

### 1.3 用户
CISSP 备考考生，支持本地单用户使用。

## 2. 功能清单

### 2.1 核心功能
| 功能ID | 功能描述 |
|--------|----------|
| F1 | 知识点管理：按八大领域（安全与风险管理、资产安全、安全架构与工程、通信与网络安全、身份与访问管理、安全评估与测试、安全运营、软件开发安全）分类存储知识点 |
| F2 | 题目管理：每个知识点绑定对应练习题（单选/多选），包含题目、选项、答案、解析 |
| F3 | 随机抽题训练：支持按领域、难度筛选，随机生成练习卷 |
| F4 | 答题记录：记录用户每次答题结果，自动分类错题 |
| F5 | 错题复习：只抽取错题进行强化训练 |
| F6 | 统计分析：展示各领域知识点掌握率、练习次数，定位薄弱点 |
| F7 | CLI 交互入口：命令行交互，操作简单，无需图形界面 |

### 2.2 辅助功能
| 功能ID | 功能描述 |
|--------|----------|
| A1 | 导入知识点/题目：支持从 JSON/CSV 批量导入 |
| A2 | 导出学习记录：支持导出错题和统计数据到 CSV |
| A3 | 难度分级：题目支持按易/中/难三级分级 |
