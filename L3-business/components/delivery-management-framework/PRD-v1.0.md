# delivery-management-framework — 产品需求文档 (PRD)

> 版本: v1.0 · 日期: 2026-09-28 · 作者: Rex/Jerry

## 1. 产品概述

为交付管理提供领域驱动设计（DDD）骨架，包含项目管理、RACI 矩阵、状态机、事件总线等核心能力。解决交付流程中职责不清、状态混乱、模块耦合的问题。

## 2. 功能清单

| # | 功能 | 描述 | 验收标准 |
|---|---|---|---|
| F1 | 项目管理 | 项目 CRUD + 成员管理 | 项目完整生命周期 |
| F2 | 工作项管理 | 任务/缺陷/风险跟踪 | 工作项状态流转 |
| F3 | RACI 矩阵 | 责任分配与查询 | 4 角色完整 |
| F4 | 状态机 | 显式状态定义和转移 | 12 种状态 |
| F5 | 事件总线 | 模块间解耦通信 | 发布/订阅模式 |
| F6 | 变更日志 | 操作审计追踪 | 完整审计链 |

## 3. 用户故事

- **项目经理**: 创建项目 → 分配成员 → 跟踪进度 → 监控风险
- **团队成员**: 查看任务 → 更新状态 → 记录工时
- **PMO**: 查看全局仪表板 → 监控进度 → 生成报告

## 4. 验收标准

- DDD 分层架构完整
- BaseModel 统一 CRUD
- ModuleRegistry 自动发现
- EventBus 正常通信
- 状态机转移正确
- RACI 分配正确

## 5. 依赖

- Python 3.12+
- SQLite（默认存储）

## 6. 演进方向

- 短期：完善核心引擎
- 中期：扩展更多业务模块
