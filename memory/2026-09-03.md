5. 第三轮对齐：确认统一入口 + 热插拔 + 合同审批是子模块

### 核心设计决策
- **L3 是框架，不是系统**：提供引擎 + 扩展点，L4 通过配置覆盖实例化
- **统一入口**：`dms <module> <command>` 单一 CLI，`delivery.db` 单一数据库
- **热插拔**：ModuleRegistry + ModuleManifest 动态注册
- **RACI 松耦合**：能力原子（12 个）+ 角色模板（6 个）+ 项目级动态分配
- **统一工作项模型**：work_items + type 区分 task/milestone/deliverable/risk/decision
- **合同审批是子模块**：SCA-001 作为 contract 模块注册，不是平级
- **L4 扩展不改 L3**：proprietary_metadata JSON + 配置覆盖

## 15:25-16:00: 交付管理框架深度调研 — 业界最佳实践对比

### 调研来源
| 来源 | 类型 | 关键发现 |
|------|------|---------|
| **Salesforce** | 商业 SaaS | Metadata-driven 架构：MT_Objects/MT_Fields/MT_Data + flex columns；所有租户共享物理表；custom fields 存为 metadata 而非真实列 |
| **Jira (Atlassian)** | 商业 SaaS | 每个租户独立 PostgreSQL 数据库（database-per-tenant）；Tenant Context Service (TCS) 逻辑隔离；Workflow Scheme 关联 workflow ↔ issue type |
| **ONES** | 商业 SaaS（国产） | 项目管理+需求+任务+工时+文档+测试一体化；云部署用 RDS MySQL + Kafka |
| **Plane.so** | 开源 (38.7k⭐) | Workspace→Project→Module→Issue；Schema 与 Work 分离（schema diff/push）；States 5 标准分组 |
| **PostgreSQL RLS** | 数据库原生 | Row-Level Security = 数据库级租户隔离安全网；session variable `current_tenant` + policy |
| **Hybrid Tenancy** | 2026 趋势 | 混合隔离：小租户共享 schema，大租户独立 schema/库；随升级迁移 |

### 我们设计的优势
1. ✅ 框架+实例化模式（对齐 Salesforce 的 metadata-driven 思想）
2. ✅ ModuleRegistry 热插拔（对齐 WordPress/VS Code 插件模式）
3. ✅ RACI 松耦合（对齐 PMBOK 标准）
4. ✅ 统一工作项模型（对齐 OpenProject Work Package）
5. ✅ SaaS-ready tenant_id（对齐业界主流）

### 发现的优化空间（6 项）
1. ⚠️ **Metadata-driven 自定义字段** — Salesforce/Jira 支持租户自定义字段，我们的 proprietary_metadata JSON 不够结构化
2. ⚠️ **Hybrid 多租户策略** — Jira 用 database-per-tenant，2026 主流是 hybrid（共享+独立混合）
3. ⚠️ **PostgreSQL RLS 安全网** — 应用层 tenant_id 过滤可能被遗忘，RLS 是数据库级强制保障
4. ⚠️ **Plane Schema/Work 分离** — Plane 的 schema 版本控制（diff/push）是亮点
5. ⚠️ **Jira Workflow Scheme** — workflow 按 issue type 关联，比我们当前的状态机更灵活
6. ⚠️ **租户级迁移** — 混合模式下需要租户在共享↔独立间迁移的能力

## 15:25-16:10: 深度调研 + 6 项业界优化落地

### 调研来源
- Salesforce: metadata-driven (MT_Objects/MT_Fields/flex columns), multi-tenant shared schema
- Jira/Atlassian: database-per-tenant, Tenant Context Service, Workflow Scheme
- ONES: 项目管理+需求+任务+工时+文档+测试, RDS MySQL + Kafka
- Plane.so: Schema/Work 分离, schema diff/push, States 5 标准分组
- PostgreSQL RLS: 数据库级强制租户隔离
- Hybrid Tenancy (2026 trend): 小租户共享 + 大租户独立

### 6 项优化全部采纳
1. Metadata-driven 自定义字段 → custom_fields 元数据表 (Salesforce)
2. Hybrid 多租户路由 → TenantRouter 三级路由 (Jira + 2026)
3. PostgreSQL RLS → 应用层 + 数据库层双重保障
4. Workflow Scheme → Workflow ↔ 业务类型映射 (Jira)
5. Schema diff/migrate → schema_version + CLI (Plane)
6. 租户迁移工具 → 共享 ↔ 独立一键迁移
