# 个人/家庭财务仪表盘设计

## 1. 摘要
家庭财务仪表盘的核心目标是让用户**一眼看懂家庭财务健康状况**，快速获取关键指标，方便日常管理。设计上偏向**数据密度、信任感、可读性**。

## 2. 核心信息层级

### 首页第一屏（必须展示）
1. **四大核心指标**：家庭净值、总资产、总负债、资产负债率
   - 用统计卡片展示
   - 正负金额语义化颜色（绿色正/红色负）

2. **两个概览表**：账户概览、最近交易
   - 两栏网格布局
   - 账户展示名称 + 余额，方便快速查看流动性
   - 最近交易展示日期 + 摘要 + 金额，让用户知道最近花了什么

### 二级页（按分类）
- 预算：分类预算 + 进度条 + 状态
- 贷款：贷款列表 + 本金 + 利率 + 期限
- 保险：保单号 + 名称 + 类型 + 保额 + 保费 + 状态
- 投资：投资组合 + 持仓 + 收益
- 报表：现金流、资产负债表、收支统计
- 建议：财务健康评分、资产配置建议、保障缺口

## 3. 设计风格偏好

### 信任感
- 清晰的数据层次，大数字醒目
- 干净的留白，避免拥挤
- 统一的字体和颜色系统，不花哨
- 高对比度文字，保证长时间阅读舒适

### 数据可读性
- 金额数字右对齐，使用 `tabular-nums` 保证对齐
- 千分位分隔，方便快速读取大数
- 语义化颜色：绿色表示正/健康，红色表示负/超支/危险

### 移动端友好
- 单列布局，适合单手操作
- 导航横向滚动，避免折叠/汉堡菜单
- 点击目标 ≥ 44×44px，方便触摸

## 4. 交互模式

### 导航
- 顶栏导航，所有页面入口可见，不需要点击汉堡菜单
- 当前页面高亮，用户知道自己在哪

### 表格
- 行 hover 背景变浅，方便阅读
- 重要数据（金额/净值）加粗

### 预算
- 进度条展示使用占比，颜色区分状态（正常/预警/超支）
- 显示日均可用，方便用户调整消费

## 5. 数据可视化建议

### 优先文本表格
- 财务数据精确性 > 图表可视化
- 精确数字比饼图/柱状图更重要
- 首页只展示文字和卡片，图表放在报表页

### 报表页可增加
- 月度收支柱状图
- 资产配置饼图
- 净值增长曲线图

## 6. 可访问性特别注意
- 金额对比度足够（深色文字浅色背景）
- 语义颜色不唯一，配合文字/进度条表示状态
- 键盘可导航所有链接和按钮

## 7. 适用场景
- 本地个人理财系统
- 家庭财务共享
- 低频率日常管理（每天看几次，不是一直用）
