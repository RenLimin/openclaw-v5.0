# IN-003: 家庭保险配置方法论

## 概述

保险是家庭财务安全网。配置保险的目标不是"越多越好"，而是**用合理的保费，覆盖家庭无法承受的风险**。

## 保险配置的基本原则

### 1. 先大人后小孩

大人是家庭经济支柱，小孩的保费来源依赖大人。大人保障做足了，小孩才有保障。

### 2. 先保障后理财

保障型保险（重疾/医疗/寿险/意外）优先级远高于理财型保险（年金/分红/万能）。不要把保险当投资。

### 3. 保额优先于保障期限

**保额够不够比保多久更重要**。50 万保额保 30 年，优于 10 万保额保终身。

### 4. 家庭支柱优先

**家庭收入占比越高的人，越需要高保额**。双收入家庭按收入比例分配保费和保额。

### 5. 保费预算：年收入 5%-10%

总保费控制在家庭年收入的 5%-10%。超过 10% 可能影响生活质量，低于 5% 可能保障不足。

## 四大基础险种

### 1. 重疾险 (Critical Illness)

**作用**：确诊约定的重大疾病，一次性赔付保额。

**为什么需要**：
- 弥补患病后的收入损失（2-5 年）
- 支付治疗费用（社保报销外的部分）
- 康复期营养费、护理费

**保额建议**：
```
重疾险保额 = 年收入 × 3~5 年 + 50 万治疗费
```

- 经济支柱：50-100 万
- 配偶：30-50 万
- 小孩：30-50 万

**保障期限**：优先保到 70 岁，预算充足保终身。

### 2. 医疗险 (Medical)

**作用**：报销住院/手术/特殊门诊等医疗费用。

**为什么需要**：社保报销有起付线、封顶线、自费药限制。百万医疗可以覆盖大额医疗支出。

**类型**：

| 类型 | 保额 | 免赔额 | 价格 | 适用 |
|---|---|---|---|---|
| 百万医疗险 | 100-400 万 | 1 万 | 几百/年 | 绝大部分人 |
| 中端医疗险 | 100-200 万 | 0-5000 | 几千/年 | 追求更好就医体验 |
| 高端医疗险 | 千万级 | 0 | 几万~几十万 | 高净值人群 |

### 3. 定期寿险 (Term Life)

**作用**：身故/全残赔付。保障家庭经济支柱突然倒下后的房贷、子女教育、老人赡养。

**保额建议**：
```
寿险保额 = 房贷余额 + 子女教育金 + 老人赡养费 + 5 年生活费
```

简单算法：**年收入 × 10**。

**保障期限**：保到 60 岁或 70 岁（覆盖主要收入期）。

**谁最需要**：
- 家庭经济支柱 ✅ 必须
- 全职配偶 ✅ 需要（家务劳动价值）
- 小孩 ❌ 不需要（没有收入责任）

### 4. 意外险 (Accident)

**作用**：意外身故/伤残赔付 + 意外医疗报销。

**为什么需要**：
- 意外险性价比极高（100 万保额仅 300 元左右）
- 伤残按等级赔付（1-10 级，10%-100%）
- 意外医疗可以覆盖日常小意外

**保额建议**：50-100 万。

## 家庭保险配置清单

### 双收入家庭（夫+妻+1孩，年收入 40 万）

| 成员 | 重疾险 | 医疗险 | 寿险 | 意外险 | 年保费 |
|---|---|---|---|---|---|
| 丈夫（主力） | 50 万/30 年 | 300 万 | 150 万/60 岁 | 100 万 | ~8,000 |
| 妻子 | 30 万/30 年 | 300 万 | 100 万/60 岁 | 100 万 | ~6,000 |
| 孩子 | 30 万/30 年 | 300 万 | - | 50 万 | ~3,000 |
| **合计** | | | | | **~17,000** |

保费占收入比例：**4.25%**，在合理范围内。

## 常见误区

### ❌ 误区 1：买了保险就万事大吉

保险只是风险管理的手段之一，还需要：
- 应急准备金（3-6 个月生活费）
- 投资增值
- 职业发展

### ❌ 误区 2：返还型保险"不花钱"

返还型保险保费是消费型的 2-3 倍，多交的保费几十年后返还，实际收益率往往不足 2%。

### ❌ 误区 3：给孩子买终身寿险

孩子没有家庭收入责任，不需要寿险。终身寿险更适合遗产规划，不是普通家庭需要的。

### ❌ 误区 4：一张保单保所有

"大而全"的保单往往每项保额都不够，且价格贵。分开买更灵活、保额更高、保费更低。

### ❌ 误区 5：老人也买重疾险

50 岁以上买重疾险：
- 保费极高（可能保费倒挂）
- 健康告知严格
- 不如直接买医疗险 + 防癌险

## 保险配置步骤

```
1. 风险评估：家庭结构、收入、负债、健康状况
2. 确定预算：年收入 5%-10%
3. 按优先级配置：意外险 → 医疗险 → 重疾险 → 寿险
4. 选产品：对比条款、保额、保费、公司
5. 健康告知：如实告知，避免理赔纠纷
6. 定期复盘：每 3-5 年根据家庭变化调整
```

## 在 FIN-L4 中的实现

- **保单管理**：录入所有家庭成员的保单，统一查看
- **现金价值**：按年计算现金价值表，了解退保损失
- **保障缺口分析**：自动计算各险种保额缺口，给出建议
- **退保测算**：对比继续持有 vs 退保的损失
