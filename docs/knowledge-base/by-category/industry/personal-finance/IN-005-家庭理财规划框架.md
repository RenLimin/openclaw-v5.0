# IN-005: 家庭理财规划完整框架

## 概述

家庭理财不是"炒股票"或"买基金"，而是一个系统性工程。目标是**在不同人生阶段，合理分配有限的财务资源，实现家庭生活目标的最大化**。

## 家庭理财的五大目标

| 优先级 | 目标 | 说明 |
|---|---|---|
| 1️⃣ | 财务安全 | 有应急金、有保险、不负债（除房贷外） |
| 2️⃣ | 生活品质 | 日常开销、子女教育、休闲娱乐 |
| 3️⃣ | 财富积累 | 买房、投资增值、净资产增长 |
| 4️⃣ | 长期保障 | 养老规划、子女教育金 |
| 5️⃣ | 财务自由 | 被动收入 > 支出，不用为钱工作 |

## 家庭理财七步法

### 第一步：财务体检

**搞清楚现状**——你现在在哪？

- 资产负债表：有多少资产？多少负债？净资产多少？
- 收支流水：每月收入多少？花多少？存多少？
- 保障状况：有没有保险？够不够？
- 信用状况：征信如何？

**关键指标**：

| 指标 | 健康值 | 说明 |
|---|---|---|
| 储蓄率 | ≥ 20% | 月储蓄 / 月收入 |
| 资产负债率 | < 50% | 总负债 / 总资产 |
| 房贷收入比 | < 30% | 月供 / 月收入 |
| 应急金月数 | 3-6 个月 | 流动资产 / 月支出 |
| 保费收入比 | 5%-10% | 年保费 / 年收入 |

### 第二步：设定目标

**明确你要去哪**——SMART 原则

- **S**pecific：具体（不是"攒钱"，是"买房首付 100 万"）
- **M**easurable：可量化（金额、时间）
- **A**chievable：可实现
- **R**elevant：相关（和人生目标一致）
- **T**ime-bound：有时限

**常见目标分类**：
- 短期（1 年内）：旅行、换手机、应急金
- 中期（1-5 年）：买车、装修、首付
- 长期（5 年以上）：买房、子女教育、退休

### 第三步：建立安全垫

**在追求收益前，先确保不会被打垮**

1. **应急金**：3-6 个月生活费，放在货币基金/活期
2. **保险配置**：重疾+医疗+寿险+意外（详见 IN-003）
3. **避免高息负债**：信用卡全额还、不碰网贷

### 第四步：日常收支管理

**收入 - 储蓄 = 支出**，而不是反过来

| 方法 | 说明 | 适合人群 |
|---|---|---|
| 50/30/20 法则 | 50%必需 + 30%想要 + 20%储蓄 | 新手入门 |
| 信封预算法 | 每个类别分配固定金额，花完为止 | 控制消费 |
| 零基预算 | 每一分钱都有归属，收入-支出=0 | 精细管理 |
| 自动储蓄 | 发工资自动转存储蓄账户 | 懒人首选 |

### 第五步：资产配置

**让钱为你工作**——详见 IN-004

- 根据风险承受能力和投资期限确定配置比例
- 分散投资：不同资产、不同行业、不同地区
- 定期再平衡，保持纪律

### 第六步：专项规划

#### 子女教育金规划

- 时间确定（18 岁上大学），金额大
- 投资期限长（从出生算 18 年）
- 建议：教育金保险 + 指数基金定投

#### 养老规划

- **越早开始越好**（复利效应）
- 替代率：退休后收入 / 退休前收入，目标 70%-80%
- 三支柱：社保养老金 + 企业年金 + 个人储蓄

#### 购房规划

- 首付准备：房价 × 30%（首套）
- 月供控制：≤ 月收入 30%
- 总房价：年收入 × 5-8 倍（合理范围）

### 第七步：定期检视与调整

**市场在变，人生在变，理财计划也要变**

- **月度**：收支对账、预算执行
- **季度**：投资组合检视
- **年度**：全面财务体检，调整目标和配置
- **重大事件**：结婚、生子、换工作、买房、继承……重新规划

## 家庭生命周期与理财重点

| 阶段 | 年龄 | 特点 | 理财重点 |
|---|---|---|---|
| 单身期 | 22-30 | 收入低、负担轻 | 提升职业、积累本金、学习投资 |
| 新婚期 | 28-35 | 双收入、买房 | 买房规划、保险配置、生育准备 |
| 育儿期 | 30-45 | 上有老下有小 | 子女教育金、提高保额、加速积累 |
| 成熟期 | 45-55 | 收入顶峰、支出减少 | 加速养老储备、降低风险敞口 |
| 退休期 | 55+ | 收入减少、医疗增加 | 保本为主、现金流规划、遗产规划 |

## 财务健康诊断清单

### 🟢 优秀（全部满足）

- [ ] 有 6 个月以上应急金
- [ ] 保险保额充足（寿险 10 倍收入、重疾 5 倍收入）
- [ ] 储蓄率 ≥ 30%
- [ ] 房贷月供 < 收入 25%
- [ ] 有明确的投资计划且严格执行
- [ ] 有养老规划和子女教育规划

### 🟡 及格（大部分满足）

- [ ] 有 3 个月应急金
- [ ] 有基础保险（医疗险+意外险）
- [ ] 储蓄率 ≥ 15%
- [ ] 房贷月供 < 收入 40%
- [ ] 有一定投资（基金/股票/理财）
- [ ] 大致知道钱花哪了

### 🔴 不及格（需要改进）

- [ ] 月光，没有储蓄
- [ ] 没有任何保险
- [ ] 信用卡经常分期或最低还款
- [ ] 不知道自己有多少钱、欠多少钱
- [ ] 用网贷/消费贷维持生活
- [ ] 借钱投资（杠杆炒股/炒币）

## 常见误区

### ❌ 误区 1：理财 = 投资 = 赚钱

理财是**全面的财务规划**，投资只是其中一环。保障、节税、传承、消费规划都是理财。

### ❌ 误区 2：等有钱了再理财

**钱少更需要理财**——正因为钱少，每一分钱都要花在刀刃上。从记账、储蓄开始。

### ❌ 误区 3：追求高收益

高收益必然伴随高风险。**不懂的东西不要碰**——P2P、虚拟币、原始股……你看上的是利息，人家看上的是本金。

### ❌ 误区 4：频繁操作

交易越频繁，收益越低（手续费+滑点+情绪化决策）。长期持有 > 频繁买卖。

### ❌ 误区 5：把所有钱投进股市

**永远不要用短期要用的钱做长期投资**。如果 3 年内要用钱，不要投股票。

## 在 FIN-L4 中的实现

- **资产负债表**：自动计算资产、负债、净资产
- **收支汇总**：收入/支出分类统计
- **预算管理**：分类预算 + 执行追踪 + 超支预警
- **保险管理**：保单统一管理 + 保障缺口分析
- **投资分析**：盈亏分析 + 资产配置 + 再平衡建议
- **理财建议**：健康诊断 + 债务优化 + 配置建议
