# 选品策略与市场调研

## 选品方法论

### 选品四维评估

| 维度 | 说明 | 工具 |
|------|------|------|
| 市场需求 | 搜索量、销量趋势 | Jungle Scout、Google 趋势 |
| 竞争程度 | 卖家数量、Review 数 | Helium 10、Keepa |
| 利润空间 | 售价 - 采购 - 物流 - 佣金 | 利润计算器 |
| 合规风险 | 认证要求、知识产权 | 认证数据库、商标查询 |

### 选品策略

| 策略 | 说明 |
|------|------|
| 蓝海选品 | 高需求+低竞争 |
| 季节性选品 | 节日/季节驱动（圣诞/夏季） |
| 跟卖风险 | 避免品牌备案产品 |
| 轻小商品 | 降低物流成本 |

## 市场调研工具

| 工具 | 用途 |
|------|------|
| Jungle Scout | 机会分数、销量估算 |
| Helium 10 | 关键词研究、竞品分析 |
| Keepa | 价格历史、促销追踪 |
| Google 趋势 | 搜索趋势、地域分布 |
| SimilarWeb | 独立站流量分析 |

## 本地化需求洞察

| 维度 | 说明 |
|------|------|
| 气候 | 季节性需求（北欧冬季/东南亚夏季） |
| 文化 | 颜色偏好、尺寸标准、使用习惯 |
| 法规 | 产品标准、标签要求、禁售品 |
| 价格带 | 不同市场的消费能力差异 |

## 数据驱动决策

| 指标 | 说明 |
|------|------|
| 月销量 | 市场容量估算 |
| Review 增速 | 产品生命周期判断 |
| BSR（Best Seller Rank） | 品类排名趋势 |
| 关键词搜索量 | 需求量化 |
| 转化率 | Listing 质量评估 |
