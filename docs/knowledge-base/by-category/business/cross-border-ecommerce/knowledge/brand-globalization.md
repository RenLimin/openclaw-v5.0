# 品牌出海与 DTC 独立站

## DTC 独立站 vs 平台

| 维度 | DTC 独立站 | 第三方平台 |
|------|-----------|-----------|
| 品牌控制 | 完全控制 | 受限 |
| 数据所有权 | 完整用户数据 | 受限 |
| 流量 | 需自行获取 | 平台流量 |
| 成本 | 建站+营销 | 佣金+广告 |
| 灵活性 | 高 | 受平台规则限制 |

## 独立站建站

| 工具 | 特点 |
|------|------|
| Shopify | 生态成熟、App 丰富 |
| Shoplazza（店匠） | 中文友好、国内卖家友好 |
| WooCommerce | WordPress 插件、灵活 |
| BigCommerce | 企业级、无交易费 |

## 社交媒体营销

| 平台 | 特点 | 适用 |
|------|------|------|
| Facebook/Instagram | 视觉营销、精准定向 | 品牌认知 |
| TikTok | 短视频+直播、病毒传播 | 年轻群体 |
| Pinterest | 图片搜索、长尾流量 | 家居/时尚 |
| YouTube | 长视频、深度内容 | 产品评测 |

## 内容本地化

| 维度 | 说明 |
|------|------|
| 语言 | 母语级翻译，非机翻 |
| 文化 | 避免文化禁忌（颜色/数字/符号） |
| 节日 | 本地节日营销（斋月/圣诞/春节） |
| KOL | 本地达人合作，非国内网红 |

## 站外引流策略

| 策略 | 说明 |
|------|------|
| Google Ads | 搜索+购物广告，精准流量 |
| Meta Ads | 兴趣定向+再营销 |
| Deal 促销 | Lightning Deal、7-Day Deal |
| 红人营销 | Creator Marketplace、MCN 合作 |
