# 国际物流与海外仓

## 物流模式对比

| 模式 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| FBA | Amazon 代发货 | 流量加权、Prime 标 | 仓储费、IPI 限制 |
| FBM | 卖家自发货 | 自主控制 | 无 Prime 标 |
| 第三方海外仓 | 代发货服务商 | 多平台通用 | 管理成本高 |
| 海外仓+平台仓 | 混合模式 | 灵活调配 | 管理复杂 |

## 头程物流

| 方式 | 时效 | 成本 | 适用 |
|------|------|------|------|
| 海运整柜（FCL） | 20-40天 | 最低 | 大批量、不紧急 |
| 海运散货（LCL） | 25-45天 | 低 | 小批量 |
| 空运/空派 | 5-10天 | 高 | 紧急补货 |
| 中欧班列 | 15-25天 | 中 | 欧洲方向 |
| 国际快递 | 3-5天 | 最高 | 样品/急件 |

## 库存管理

| 指标 | 说明 | 目标 |
|------|------|------|
| IPI（库存绩效指标） | Amazon 仓储健康度 | > 400 |
| 库存周转天数 | 从入库到售出天数 | < 60天 |
| 滞销率 | 长期未售出占比 | < 10% |
| 缺货率 | 断货时间占比 | < 2% |

## 物流成本核算

| 成本项 | 说明 |
|------|------|
| 头程运费 | 工厂 → 海外仓 |
| 仓储费 | 海外仓/月租 + 操作费 |
| 尾程配送费 | 海外仓 → 客户 |
| 关税/进口税 | 按品类和目的地 |
| 退货处理费 | 退货检测/换标/销毁 |

**物流成本通常占售价 15-30%，直接影响定价策略。**
