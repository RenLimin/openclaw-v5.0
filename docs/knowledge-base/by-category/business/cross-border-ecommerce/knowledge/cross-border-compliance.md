# 跨境合规与税务

## 产品合规

| 市场 | 认证 | 适用 |
|------|------|------|
| 欧盟 | CE 标志、RoHS、REACH | 电子/玩具/化妆品 |
| 美国 | FCC（电子）、CPSC（儿童）、FDA（食品/化妆品） | 多品类 |
| 日本 | PSE（电子）、PSC（儿童） | 电子/玩具 |
| 东南亚 | NPRA（泰国化妆品）、BPOM（印尼） | 化妆品/食品 |

## 平台合规

| 规则 | 说明 |
|------|------|
| 知识产权 | 商标、专利、版权，侵权可导致账户关闭 |
| 产品安全 | 禁止销售不安全产品 |
| 评论政策 | 禁止刷评、诱导好评 |
| 类目审核 | 部分品类需额外审核（食品/化妆品/医疗） |

## 税务合规

| 税种 | 说明 | 阈值 |
|------|------|------|
| VAT（欧盟） | 增值税 | 远程销售阈值 €10,000-35,000 |
| GST（东南亚/澳新） | 商品服务税 | 各国不同 |
| 销售税（美国） | Sales Tax | 各州不同 |
| 关税 | 进口关税 | 按 HS Code |

## 违规成本

| 违规 | 后果 |
|------|------|
| 无 CE/FCC | 产品扣押、罚款 |
| 未注册 VAT | 销售冻结、补缴+罚金 |
| 知识产权侵权 | 账户关闭、法律诉讼 |
| 刷单刷评 | 账户永久封禁 |

**违规成本平均高达年销售额 10-20%。**
