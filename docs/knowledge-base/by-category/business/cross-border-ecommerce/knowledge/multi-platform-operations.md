# 多平台运营策略

## 平台对比

| 平台 | 核心市场 | 特点 | 适合 |
|------|----------|------|------|
| Amazon | 北美/欧洲/日本 | 品牌化、FBA 物流、高客单价 | 品牌卖家 |
| Shopee | 东南亚/拉美 | 价格敏感、社交电商、低客单价 | 铺货型卖家 |
| Lazada | 东南亚 | 品牌化、LazMall 入驻 | 品牌卖家 |
| AliExpress | 全球 | 价格竞争、信用保障 | 工厂型卖家 |
| Temu | 北美/欧洲 | 全托管/半托管、极致性价比 | 供应链型卖家 |
| TikTok Shop | 海外 | 短视频+直播、内容驱动 | 内容型卖家 |

## Amazon 运营核心

| 能力 | 说明 |
|------|------|
| Listing 优化 | 标题、五点描述、A+ 页面、关键词 |
| Buy Box 争夺 | 价格、配送、卖家评级 |
| 广告 | SP/SB/SD、ACOS/TACOS 控制 |
| FBA 管理 | IPI 评分、库存绩效、长期仓储费 |
| 品牌分析 | 搜索词报告、市场篮子分析 |

## 多平台运营策略

| 策略 | 说明 |
|------|------|
| 平台差异化 | 同一产品在不同平台做本地化调整 |
| 库存分配 | 根据平台销量和物流时效分配库存 |
| 统一数据 | 多平台数据汇总，统一决策 |
| 风险分散 | 不依赖单一平台，降低政策风险 |
