# PMBOK 8th：7 个绩效域

> PMBOK 第 8 版定义了 7 个绩效域，代表项目管理的核心关注领域。

## 概述

绩效域是项目管理中需要持续关注和实践的领域。
7 个绩效域相互关联，项目经理需要在整个项目生命周期中平衡它们。

## 7 个绩效域

### 1. 干系人（Stakeholders）
识别、分析和管理影响项目或被项目影响的个人和组织。

**关键活动**：干系人识别、分析、参与计划、沟通管理
**成功标志**：干系人积极参与，期望得到有效管理

### 2. 团队（Team）
建立高效的项目团队，包括领导力、团队发展和冲突管理。

**关键活动**：团队组建、发展、领导力、冲突解决
**成功标志**：团队协作高效，成员有安全感和归属感

### 3. 项目生命周期（Project Lifecycle）
选择和管理适合项目特点的开发方法（预测型/适应型/混合型）。

**关键活动**：方法选择、阶段定义、里程碑规划
**成功标志**：生命周期方法与项目特征匹配

### 4. 规划（Planning）
制定和维护项目计划，包括范围、进度、成本、资源等。

**关键活动**：范围定义、WBS、进度计划、成本估算、资源规划
**成功标志**：计划可行、干系人认可、有适当的详细程度

### 5. 项目工作（Project Work）
执行项目工作，管理团队、采购和信息流。

**关键活动**：任务分配、执行跟踪、采购管理、信息分发
**成功标志**：工作按计划推进，问题及时解决

### 6. 交付（Delivery）
确保项目交付物满足需求和验收标准。

**关键活动**：需求管理、验收标准定义、质量控制
**成功标志**：交付物被干系人接受

### 7. 不确定性（Uncertainty）
识别、评估和应对项目风险和不确定性。

**关键活动**：风险识别、定性/定量分析、应对规划、监控
**成功标志**：风险在可控范围内，有应急预案

## 绩效域间关系

```
干系人 ←→ 团队 ←→ 项目生命周期
   ↕           ↕           ↕
规划 ←→ 项目工作 ←→ 交付
   ↕                       ↕
   └────── 不确定性 ────────┘
```
