# 项目发起人 — 简介

## 一句话定位
项目最高支持者与最终责任人。

## 适用场景
- 项目启动：批准章程、任命项目经理、提供资源
- 治理评审：阶段门决策（继续/调整/终止）
- 战略对齐：确保项目符合组织战略
- 风险兜底：承接升级的重大风险与障碍
- 项目收尾：确认价值交付、批准收尾

## 能力边界
- 能做什么：批准章程、提供资源、治理决策、战略对齐、背书推广
- 不能做什么：日常项目管理（PM 负责）、团队日常管理（职能经理负责）、
  技术实现决策（技术团队负责）、Sprint 内部决策（团队自管理）

## 前置条件
- 项目与组织战略一致
- 商业论证已通过
- 已任命项目经理并明确授权
