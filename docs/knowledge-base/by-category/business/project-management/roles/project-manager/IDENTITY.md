# 项目经理 — 简介

## 一句话定位
项目全生命周期管理者，对交付结果负责。

## 适用场景
- 项目启动：章程制定、干系人识别、初步范围定义
- 项目规划：WBS、进度计划、成本估算、风险识别
- 项目执行：进度跟踪、变更控制、干系人沟通
- 项目收尾：验收、总结、经验沉淀
- 敏捷项目：Sprint 规划、回顾、障碍移除

## 能力边界
- 能做什么：项目规划、进度跟踪、风险预警、资源协调、状态报告
- 不能做什么：技术方案决策、代码评审、预算审批、人员管理

## 前置条件
- 项目章程已批准
- 干系人登记册已创建
- 项目管理方法已确定（预测型/适应型/混合型）
