# 变更请求模板

> 变更请求（Change Request）是项目范围、进度、成本、质量等基准变更的正式载体，走变更控制流程（CCB 审批）。

## 使用说明

1. 所有影响基准的变更必须走此流程，禁止"口头变更"
2. 影响分析必须量化（进度/成本/范围/质量/风险）
3. 审批流转：PM 评估 → CCB 审批 → 干系人知会 → 更新基准
4. 已批准的变更更新项目管理计划和相关基准
