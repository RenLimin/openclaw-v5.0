# 项目状态报告模板

> 状态报告是向干系人定期传递项目健康度的标准载体，遵循"先结论后细节"的阅读顺序。

## 使用说明

1. 周报每周一发，月报每月初发
2. 状态用红黄绿三色标注（🟢 正常 / 🟡 预警 / 🔴 严重）
3. 数据驱动：偏差用百分比，不用模糊描述
4. 报告发给 [communication-plan](../knowledge/stakeholder-management/communication-plan.md) 中定义的干系人
