# 家庭预算表模板

> 按 50/30/20 法则（或自定义比例）分配收入，逐月跟踪实际 vs 预算偏差。

## 填写说明
- **预算期间**：____ 年
- **预算类型**：□ 年度预算　□ 月度预算
- **收入基线**：月均税后收入 ______ 元
- 预算分配法则：□ 50/30/20　□ 标准普尔四象限　□ 零基预算　□ 自定义

## 一、预算分配

| 类别 | 预算比例 | 月预算额 | 年预算额 |
|------|----------|----------|----------|
| 必要开支（50%） | | | |
| 可选开支（30%） | | | |
| 储蓄投资（20%） | | | |
| **合计** | 100% | | |

## 二、细分科目

| 科目 | 月预算 | 1 月 | 2 月 | ... | 12 月 | 年实际 | 偏差 |

| 住房 | | | | | | | |
| 餐饮 | | | | | | | |
| 交通 | | | | | | | |
| 娱乐 | | | | | | | |
| 储蓄 | | | | | | | |
| 投资 | | | | | | | |

## 三、偏差规则

- **关注线**：单科目超预算 10% → 标记黄色，下月复核
- **调整线**：单科目超预算 20% → 标记红色，调整额度或动因分析
- **可控项**（娱乐/购物）：超支后下月压缩
- **不可控项**（医疗/维修）：动用应急储备，不削其他预算

## 使用提示
- 预算 = 计划，实际 = 结果，偏差 = 管理机会，不追求"零偏差"
- 每季度滚动调整一次科目额度
- 配合 [月度收支表](./monthly-cashflow.md) 记录实际值
