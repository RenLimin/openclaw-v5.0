- **当月结余** = 收入合计 − 支出合计 = ______
- **储蓄率** = 储蓄与投资 / 收入合计 = ______（目标 ≥ 20%）
- **刚性支出占比** = 刚性支出 / 收入合计 = ______（参考 ≤ 50%）
- **可选支出占比** = 可选支出 / 收入合计 = ______（参考 ≤ 30%）
