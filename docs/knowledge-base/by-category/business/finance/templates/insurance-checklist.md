## 三、保障缺口核对

| 风险 | 需覆盖 | 已有保障 | 缺口 | 建议动作 |
|------|--------|----------|------|----------|
| 医疗费用 | 大额医疗自付风险 | | | |
| 收入损失（重疾） | 3-5 年收入 | | | |
| 家庭支柱身故 | 债务+责任−可变现资产 | | | |
| 意外伤残 | 意外医疗+收入损失 | | | |
| 养老 | 退休收入替代 | | | |

## 四、检视检查点

- [ ] 保单受益人是否与当前意愿一致
- [ ] 缴费卡/续期提醒是否有效
- [ ] 家庭成员/收入/负债变化是否需调整保额
- [ ] 是否有重复保障（多份医疗/意外）可精简
- [ ] 保单存放位置家人是否知晓
