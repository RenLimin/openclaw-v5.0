# 家庭债务优化策略

> 债务不是敌人，过高的利息成本才是。优化的目标：以最低成本清偿高息债务，把 DTI 压回安全线。

## 1. 概述

债务优化是在家庭现金流约束下，对多笔债务进行清偿排序、利率谈判与结构整合的系统方法。适用场景：多张信用卡/消费贷缠身、房贷车贷并存、家庭 DTI 过高。

## 2. 核心概念

### 2.1 三种清偿策略

| 策略 | 排序依据 | 优点 | 缺点 |
|------|----------|------|------|
| 雪崩法（Avalanche） | 利率从高到低 | 利息总成本最低 | 前期看不到进度，易放弃 |
| 雪球法（Snowball） | 余额从小到大 | 快速获得"清债"正反馈 | 总利息较高 |
| 混合法 | 小额 + 高息优先 | 兼顾心理与成本 | 需要规则自律 |

### 2.2 关键指标

- **DTI（Debt-to-Income）**：月债务还款额 / 月收入，安全线 ≤ 36%
- **信用卡循环利率**：通常 15-18%（远高于房贷），最高优先清偿
- **负债收入比红线**：> 50% 需立即升级（债务危机预警）

## 3. 实践指南

### 3.1 优化流程

1. 债务清单化：利率、余额、月供、到期日逐笔列出
2. 按利率降序 + 余额升序交叉排序，确定清偿顺序
3. 优先清偿高息短期债（信用卡/消费贷），保留低息长期债（房贷）
4. 低息债考虑整合（如以低息贷款置换高息消费贷），但需计算手续费与总成本
5. 每月至少清偿最低还款，多余资金全部投给第一优先级债务
6. 清偿完成后把释放的月供转入储蓄/投资，防止"消费升级回弹"

### 3.2 债务整合评估

| 项 | 判断 |
|----|------|
| 整合后综合利率 | 明显低于原加权平均利率才值得 |
| 手续费/提前还款成本 | 计入总成本比较 |
| 期限拉长 | 月供下降但总利息可能上升，需权衡 |

## 4. 注意事项

- 绝对避免"以贷养贷"：用新债还旧债会把 DTI 推向失控
- 消费贷利率远高于房贷，优先清；房贷享受个税扣除，一般最后清
- 涉及协商减免、法律诉讼等极端情况立即升级，超出规划范畴
- 本内容为方法论，不构成债务重组法律意见
