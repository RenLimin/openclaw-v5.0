# 家庭账户体系与记账方法

> 家庭理财的数据地基：账户怎么分、账怎么记，决定了资产负债与预算分析的准确性。

## 1. 概述

家庭账户体系是财务规划的起点。清晰的三层账户分类让"钱在哪、花在哪、欠多少"一目了然，也是后续资产配置、预算管理与财务健康诊断的前提。适用场景包括：家庭财务体检、每月收支盘点、年度资产负债核对。

## 2. 核心概念

### 2.1 账户分类（资产/负债/权益）

| 账户类型 | 定义 | 示例 |
|----------|------|------|
| 现金及流动性资产 | 可随时变现的资产 | 现金、活期存款、货币基金 |
| 投资资产 | 以增值为目的的持有 | 股票、基金、债券、房产 |
| 使用资产 | 家庭自用、不以变现为目的 | 自住房、汽车 |
| 负债 | 家庭对外债务 | 房贷、车贷、消费贷、信用卡 |
| 净资产 | 资产总额 − 负债总额 | 家庭真正拥有的财富 |

### 2.2 复式记账原则

- **有借必有贷，借贷必相等**：每笔交易同时记入两个以上科目，保证账目平衡
- **权责发生制 vs 收付实现制**：家庭记账建议以收付实现制为主（以资金实际进出为准），投资计价辅以市值调整
- **科目层级**：收入（工资/经营/投资/其他）与支出（刚性/可选/储蓄/投资）的分类需固定，避免口径漂移

## 3. 实践指南

### 3.1 记账流程

1. 开立账户清单：列全银行、证券、保险、借贷账户
2. 设定科目表：按"资产-负债-收入-支出-净资产"五大类建科目
3. 逐笔记录：日常消费即时记或每日补记
4. 月度对账：与银行/证券对账单核对，处理未达账项
5. 季度重估：投资资产按市值调整，房产按评估价更新

### 3.2 记账工具选型

| 工具 | 优点 | 缺点 | 适合人群 |
|------|------|------|----------|
| 表格（Excel/Sheets） | 灵活、可自定义、数据自有 | 维护成本高、易错 | 进阶用户 |
| 记账 App | 自动记账、图表丰富 | 数据在云端、隐私存疑 | 普通家庭 |
| 复式记账软件（如 Beancount） | 精确、可审计、文本化 | 学习曲线陡 | 技术型用户 |

## 4. 注意事项

- **隐私优先**：家庭财务数据高度敏感，优先本地化存储，避免全部依赖第三方云服务
- **口径统一**：记账科目一旦确定，年内不随意变更，保证同比可比
- **市值 vs 成本**：净资产采用市值口径，投资分析才具参考价值
- 本内容为方法论，不构成具体投资建议
