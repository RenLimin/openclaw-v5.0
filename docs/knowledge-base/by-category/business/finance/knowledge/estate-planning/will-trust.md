# 遗嘱与信托

## 遗嘱（Will）

### 法定形式（《民法典》第 1134-1139 条）

| 形式 | 要求 | 效力 |
|------|------|------|
| 自书遗嘱 | 亲笔书写、签名、注年月日 | 有效 |
| 代书遗嘱 | 两名以上见证人，代书人+见证人签名 | 有效 |
| 打印遗嘱 | 两名以上见证人，每页签名+日期 | 有效 |
| 录音录像遗嘱 | 两名以上见证人，记录姓名/日期 | 有效 |
| 口头遗嘱 | 危急情况 + 两名见证人 | 危急解除后 3 个月失效 |
| 公证遗嘱 | 公证机构办理 | 效力最强 |

### 遗嘱无效情形

- 无民事行为能力人所立
- 受欺诈、胁迫所立
- 伪造、篡改部分无效
- 处分了他人财产
- 未为缺乏劳动能力又无生活来源的继承人保留必要份额（必留份）

### 遗嘱内容要素

1. 立遗嘱人身份信息
2. 财产清单（不动产、存款、股权、数字资产等）
3. 继承人和受遗赠人
4. 财产分配方案
5. 遗嘱执行人指定
6. 见证人信息（如需）
7. 日期和签名

## 法定继承顺序

| 顺序 | 继承人 | 分配 |
|------|--------|------|
| 第一顺序 | 配偶、子女、父母 | 均分 |
| 第二顺序 | 兄弟姐妹、祖父母、外祖父母 | 无第一顺序时继承 |

**特殊规则**：
- 丧偶儿媳/女婿对公婆/岳父母尽主要赡养义务的，为第一顺序继承人
- 代位继承：被继承人子女先于被继承人死亡的，由孙子女代位继承

## 信托（Trust）

### 家族信托

| 维度 | 说明 |
|------|------|
| 设立门槛 | 通常 1,000 万起（银保监规〔2023〕1 号） |
| 当事人 | 委托人、受托人（信托公司）、受益人 |
| 财产类型 | 资金、保单、股权、不动产 |
| 期限 | 通常 10-50 年或永续 |
| 功能 | 财富传承、风险隔离、税务规划、隐私保护 |

### 信托 vs 遗嘱

| 维度 | 遗嘱 | 信托 |
|------|------|------|
| 生效时间 | | 死亡后 | 设立时（生前信托） |
| 公示 | 需继承权公证 | 私密 |
| 灵活性 | 一次性分配 | 可设条件、分期给付 |
| 债务隔离 | 继承财产用于偿债 | 信托财产独立 |
| 成本 | 公证费/诉讼费 | 设立费+年度管理费 |
| 复杂度 | 低 | 高 |

## 遗产税现状与筹划

### 中国现状

- **尚未开征遗产税**：目前中国无遗产税
- 2010 年遗产税草案（未通过）：起征点 80 万，超额累进 20-50%
- 未来开征可能性：学界持续讨论

### 国际经验

| 国家 | 税率 | 免税额 |
|------|------|--------|
| 美国 | 最高 40% | $1292 万（2023） |
| 日本 | 最高 55% | 3,000 万日元 + 600 万×法定继承人数 |
| 英国 | 40% | £32.5 万 |
| 韩国 | 最高 50% | 基本扣除 |

### 提前筹划策略

1. **生前赠与**：利用年度赠与免税额度逐步转移
2. **保险规划**：身故保险金不属于遗产（指定受益人）
3. **家族信托**：资产所有权转移至信托
4. **慈善捐赠**：部分国家/地区可税前扣除
5. **跨境架构**：利用税收协定和属地原则

## 数字资产继承

### 常见数字资产类型

- 支付宝/微信余额
- 证券/基金账户
- 虚拟货币
- 数字版权/域名
- 社交媒体账号（通常不可继承，但可申请纪念账号）

### 继承流程

1. 获取被继承人死亡证明
2. 办理继承权公证
3. 向各平台提交继承申请
4. 转移账户资产

### 建议

- 建立数字资产清单（加密存储）
- 指定数字遗产执行人
- 使用密码管理器（共享主密码方案）

## 遗产规划检查清单

- [ ] 是否立有有效遗嘱
- [ ] 遗嘱是否覆盖全部主要资产
- [ ] 是否指定遗嘱执行人
- [ ] 保险受益人是否明确指定
- [ ] 是否考虑家族信托（资产 >1000 万）
- [ ] 数字资产是否有继承方案
- [ ] 是否定期检视（每 3-5 年或重大事件后）

## 常见误区

1. **认为遗产规划只属于富人**：中等收入家庭同样需要遗嘱
2. **口头承诺有效**：口头遗嘱仅在危急情况下有效
3. **配偶自动继承全部**：第一顺序继承人包括子女和父母
4. **忽视债务**：继承人在遗产范围内承担被继承人债务
5. **不更新遗嘱**：离婚/再婚/生子后需重新订立
