# 企业税务筹划

## 企业主要税种

| 税种 | 税率/征收率 | 计税基础 |
|------|-------------|----------|
| 企业所得税 | 25%（标准） | 应纳税所得额 |
| 增值税 | 13%/9%/6%/3% | 销项 - 进项 |
| 城市维护建设税 | 7%/5%/1% | 实缴增值税+消费税 |
| 教育费附加 | 3% | 实缴增值税+消费税 |
| 地方教育附加 | 2% | 实缴增值税+消费税 |
| 印花税 | 0.03%-0.1% | 合同金额 |

## 企业所得税

### 标准税率与优惠税率

| 类型 | 税率 | 条件 |
|------|------|------|
| 一般企业 | 25% | 默认 |
| 高新技术企业 | 15% | 通过高新认定 |
| 技术先进型服务企业 | 15% | 认定通过 |
| 小型微利企业 | 实际 5% | 年应纳税所得额 ≤ 300 万 |
| 西部大开发 | 15% | 鼓励类产业 |

### 税前扣除

| 项目 | 扣除比例 | 说明 |
|------|----------|------|
| 工资薪金 | 100% | 合理工资支出 |
| 职工福利费 | 14% of 工资 | 超限结转 |
| 职工教育经费 | 8% of 工资 | 超限可结转 |
| 业务招待费 | 60% or 0.5%营收 | 取低 |
| 广告和业务宣传费 | 15%营收（一般）/ 30%（化妆品等） | 超限可结转 |
| 公益性捐赠 | 12%利润总额 | 超限可结转 3 年 |

### 研发费用加计扣除

| 企业类型 | 加计比例 |
|----------|----------|
| 制造业企业 | 100% |
| 科技型中小企业 | 100% |
| 其他企业 | 75% |

即每投入 100 万研发费用，可在税前扣除 200 万（制造业）。

## 增值税

### 纳税人分类

| 类型 | 标准 | 税率 |
|------|------|------|
| 一般纳税人 | 年应税销售额 > 500 万 | 13%/9%/6% |
| 小规模纳税人 | 年应税销售额 ≤ 500 万 | 3%（2023-2027 减按 1%） |

### 进项抵扣

可抵扣的进项税额：
- 原材料/商品采购增值税专用发票
- 固定资产采购
- 服务采购（咨询、广告、运输等）
- 进口环节增值税

不可抵扣：
- 用于免税项目的进项
- 集体福利/个人消费
- 餐饮服务（一般情况）

### 小规模纳税人优惠

- 月销售额 ≤ 10 万元：免征增值税
- 2023-2027：3% 征收率减按 1% 征收
- 可选择按一般纳税人纳税（进项充足时有利）

## 小微企业税收优惠（2023-2027）

| 优惠 | 内容 |
|------|------|
| 企业所得税 | 应纳税所得额 ≤ 300 万，实际税负 5% |
| 增值税 | 小规模纳税人 3% 减按 1% |
| "六税两费" | 资源税、城建税、房产税等减半征收 |
| 个体户 | 年应纳税所得额 ≤ 200 万，减半征收个税 |

## 跨境税务基础

### 转让定价

关联方交易需遵循独立交易原则（Arm's Length Principle）：
- 可比非受控价格法
- 再销售价格法
- 成本加成法
- 交易净利润法
- 利润分割法

### 税收协定

中国已签署 100+ 个双边税收协定，主要优惠：
- 股息预提税：从 10% 降至 5% 或更低
- 利息预提税：从 10% 降至 7% 或更低
- 特许权使用费：从 10% 降至 6% 或更低

### CRS（共同申报准则）

全球金融账户信息自动交换：
- 中国自 2018 年起参与 CRS
- 高净值人士海外账户信息将交换回中国
- 需合规申报海外金融资产

## 税务筹划原则

1. **合法性**：筹划 ≠ 逃税，必须有法律依据
2. **前瞻性**：事前规划，事后调整空间极小
3. **整体性**：综合考量所有税种和期间
4. **风险可控**：激进筹划方案需评估稽查风险
5. **文档完备**：留存合同、发票、决策记录
