# 健康保险配置

## 中国医疗保障体系

| 层次 | 类型 | 覆盖 |
|------|------|------|
| 第一层 | 社会医疗保险 | 基本医保（职工/居民） |
| 第二层 | 补充医疗保险 | 大病保险、企业补充医疗 |
| 第三层 | 商业健康保险 | 医疗险、重疾险、护理险 |
| 第四层 | 个人储蓄/互助 | 医疗储蓄账户、网络互助 |

## 商业健康保险产品

### 医疗保险（Medical Insurance）

| 类型 | 保额 | 免赔 | 报销范围 | 保费 |
|------|------|------|----------|------|
| 百万医疗险 | 200-600 万 | 1 万 | 住院+特殊门诊 | 200-1,000 元/年 |
| 中端医疗险 | 20-100 万 | 0-1.5 万 | 住院+门诊+特需 | 3,000-15,000 元/年 |
| 高端医疗险 | 千万级 | 0 | 全球就医+私立 | 1-10 万元/年 |
| 防癌医疗险 | 200-400 万 | 0 | 癌症治疗 | 500-3,000 元/年 |

**关键条款**：
- 保证续保年限（6 年/20 年）
- 外购药/特药清单
- 质子重离子治疗
- CAR-T 疗法覆盖

### 重大疾病保险（Critical Illness Insurance）

| 维度 | 说明 |
|------|------|
| 赔付方式 | 确诊即赔（一次性给付） |
| 保障病种 | 28 种重疾（行业统一）+ 各保司扩展 |
| 保额建议 | 年收入 × 3-5 倍（至少 30-50 万） |
| 保障期限 | 定期（至 70 岁）/ 终身 |
| 赔付次数 | 单次 / 多次分组 / 多次不分组 |

**核心重疾（统一定义 28 种）**：
- 恶性肿瘤（重度）
- 急性心肌梗死
- 脑中风后遗症
- 重大器官移植
- 冠状动脉搭桥术
- 严重慢性肾衰竭

### 长期护理保险（Long-term Care Insurance）

| 维度 | 说明 |
|------|------|
| 触发条件 | 失能等级评估（通常 ADL 量表） |
| 给付方式 | 按月/按年给付护理金 |
| 适用人群 | 40-60 岁提前规划 |
| 试点情况 | 中国 49 城长护险试点 |

## 配置策略

### 标准组合方案

| 年龄段 | 推荐组合 | 年保费参考 |
|--------|----------|------------|
| 25-35 岁 | 百万医疗 + 消费型重疾（50 万） | 3,000-6,000 元 |
| 35-50 岁 | 百万医疗/中端医疗 + 终身重疾（50-100 万） | 8,000-20,000 元 |
| 50-65 岁 | 防癌医疗 + 防癌险 + 长护险 | 5,000-15,000 元 |
| 65 岁以上 | 防癌医疗 + 惠民保 | 1,000-3,000 元 |

### 配置优先级

1. **社保为基础**：职工医保/居民医保必须参加
2. **医疗险兜底**：百万医疗险解决大病住院费用
3. **重疾险补偿**：解决收入损失和康复费用
4. **护理险补充**：应对长期失能风险

## 社保 vs 商业保险

| 维度 | 社会医保 | 商业医疗险 |
|------|----------|------------|
| 参保条件 | 无限制 | 健康告知 |
| 报销比例 | 70-90% | 100%（社保结算后） |
| 报销上限 | 社平工资 4-6 倍 | 200-600 万 |
| 用药范围 | 社保目录 | 含自费药/靶向药 |
| 就医范围 | 定点医院 | 公立+部分私立 |

## 健康告知要点

### 常见拒保/加费情况

- 高血压 2 级以上
- 糖尿病
- 结节（甲状腺/乳腺/肺）
- 乙肝大三阳
- BMI 超标（>30）
- 既往症（癌症、心脑血管疾病）

### 核保技巧

- **智能核保**：线上快速核保，不留拒保记录
- **预核保**：部分保司支持，不影响正式投保
- **多家同时投保**：选择最优核保结论

## 惠民保（城市定制型商业医疗保险）

| 特点 | 说明 |
|------|------|
| 门槛低 | 无年龄/健康限制 |
| 保费低 | 50-200 元/年 |
| 保额高 | 100-300 万 |
| 免赔高 | 通常 2 万 |
| 适合 | 无法购买商业医疗险的老年/带病人群 |

## 常见误区

1. **有社保不需要商业险**：社保报销有封顶线和目录限制
2. **重疾险代替医疗险**：功能不同，不能互相替代
3. **给老人买重疾险**：保费倒挂（保费≈保额），不划算
4. **忽视续保条件**：非保证续保产品可能停售/拒续
5. **保额不足**：重疾保额低于 30 万难以覆盖康复期
