# 人寿保险配置

## 产品类型

### 定期寿险（Term Life）

| 维度 | 说明 |
|------|------|
| 功能 | 纯保障型，覆盖身故/全残风险 |
| 期限 | 固定期限（10/20/30 年或至 60/70 岁） |
| 保费 | 低保费、高杠杆（30 岁男性 100 万保额约 1,000 元/年） |
| 现金价值 | 无 |
| 适用 | 家庭经济支柱、房贷余额较高阶段 |

### 终身寿险（Whole Life）

| 维度 | 说明 |
|------|------|
| 功能 | 保障 + 储蓄/传承 |
| 期限 | 终身 |
| 保费 | 较高（约为定寿的 10-15 倍） |
| 现金价值 | 逐年增长，可保单贷款 |
| 适用 | 高净值人群遗产规划、债务隔离 |

### 增额终身寿（Increasing Whole Life）

| 维度 | 说明 |
|------|------|
| 功能 | 保障 + 现金价值复利增长 |
| 保额增长 | 通常 3.0-3.5% 复利递增 |
| 现金价值 | 中后期趋近保额 |
| 流动性 | 减保/退保/保单贷款 |
| 适用 | 中长期储蓄、教育金、养老金 |

## 保额计算

### 需求法（Needs Approach）

```
所需保额 = 家庭负债 + 子女教育金 + 配偶生活费用缺口 + 父母赡养 - 已有资产
```

### 收入倍数法（经验法则）

| 年龄段 | 建议保额 |
|--------|----------|
| 25-35 岁 | 年收入 × 10-15 倍 |
| 35-50 岁 | 年收入 × 8-10 倍 |
| 50 岁以上 | 年收入 × 5-8 倍 |

### 典型家庭配置示例

| 家庭成员 | 建议保额 | 产品类型 |
|----------|----------|----------|
| 经济支柱（35 岁） | 200-500 万 | 定期寿险 |
| 配偶 | 100-200 万 | 定期寿险 |
| 子女 | 不建议配置寿险 | — |

## 配置原则

### 保障优先

1. **先保障后储蓄**：先买足定期寿险，再考虑增额寿
2. **先大人后小孩**：经济支柱优先
3. **先保额后期限**：保额不足等于没保

### 保费预算

- 家庭年保费支出建议控制在年收入的 5-10%
- 超过 15% 视为负担过重
- 优先配置消费型产品（杠杆高）

## 核保与告知

### 健康告知原则

- **如实告知**：健康问卷必须如实填写
- **有问必答，不问不答**：问卷未涉及的可不主动告知
- **两年不可抗辩**：合同成立超 2 年，保险公司不得解除合同（恶意欺诈除外）

### 常见核保结论

| 结论 | 说明 |
|------|------|
| 标准体 | 正常承保 |
| 加费承保 | 加 20-100% 保费 |
| 除外承保 | 特定疾病不保 |
| 延期 | 暂不承保，观察后重新评估 |
| 拒保 | 无法承保 |

## 保单架构设计

### 投保人/被保险人/受益人

| 角色 | 税务/法律效果 |
|------|---------------|
| 投保人 | 保单所有人，可退保/贷款 |
| 被保险人 | 保险标的 |
| 受益人 | 身故保险金领取人（免个税） |

### 债务隔离功能

- 身故保险金不属于遗产（指定受益人时）
- 受益人获得的保险金不用于抵债（特定条件下）
- 但投保前已存在的债务可能被追索

## 常见误区

1. **给孩子买寿险**：孩子不是经济支柱，优先给大人买
2. **只看返还不重保障**：返还型保险收益低、保障不足
3. **保额太低**：50 万以下的定寿在通胀后杯水车薪
4. **忽视健康告知**：隐瞒病史可能导致拒赔
5. **保单不检视**：家庭结构变化时需调整
