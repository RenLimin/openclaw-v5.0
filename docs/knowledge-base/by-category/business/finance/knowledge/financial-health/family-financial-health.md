# 家庭财务健康诊断

> 财务健康不是"有多少钱"，而是"抗风险能力 + 现金流质量 + 目标可达性"的综合体检。

## 1. 概述

家庭财务健康诊断用一组可量化指标评估家庭财务状况，识别薄弱环节并给出改进方向。它是理财规划的前置动作，也是年度体检的固定项目。适用场景：年度财务体检、重大决策前（买房/换工作/生娃）、财务焦虑排查。

## 2. 核心概念

### 2.1 核心健康指标

| 指标 | 公式 | 安全线 | 含义 |
|------|------|--------|------|
| 储蓄率 | 储蓄/收入 | ≥ 20% | 财富积累速度 |
| 负债率（DTI） | 月债务还款/月收入 | ≤ 36% | 偿债压力 |
| 流动性比率 | 流动资产/月支出 | 3-6 月 | 失业/意外缓冲 |
| 应急储备 | 现金类资产 | 3-6 个月支出 | 突发事件应对 |
| 净资产增长率 | 净资产环比 | 正向增长 | 财富趋势 |
| 保障覆盖率 | 保额/风险敞口 | 见保险规划 | 风险转移 |

### 2.2 诊断框架（三桶分层）

- **安全桶**：应急储备 + 保障，保证"天塌下来生活不变"
- **增值桶**：长期投资，实现财富增长
- **目标桶**：短期目标资金（买房首付、教育金、旅行）

## 3. 实践指南

### 3.1 诊断流程

1. 收集资产负债表 + 收支表数据（来自账户体系与预算管理）
2. 计算六大核心指标
3. 对照安全线逐项打分（绿/黄/红）
4. 定位短板：如储蓄率低 → 查预算；DTI 高 → 查债务；流动性不足 → 补应急金
5. 输出改进清单（3-5 条可执行动作），纳入下季度跟踪

### 3.2 红黄绿分级

| 等级 | 判定 | 动作 |
|------|------|------|
| 🟢 健康 | 全部指标达标 | 维持 + 年度复检 |
| 🟡 关注 | 1-2 项黄灯 | 制定 3 个月改善计划 |
| 🔴 预警 | 任意红灯（如 DTI > 50%、应急金 < 1 月） | 立即降杠杆 + 补流动性 + 升级讨论 |

## 4. 注意事项

- 指标安全线是通用参考，需结合家庭生命周期（青年/中年/退休）调整
- 单一指标不能定论，需综合看（如高储蓄率但无保障 = 抗风险仍差）
- 诊断基于历史数据，未来现金流变化（失业/大病）需做压力测试
- 本内容为诊断方法论，不构成医疗/法律/投资建议
