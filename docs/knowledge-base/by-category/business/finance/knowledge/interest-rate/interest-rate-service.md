# 利率服务与实时利率获取

> 利率是家庭财务的"水龙头"：贷款成本、存款收益、投资贴现率都随它波动。

## 1. 概述

利率服务为家庭财务决策提供实时利率基准：LPR 影响房贷与经营贷成本，央行基准利率影响存款与理财收益，商业银行利率影响具体产品选择。适用场景：贷款重定价测算、存款/理财比价、投资机会成本评估。

## 2. 核心概念

### 2.1 利率体系（中国）

| 利率 | 发布方 | 频率 | 用途 |
|------|--------|------|------|
| LPR（1Y / 5Y+） | 全国银行间同业拆借中心 | 每月 20 日 | 贷款定价基准 |
| 7 天逆回购利率 | 中国人民银行 | 不定期 | 政策利率风向标 |
| 存款基准利率 | 中国人民银行 | 不定期 | 存款定价锚 |
| 商业银行挂牌利率 | 各商业银行 | 不定期 | 实际存款/贷款产品 |

### 2.2 数据源对比

| 数据源 | 类型 | 延迟 | 免费额度 | 适用 |
|--------|------|------|----------|------|
| 央行官网 / 拆借中心 | 官方一手 | 发布即更新 | 免费 | 权威核对 |
| API Ninjas（22 国央行） | API | 近实时 | 有免费层 | 程序化获取 |
| Trading Economics | API | 近实时 | 有免费层 | 多国对比 |

## 3. 实践指南

### 3.1 获取流程

1. 明确需求期限（1Y / 5Y+ / 存款 / 贷款）
2. 首选官方源（央行/拆借中心）核对最新值
3. 需要程序化集成时接入 API（多源冗余：API Ninjas + 官方爬虫兜底）
4. 记录获取时间与来源，标注时效性
5. 用于测算：房贷重定价、新贷款报价对比、存款转投决策

### 3.2 利率敏感性

- **贷款方**：LPR 降 10BP，百万房贷月供约降数十元（随本金与剩余期限变化）
- **存款方**：利率下行周期，锁定长期存款/储蓄型保险可对冲再投资风险
- **决策原则**：利率上行周期优先浮动利率贷款+短期存款；下行周期反之

## 4. 注意事项

- 利率实时变动，所有测算需标注"数据获取时间"，避免过期误用
- 商业贷款实际利率 = 基准 + 加点，需结合个人信用、银行政策
- API 有调用限额与延迟，重要决策以官方发布为准
- 本内容为方法论，不构成利率走势预测或投资建议
