# 投资风险管理

## 风险类型

### 市场风险（Market Risk）
由市场价格波动导致损失的风险，包括：
- **股票风险**：个股或股指价格下跌
- **利率风险**：债券价格与利率反向变动
- **汇率风险**：外币资产的本币价值波动
- **商品风险**：大宗商品价格波动

### 信用风险（Credit Risk）
交易对手违约或信用恶化导致损失的风险：
- 债券违约
- 理财产品底层资产违约
- 券商/托管机构信用风险

### 流动性风险（Liquidity Risk）
无法以合理价格及时变现资产的风险：
- 市场流动性枯竭（如股灾时跌停潮）
- 产品流动性受限（封闭期、赎回限制）

### 操作风险（Operational Risk）
内部流程、人员、系统故障导致损失：
- 交易执行错误
- 估值模型错误
- 合规违规

## 风险度量指标

### 波动率（Volatility）
衡量收益率的离散程度，常用年化标准差。

```
σ_annual = σ_daily × √252
```

### 风险价值（VaR, Value at Risk）
在给定置信水平和持有期下，最大潜在损失。

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 历史模拟法 | 基于历史收益率分布 | 不假设分布、简单直观 | 依赖历史数据质量 |
| 方差-协方差法 | 假设正态分布 | 计算快 | 低估尾部风险 |
| 蒙特卡洛模拟 | 随机模拟大量路径 | 灵活、可处理非线性 | 计算量大 |

### 最大回撤（Max Drawdown）
从峰值到谷底的最大累计亏损幅度。

```
MDD = (Peak - Trough) / Peak
```

### 夏普比率（Sharpe Ratio）
每单位风险的超额收益。

```
Sharpe = (Rp - Rf) / σp
```

其中 Rp=组合收益，Rf=无风险利率，σp=组合波动率

### 索提诺比率（Sortino Ratio）
类似夏普比率，但只惩罚下行波动。

```
Sortino = (Rp - Rf) / σ_downside
```

## 风险管理策略

### 风险限额体系

| 层级 | 指标 | 示例 |
|------|------|------|
| 组合层 | 最大回撤限额 | 总组合回撤不超过 15% |
| 资产层 | 单一资产占比上限 | 单只股票不超过 5% |
| 风险层 | VaR 限额 | 95% 置信度日 VaR 不超过 2% |

### 对冲策略

| 策略 | 工具 | 适用场景 |
|------|------|----------|
| 股指期货对冲 | IF/IC/IM 期货 | 系统性风险敞口管理 |
| 期权保护 | 买入看跌期权 | 保留上行收益、限制下行 |
| 债券久期调整 | 国债期货 | 利率风险管理 |
| 外汇远期 | NDF/远期结售汇 | 汇率风险锁定 |

### 止损规则

- **固定比例止损**：亏损达买入价 8-10% 时强制卖出
- **移动止损**：随盈利上移止损位（如最高价回撤 5%）
- **时间止损**：持仓超过预期时间未达目标，重新评估

## 压力测试

模拟极端市场情景对组合的影响：

| 情景 | 假设 | 用途 |
|------|------|------|
| 2008 金融危机 | 全球股市跌 50%+ | 极端尾部风险 |
| 2015 股灾 | A 股两月跌 40%+ | 流动性危机 |
| 2020 新冠暴跌 | 全球市场熔断 | 黑天鹅事件 |
| 利率急升 | 10Y 国债收益率+200bp | 债券组合压力 |

## 行为金融陷阱

| 偏差 | 表现 | 对策 |
|------|------|------|
| 损失厌恶 | 持有亏损、过早卖出盈利 | 预设止损/止盈规则 |
| 过度自信 | 频繁交易、集中持仓 | 强制分散化检查 |
| 锚定效应 | 参考买入价做决策 | 基于当前价值重新评估 |
| 羊群效应 | 追热点、跟风操作 | 独立分析、逆向思考 |
| 近因偏差 | 过度重视近期表现 | 拉长评估周期 |
