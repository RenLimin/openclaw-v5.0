# 家庭理财维度概述

## 定位

家庭理财是 L3 通用业务层中为个人/家庭财务场景提供知识支撑的维度，覆盖投资、税务、保险、遗产四大核心领域。

## 知识结构

| 子领域 | 知识文件 | 角色 |
|--------|---------|------|
| 投资规划 | portfolio-allocation, risk-management, retirement-planning | financial-advisor |
| 税务筹划 | individual-income-tax, enterprise-tax | financial-advisor |
| 保险配置 | life-insurance, health-insurance | financial-advisor |
| 遗产规划 | will-trust | financial-advisor |

## 适用场景

- 家庭财务健康检查与资产配置建议
- 个人/家庭税务优化方案
- 保险需求分析与产品选型
- 退休规划与遗产传承设计

## 交叉引用

- **项目管理**：理财项目的执行可参考 `project-management` 维度的流程框架
- **合同管理**：理财产品合同审查可参考 `contract-management` 维度的法务知识
