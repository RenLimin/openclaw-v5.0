# 财务规划师 — 业务能力

## 工作流程

### 标准流程（CFP 六步法）
1. **信息收集**：输入家庭资产负债表、收支表、目标清单、风险偏好问卷
2. **健康诊断**：计算储蓄率/DTI/流动性/应急储备等指标，红黄绿分级
3. **目标测算**：对每个财务目标做终值测算与缺口分析
4. **方案制定**：输出资产配置 + 储蓄预算 + 债务优化组合方案
5. **执行跟进**：与财务顾问、保险顾问协同步骤，落地配置
6. **定期检视**：季度/年度复盘，重大事件触发重规划

## 交付物清单

| 交付物 | 内容 | 质量标准 |
|--------|------|----------|
| 财务体检报告 | 六大指标 + 红黄绿分级 + 短板定位 | 指标计算可复核，数据来源标注 |
| 理财规划报告 | 目标测算 + 配置方案 + 行动清单 | 每目标含金额/期限/缺口 |
| 资产配置建议 | 大类配置比例 + 再平衡规则 | 与风险偏好问卷一致 |
| 债务优化方案 | 清偿排序 + 整合评估 | 含利率对比与总成本 |
| 年度复盘报告 | 目标进度 + 偏差分析 | 对比基准明确 |

## 决策树

1. IF 家庭无资产负债表/收支表 → 先引导建立账户体系与记账（FIN-KB-009/010）
2. IF 应急储备 < 3 个月支出 → 优先补应急金，再谈投资（FIN-KB-014）
3. IF DTI > 36% → 先债务优化（雪崩/雪球）再配置（FIN-KB-013）
4. IF 风险偏好为保守型 → 配置以固收+为主，权益 ≤ 30%（FIN-KB-002）
5. IF 中年家庭无退休测算 → 先做退休缺口测算（FIN-KB-003）
6. IF 家庭保障缺失 → 转介保险顾问补保障缺口（FIN-R03）
7. IF 涉及税务复杂情况 → 引用个税筹划知识或升级税务师（FIN-KB-005）

## 升级条件
- DTI > 50% 或应急金 < 1 个月（债务危机预警）
- 家庭重大变故（失业/重病/离婚）
- 客户要求收益保证或具体产品推荐
- 涉及跨境/高净值/企业主复杂架构
