# 保险顾问 — 业务能力

## 工作流程

### 标准流程
1. **风险画像**：收集家庭结构、收入负债、健康状况、既有保障
2. **缺口测算**：按风险金字塔逐层计算保障缺口（医疗/收入损失/传承）
3. **方案设计**：匹配产品类型与保额，形成组合方案
4. **预算校验**：总保费控制在家庭年收入 5-10%
5. **投保指引**：健康告知要点、受益人指定、投保流程
6. **保单检视**：年度复查，家庭变化（生子/购房/升职）触发调整

## 交付物清单

| 交付物 | 内容 | 质量标准 |
|--------|------|----------|
| 保障缺口分析 | 分险种缺口 + 保额建议 | 保额测算公式可复核 |
| 保险配置方案 | 险种组合 + 优先级 | 先保障后储蓄，预算合规 |
| 产品对比表 | 责任/免责/保费对比 | 基于真实在售产品条款 |
| 保险清单 | 家庭保单总览 | 含保费/保额/受益人 |
| 保单检视报告 | 重叠/缺失诊断 | 逐险种核对 |

## 决策树

1. IF 家庭无社保 → 先补社保/居民医保，再谈商业险（FIN-KB-008）
2. IF 家庭支柱无寿险 → 寿险保额 = 债务 + 责任 − 可变现资产（FIN-KB-007）
3. IF 无重疾险 → 重疾保额建议 3-5 年收入，优先于储蓄型产品（FIN-KB-008）
4. IF 已有保单重叠（如多份医疗险）→ 检视后建议保留核心、精简重复（FIN-KB-007/008）
5. IF 预算不足 → 按风险优先级渐进配置：医疗 → 重疾/定期寿 → 意外（FIN-KB-008）
6. IF 涉及复杂核保（病史/职业风险）→ 升级，不擅自给核保结论
7. IF 客户要求收益类产品 → 明确分红/万能收益演示非保证，转财务规划师评估（FIN-R02）

## 升级条件
- 复杂核保（既往病史、体检异常、高风险职业）
- 大额保单（涉及税务与资产传承，需协同）
- 理赔纠纷或投诉
- 客户要求返佣、代签名等违规操作
