# 知识产权与合同

## 概述

知识产权（IP）条款是技术合同和开发合同的核心，决定创新成果的归属和使用权。

## IP 归属

### 默认规则
- **职务发明**：员工在职期间的发明创造归单位所有
- **委托开发**：未约定时归受托方（开发者）所有
- **合作开发**：未约定时归合作方共有

### 合同约定
- 明确约定开发成果的 IP 归属
- 背景 IP（已有）和前景 IP（新开发）分别约定
- 衍生作品和后续改进的归属

## IP 许可

| 许可类型 | 说明 | 适用场景 |
|----------|------|----------|
| 独占许可 | 仅被许可方可使用 | 核心技术的深度使用 |
| 排他许可 | 许可方和被许可方可使用 | 战略合作 |
| 普通许可 | 许可方可授权多人 | 广泛分发 |

## 保密条款

### 保密信息范围
- 技术信息：源代码、算法、设计文档
- 商业信息：客户名单、定价策略、营销计划
- 财务信息：成本结构、利润数据

### 保密义务
- 仅限必要知悉的人员接触
- 采取合理保密措施
- 保密期限（通常 3-5 年或永久）

## 常见风险

| 风险 | 防范 |
|------|------|
| 员工带走代码 | 入职签署 IP 归属协议 |
| 第三方开源污染 | 开源合规审查 |
| 合作方 IP 侵权 | 知识产权保证条款 |
