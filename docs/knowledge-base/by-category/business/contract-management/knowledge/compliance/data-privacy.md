# 数据隐私与合同

## 概述

数据隐私条款是涉及个人信息处理的合同的必备内容，需符合 PIPL（中国）和 GDPR（欧盟）等法规。

## 中国 PIPL 要点

### 个人信息处理要求
- 明确告知：处理目的、方式、种类、保存期限
- 取得同意：单独同意（敏感个人信息）、书面同意（跨境传输）
- 最小必要：仅处理实现目的所必需的信息

### 数据跨境传输
- 通过国家网信部门的安全评估
- 或取得专业机构个人信息保护认证
- 或与境外接收方订立标准合同

## 合同条款要素

### 数据处理协议（DPA）
| 条款 | 内容 |
|------|------|
| 处理目的 | 明确数据处理的业务目的 |
| 数据类型 | 处理的个人信息种类 |
| 处理方式 | 收集、存储、使用、传输、删除 |
| 安全措施 | 加密、访问控制、审计 |
| 子处理方 | 是否委托第三方处理 |
| 数据主体权利 | 查询、更正、删除、撤回同意 |

### 违约责任
- 数据泄露的赔偿责任
- 监管罚款的分担
- 数据删除和返还义务

## GDPR vs PIPL

| 维度 | GDPR | PIPL |
|------|------|------|
| 适用范围 | 欧盟境内/涉及欧盟居民 | 中国境内/涉及中国公民 |
| 同意要求 | 明确同意 | 单独同意（敏感信息） |
| 跨境传输 | 充分性认定/SCC/BCR | 安全评估/认证/标准合同 |
| 罚款 | 最高 4% 全球营收 | 最高 5% 年营收 |
| DPO 要求 | 强制（特定情形） | 强制（处理超 100 万人） |

## 实务建议
- 涉及个人信息处理的合同必须包含 DPA
- 跨境数据传输前完成合规评估
- 定期审查数据保护条款的合规性
