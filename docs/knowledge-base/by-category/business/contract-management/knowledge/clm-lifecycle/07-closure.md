# 合同终止与归档

## 概述

合同终止是合同权利义务的结束，归档是合同生命周期的最后环节。

## 终止类型

### 1. 正常终止
- 合同期限届满
- 全部义务履行完毕
- 双方签署终止确认书

### 2. 提前终止
- 双方协商一致终止
- 一方违约，另一方行使解除权
- 不可抗力导致合同无法履行

### 3. 终止后义务
- 保密义务继续有效
- 知识产权归属不变
- 未结清款项仍需支付

## 归档管理

### 归档内容
- 合同正本（纸质或电子）
- 所有补充协议
- 变更记录
- 履行记录（验收报告、付款凭证）
- 往来函件

### 归档要求
| 要求 | 说明 |
|------|------|
| 完整性 | 全部相关文件归档 |
| 可追溯 | 建立索引，便于检索 |
| 安全性 | 电子备份 + 纸质原件 |
| 保存期限 | 合同终止后至少 10 年 |

## 经验总结
- 合同终止后进行复盘
- 记录经验教训（EXP）
- 更新模板和条款库
