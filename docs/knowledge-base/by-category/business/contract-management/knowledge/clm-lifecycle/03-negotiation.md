# 合同谈判与修订

## 概述

合同谈判是双方就合同条款达成一致的过程，修订是谈判结果的具体体现。

## 谈判准备

### 1. 确定谈判目标
- 必须达成（底线条款）
- 希望达成（目标条款）
- 可以让步（交换条款）

### 2. 识别对方立场
- 分析对方核心利益
- 预判对方底线
- 准备替代方案（BATNA）

### 3. 组建谈判团队
- 商务代表：负责商务条款
- 法务代表：负责法律条款
- 技术代表：负责技术条款

## 谈判策略

| 策略 | 适用场景 | 注意事项 |
|------|----------|----------|
| 协作式 | 长期合作关系 | 寻求双赢 |
| 竞争式 | 一次性交易 | 保护核心利益 |
| 让步式 | 次要条款 | 换取对方让步 |
| 搁置式 | 僵持条款 | 先谈其他条款 |

## 修订管理

### 版本控制
- 每次修订生成新版本（v1.0 → v1.1 → v2.0）
- 小修订递增小数点后（v1.1, v1.2）
- 大修订递增整数（v2.0, v3.0）
- 保留所有版本，支持回溯

### 修订标记
- 使用修订模式（Track Changes）
- 标注修改人、修改时间和修改原因
- 双方确认后生成清洁版

## 谈判红线

| 红线 | 说明 |
|------|------|
| 付款条件 | 预付款比例不低于 30% |
| 知识产权 | 开发成果归我方所有 |
| 违约责任 | 违约金不低于合同金额 10% |
| 争议解决 | 优先仲裁，地点在我方所在地 |
