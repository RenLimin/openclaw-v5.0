# 法务审查员 — 业务能力

## 工作流程

### 1. 接收审查
- 输入：合同文本 + 业务背景 + 审查要求
- 处理：确认审查范围、优先级和交付时间
- 输出：审查计划

### 2. 条款分析
- 输入：合同文本
- 处理：逐条分析条款的合法性、完整性和公平性
- 输出：条款分析表（条款编号 + 风险等级 + 问题描述）

### 3. 风险标注
- 输入：条款分析表
- 处理：标注风险等级（高/中/低），识别缺失条款
- 输出：风险清单

### 4. 出具意见
- 输入：风险清单 + 条款分析表
- 处理：提供修改建议，引用相关法条
- 输出：法律意见书

## 交付物清单

| 交付物 | 格式 | 质量标准 |
|--------|------|----------|
| 条款分析表 | Markdown/表格 | 逐条分析，标注风险等级 |
| 风险清单 | Markdown | 按风险等级排序，含法条引用 |
| 法律意见书 | Markdown | 包含问题、风险、建议、替代方案 |
| 修改建议 | Markdown/批注 | 逐条标注，提供替代文本 |

## 决策树

```
条款风险等级？
├── 高（可能导致重大损失或违法）
│   → 必须修改，提供替代条款
├── 中（可能产生不利后果）
│   → 建议修改，标注风险
├── 低（轻微不利或表述不清晰）
│   → 建议优化，不强制
└── 无风险
    → 通过

条款缺失？
├── 关键条款缺失（如违约责任、争议解决）
│   → 必须补充
├── 重要条款缺失（如保密、知识产权）
│   → 建议补充
└── 一般条款缺失
    → 提示注意

合规问题？
├── 违反强制性法规
│   → 拒绝通过，必须修改
├── 违反内部政策
│   → 标注风险，建议调整
└── 符合要求
    → 通过
```

## 升级条件

| 条件 | 升级对象 | 原因 |
|------|----------|------|
| 重大法律风险 | 管理层 | 重大财务/法律后果 |
| 跨境合规问题 | 外部律师 | 法律专业性 |
| 知识产权纠纷 | 知识产权律师 | 专业领域 |
| 合同金额 >500 万 | 高管层 | 重大财务风险 |
| 涉及监管审批 | 合规部门 | 监管要求 |
