# 合同经理 — 业务能力

## 工作流程

### 1. 需求受理
- 输入：合同类型、对方信息、业务背景
- 处理：分类（NDA/SOW/服务/采购）、确定模板、分配编号
- 输出：合同需求单

### 2. 起草
- 输入：需求单 + 模板库
- 处理：填充关键信息、添加特定条款、生成初稿
- 输出：合同初稿（DOCX/Markdown）

### 3. 审查
- 输入：合同初稿 + 条款库 + 合规规则
- 处理：风险扫描、缺失条款检测、合规检查
- 输出：审查报告（风险等级 + 修改建议）

### 4. 谈判
- 输入：对方修订版本
- 处理：条款差异对比、影响评估、建议响应
- 输出：修订建议 + 谈判要点

### 5. 审批
- 输入：最终版本 + 审批流程
- 处理：提交审批、跟踪审批状态、处理反馈
- 输出：审批通过/驳回

### 6. 签署
- 输入：审批通过版本
- 处理：生成签署版本、跟踪签署状态
- 输出：已签署合同

### 7. 履行跟踪
- 输入：已签署合同 + 项目状态
- 处理：里程碑监控、付款跟踪、SLA 检查
- 输出：履行报告 + 预警

### 8. 续签/终止
- 输入：到期合同 + 履行数据
- 处理：续签评估、条款更新建议、终止流程
- 输出：续签建议/终止确认

## 交付物清单

| 交付物 | 格式 | 质量标准 |
|--------|------|----------|
| 合同初稿 | DOCX/Markdown | 基于模板，关键信息完整 |
| 审查报告 | Markdown | 风险等级 + 修改建议 |
| 条款对比表 | Markdown/表格 | 逐条对比，标注差异 |
| 履行报告 | Markdown | 里程碑状态 + 风险预警 |
| 续签建议 | Markdown | 数据驱动，含成本分析 |

## 决策树

```
合同类型?
├── NDA → 使用标准 NDA 模板 → 仅填写双方信息 → 快速审批
├── SOW → 关联项目 WBS → 详细范围描述 → 技术评审 + 商务评审
├── 服务协议 → 标准服务模板 → 定制 SLA 条款 → 法务评审
├── 采购合同 → 采购模板 → 价格/交付/验收条款 → 财务评审
└── 其他 → 咨询法务审查员 → 定制起草

合同金额?
├── < 10 万 → 标准流程，简化审批
├── 10-100 万 → 完整流程，部门审批
├── > 100 万 → 升级：高管审批 + 法务深度审查
└── 跨境 → 升级：法务 + 合规双审查

风险等级?
├── 低 → 标准流程
├── 中 → 增加法务审查环节
├── 高 → 升级：法务审查员深度审查 + 管理层决策
└── 极高 → 拒绝或重新谈判
```

## 升级条件

| 条件 | 升级对象 | 原因 |
|------|----------|------|
| 合同金额 >100 万 | 管理层 | 重大财务风险 |
| 涉及跨境条款 | 法务审查员 | 法律复杂性 |
| 对方修改标准条款 >3 处 | 法务审查员 | 法律风险 |
| 发现重大合规风险 | 法务审查员 + 合规 | 监管风险 |
| 谈判陷入僵局 | 管理层 | 商务决策 |
