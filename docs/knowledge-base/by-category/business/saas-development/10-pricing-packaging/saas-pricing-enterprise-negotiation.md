# 企业客户定价与谈判 SOP

## 适用场景

- SaaS 企业版客户的定制化定价
- 大客户的商务谈判流程
- 折扣、定制、合同条款的审批管理
- 企业客户的 ROI 呈现与价值销售

---

## 核心原则

1. **价值销售，不是价格销售** — 卖的是价值和结果，不是功能清单
2. **有底线，不随便让价** — 每一次让价都要有对应的回报
3. **不打价格战** — 靠差异化价值赢单，不靠便宜
4. **标准化 + 灵活度** — 有标准价目表，但也有谈判空间
5. **保护价格体系** — 不能因为一个客户乱了整个定价体系

---

## 企业版定价构成

### 标准企业版报价结构

| 项目 | 说明 | 占比参考 |
|---|---|---|
| **软件订阅费** | 按席位 / 用量 / 套餐 | 60-80% |
| **实施服务费** | 部署、配置、数据迁移、培训 | 10-20% |
| **客户成功费** | 专属 CSM、定期业务回顾 | 5-15% |
| **定制开发费** | 定制化功能开发（一次性） | 按需 |
| **支持升级费** | 7×24 支持、专属支持经理 | 5-10% |
| **SLA 保费** | 更高的 SLA 承诺 | 5-10% |

### 常见的企业版收费模式

| 模式 | 说明 | 适用场景 |
|---|---|---|
| **按席位年费** | 每个用户每年多少钱，最低起售量 | 最常见，协作 / CRM / ERP 类 |
| **包年包量** | 固定年费，包含一定用量，超出另算 | 用量型产品 |
| **固定年费+用量** | 基础年费 + 超出部分按用量 | API / 数据类产品 |
| **项目制 + 年费** | 一次性实施费 + 每年订阅费 | 复杂企业软件 |
| **按价值分成** | 按客户获得的价值抽成 | 效果类产品（如增长工具） |

## 折扣管理

### 折扣层级与审批

**标准化折扣权限：**

| 折扣幅度 | 审批人 | 备注 |
|---|---|---|
| 0-10% | 销售 | 自主决定 |
| 10-20% | 销售主管 | 需说明理由 |
| 20-30% | 销售总监 | 需商务审批 |
| 30-40% | VP / CEO | 特殊项目，需 ROI 评估 |
| 40% 以上 | 创始人 | 战略性项目，极少使用 |

**为什么要有折扣审批？**
- 防止销售乱降价把价格体系搞乱
- 每降一个点都是纯利润的损失
- 保持价格的市场一致性

### 让价的原则

**永远不要无条件让价。每一次降价都要换点什么回来。**

| 你让了什么 | 你要换回来什么 |
|---|---|
| 10% 折扣 | 签 2 年合同 |
| 15% 折扣 | 年付（不按月付） |
| 20% 折扣 | 更多席位 / 更大用量 |
| 25% 折扣 | 同意做客户案例 / 推荐 |
| 30% 折扣 | 战略合作伙伴关系 + 联合营销 |

**反模式：** 客户说"便宜点" → 销售直接降价。
**正确姿势：** "价格可以商量，您看如果签两年的话我们可以给到 XX 折扣。"

## 谈判策略

### 常见的议价招式与应对

| 客户招式 | 应对策略 |
|---|---|
| **"太贵了"** | 不说"可以便宜"，先问"和什么比太贵？"，回到价值讨论 |
| **"预算只有 X"** | 不直接降价，问"如果预算固定，我们可以调整范围" |
| **"竞品只要 X 钱"** | 不贬低竞品，强调我们的差异化价值和总拥有成本 |
| **"给我个最低价"** | 不给最低价，给性价比最高的方案 |
| **"我们是大客户，给个优惠价"** | 可以优惠，但要对等的承诺（量、年限、案例） |
| **"不便宜就不买了"** | 不慌，先确认是不是真的要走，再考虑让步 |
| **"你们老板我认识"** | 礼貌但坚持走流程，可以说"我帮您去申请" |

### 价格谈判的核心逻辑

**客户想买，你想卖。分歧在价格。**

1. **先确认价值，再谈价格** — 客户没看到价值，再便宜也嫌贵
2. **不要先出价** — 能让客户先说出预算最好
3. **每次让步都要越来越小** — 第一次让 10%，第二次 5%，第三次 2% — 表示快到底了
4. **不接受第一次报价** — 客户也一样，你报什么他都会砍一点
5. **最后要有"决定权不在我"的缓冲** — "我去申请一下"比"我说了算"更好谈

### ROI 销售法

**最好的谈判是不算价格账，算价值账。**

**客户 ROI 计算模板：**

```
你们有 100 个销售，用了我们的产品：
- 每人每天节省 1 小时 = 每天 100 小时
- 按销售时薪 ¥200 算 = 每天节省 ¥20,000
- 每月 22 天 = 每月节省 ¥440,000
- 每年 = ¥5,280,000

我们的产品只要 ¥200,000 / 年
ROI = 26.4 倍
不到 2 周就能回本
```

**有了 ROI 数据，价格谈判就变成了"值不值"而不是"贵不贵"。**

## 定制化报价

### 什么时候需要定制报价

- 客户规模超出现有套餐上限
- 需要大量定制开发
- 需要特殊的 SLA / 安全合规要求
- 需要专属服务（驻场、专属团队）
- 战略合作伙伴（换量、联合营销等）

### 定制报价构成

```
基础费用（标准企业版 × 数量）
  + 定制开发费（一次性）
  + 实施服务费（一次性 / 按人天）
  + 专属客户成功费（每年）
  + 高级支持费（每年）
  + SLA 保费（每年）
  - 战略折扣（如果有）
─────────────────────
= 总报价
```

### 定制报价的风险控制

**定制开发的风险：**
- 需求蔓延（做着做着需求越来越多）
- 工期延误
- 后续维护成本高
- 版本碎片化

**控制手段：**
- 明确的需求范围（SOW）
- 变更流程（变更要加钱加时间）
- 定制开发独立报价，不要揉进订阅费里
- 定制功能尽量产品化（做一次，其他客户也能用）
- 维护期后的持续维护单独收费

## 合同条款中的价格陷阱

### 要注意的条款

| 条款 | 风险 | 应对 |
|---|---|---|
| **多年合同价格锁定** | 签 3 年价格不变，3 年后涨价难 | 每年可以有一定比例的价格调整（如 CPI 或固定比例） |
| **无限量使用** | 客户用量暴涨，你成本飙升 | 用量上限 + 超出部分计费 |
| **最惠国条款** | 给别的客户更低价格也要给他同样的 | 尽量不要签，签了就有限制条件 |
| **无条件退款** | 用了半年说不满意要全额退款 | 退款有条件、有时限、有比例 |
| **自动续约** | 客户忘了取消自动续了，可能有纠纷 | 提前提醒，明确续约条款 |
| **数据迁移费用** | 解约后数据迁移谁出钱 | 明确责任和费用 |

## 企业客户的分层定价

### 客户分层与对应策略

| 客户层级 | ARR 范围 | 定价策略 | 销售方式 |
|---|---|---|---|
| **SMB（中小企业）** | < ¥50,000 | 标准化价格，线上自助或轻量销售 | Inside Sales |
| **Mid-Market（中型）** | ¥50,000-500,000 | 标准价 + 适度折扣 | 企业销售 |
| **Enterprise（大型）** | ¥500,000-5,000,000 | 定制化报价 + 谈判 | 大客户销售 + 售前 |
| **战略客户** | > ¥5,000,000 | 战略合作级定价 | VP / CEO 参与 |

### 不同层级的销售重点

- **SMB：** 产品说话，快速成交，标准化
- **Mid-Market：** 价值销售，ROI 计算，适度定制
- **Enterprise：** 关系 + 价值 + 服务，长周期，深度定制
- **战略客户：** 双赢，长期合作，联合创新

## 价格一致性保护

### 为什么价格一致性重要

- 市场上价格混乱 → 客户互相攀比 → 谁都不想当冤大头
- 销售各自为战 → 价格体系崩塌 → 利润大幅下降
- 价格不透明 → 客户不信任

### 保护措施

1. **公开价格表** — SMB / Mid-Market 价格公开透明
2. **折扣审批制度** — 每一级折扣对应审批人
3. **价格回顾** — 每季度 review 成交价分布
4. **CRM 价格记录** — 所有成交价录入 CRM，分析趋势
5. **客户互相询问时** — 统一口径，解释版本 / 服务 / 数量不同

## 常见陷阱

| 陷阱 | 表现 | 规避方法 |
|---|---|---|
| 上来就谈价格 | 销售一上来就报价，然后客户就砍价 | 先讲价值，确认需求，最后再谈价格 |
| 乱降价 | 为了赢单什么折扣都敢给 | 折扣审批制度，每让一步都要有回报 |
| 定制化失控 | 答应了一堆定制，最后做不完还不赚钱 | 明确 SOW，变更走流程，定制单独收费 |
| 价格体系崩塌 | 每个客户价格都不一样，越做越乱 | 标准化价格 + 分级审批 + 定期回顾 |
| 只谈价格不谈价值 | 整个谈判全是价格拉锯 | 回到 ROI 和价值，价格只是价值的一部分 |
| 为了完成指标低价签单 | 为了冲业绩，亏本也签 | 关注毛利，不只看收入；低价单需要审批 |
| 忽略后续增购 | 签单时只看首年价格 | 首年可以让步，但要为后续增购留出空间 |
