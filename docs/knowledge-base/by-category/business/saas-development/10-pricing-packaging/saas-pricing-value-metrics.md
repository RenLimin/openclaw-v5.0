# 价值度量与 PLG 转化 SOP

## 适用场景

- Product-Led Growth 模式下的价值度量与转化优化
- 找到正确的价值指标（Value Metric）
- 免费 → 付费转化率提升
- 付费 → 更高套餐的增购转化

---

## 核心原则

1. **价值指标对齐客户价值** — 客户用得越多得到的价值越多，你也收得越多
2. **可预期，不惊吓** — 客户知道大概会花多少钱，不会月底收到惊吓账单
3. **转化是漏斗，不是单点** — 从激活到付费有很多环节，每个环节都可以优化
4. **数据驱动** — 每个转化环节都要有数据，知道卡在哪
5. **自然转化优于人工推销** — 产品自己说服客户付费，不是销售硬推

---

## 什么是价值指标

### 定义

价值指标（Value Metric）是你收费的单位，也是客户获得价值的单位。

**好的价值指标的三个特征：**
1. **与价值对齐** — 客户获得的价值越多，付的钱越多
2. **可预测** — 客户能预估自己的花费
3. **可扩展** — 客户增长时你的收入也增长

### 常见价值指标对比

| 价值指标 | 与价值对齐 | 可预测性 | 可扩展性 | 示例产品 |
|---|---|---|---|---|
| **每席位** | 中 | 高 | 高 | Slack、CRM |
| **API 调用次数** | 高 | 中 | 高 | Twilio、Stripe |
| **存储容量** | 高 | 高 | 高 | Dropbox、云盘 |
| **活跃用户** | 高 | 中 | 高 | 按实际使用的产品 |
| **交易金额抽成** | 高 | 低 | 高 | 支付、电商平台 |
| **功能套餐** | 中 | 高 | 中 | 大多数 SaaS |

### 怎么找到你的价值指标

**问三个问题：**

1. **客户从你的产品中获得价值的单位是什么？**
   - 协作工具 → 每个人用就有价值 → 席位
   - 通信 API → 每条短信都有价值 → 用量
   - 数据分析 → 查得越多越值 → 查询量

2. **随着客户增长，什么会自然增长？**
   - 客户公司变大 → 用户数增长 → 按席位
   - 业务量增长 → API 调用增长 → 按用量

3. **你的成本结构是什么？**
   - 每个用户都消耗资源 → 按用户收费合理
   - 每次调用都有成本 → 按用量收费合理

## PLG 转化漏斗

### 五层漏斗

```
访客（Visitor）
   ↓ 注册
注册用户（Signup）
   ↓ 激活
激活用户（Activated）
   ↓ 首次付费
付费客户（Paid）
   ↓ 增购 / 升级
扩张客户（Expanded）
```

### 各层转化率基准

| 转化环节 | 基准（参考） | 说明 |
|---|---|---|
| 访客 → 注册 | 5-15% | 落地页转化率 |
| 注册 → 激活 | 30-50% | 完成关键激活动作 |
| 激活 → 付费 | 3-10% | 免费转付费 |
| 付费 → 增购 | 10-30% | NRR 中的 expansion |
| 整体 LTV:CAC | > 3:1 | 健康标准 |

**注意：** 这些只是参考，不同产品差异很大。重要的是持续优化自己的转化率。

## 转化优化的五个杠杆

### 杠杆 1：提升激活率

**问题：** 注册了很多人，但大多没真正用起来

**优化手段：**
- 优化 Onboarding 流程（参考 Onboarding SOP）
- 降低首次使用门槛
- Aha Moment 前置（越快体验到价值越好）
- 空状态引导（不要让用户看到空白页面）
- 模板和示例数据（从模板开始比从零开始容易）
- 邮件 Onboarding 序列（引导用户回来完成激活）

### 杠杆 2：付费墙设计

**付费墙（Paywall）放在哪里？**

| 付费墙类型 | 说明 | 转化率 | 用户体验 |
|---|---|---|---|
| **用量墙** | 免费用到上限了要付费 | 高 | 好（用到了才要付钱） |
| **功能墙** | 高级功能要付费 | 中 | 中 |
| **时间墙** | 试用期到了要付费 | 中高 | 中 |
| **用户数墙** | 超过 N 个用户要付费 | 中高 | 中 |

**最佳实践：**
- 让用户先用出价值，再遇到付费墙
- 付费墙的位置 = 体验到 Aha Moment 之后
- 不要在用户还没感受到价值的时候就要钱
- 付费墙要有明确的升级理由（升级了能干嘛）

### 杠杆 3：转化时机

**什么时候提示升级？**

✅ **好的时机：**
- 刚完成一个有成就感的操作之后
- 达到免费版上限，想继续用的时候
- 用户主动探索高级功能的时候
- 用户问"能不能 XXX"的时候
- 试用期快结束的时候

❌ **坏的时机：**
- 刚注册就要钱
- 用户第一次用就弹升级广告
- 操作到一半打断要付费

### 杠杆 4：升级体验

**升级流程要多顺滑？**

目标：3 步以内完成升级付款。

**升级流程优化：**
- 产品内一键升级（不要跳出去）
- 支持多种支付方式
- 月付 / 年付选择（默认年付更划算）
- 升级即时生效（付完钱马上能用）
- 升级后引导用户使用高级功能

### 杠杆 5：流失挽回

**用户遇到付费墙走了怎么办？**

**挽回手段：**
- 退出意图弹窗（准备关页面时弹优惠）
- 降价（首月半价、年付折扣）
- 免费延长试用
- 教育内容（告诉用户高级功能的价值）
- 人工跟进（高价值用户，销售联系）

**注意：** 不要一上来就降价。先展示价值，价值到位了客户愿意付钱。

## 关键转化率分析

### 分析框架

每个转化环节都要问：
1. **当前转化率是多少？**
2. **行业基准是多少？**
3. **用户卡在哪了？**
4. **怎么优化？**

### 常见卡点

| 卡点 | 原因 | 优化方向 |
|---|---|---|
| 注册率低 | 落地页没说清价值 | 优化价值主张、社会认同 |
| 激活率低 | Onboarding 太难，找不到价值 | 简化流程、前置 Aha Moment |
| 付费转化率低 | 没感受到价值 / 太贵 | 提前价值、调整定价、增加功能 |
| 增购率低 | 高级功能没用上 | 引导使用高级功能、展示价值 |

## 价格透明度与用量预警

### 用量型产品的痛点

客户最怕的："月底收到天价账单"

**怎么让客户有安全感：**
1. **用量仪表盘** — 随时看用了多少
2. **用量预警** — 用到 50% / 80% / 100% 自动提醒
3. **封顶机制** — 超过多少就不再收费 / 暂时停掉
4. **预估账单** — 按当前使用量预估本月费用
5. **预算控制** — 客户自己设上限，到了就停

### 好的用量计费体验

- 客户随时知道花了多少钱
- 不会收到"惊喜"账单
- 可以自己控制花费
- 用得多 = 获得的价值多 = 愿意多付钱

## 转化实验

### A/B 测试什么

**定价页测试：**
- 价格高低
- 套餐数量（3 档 vs 4 档）
- 月付 vs 年付默认选项
- 功能对比表的展示方式
- 锚定策略（哪个标"最受欢迎"）

**付费墙测试：**
- 付费墙的位置
- 升级提示的文案
- 升级按钮的位置和样式
- 升级优惠的形式

**转化漏斗测试：**
- Onboarding 步骤数
- 首次体验路径
- 邮件序列的内容和频率

### 实验注意事项

- **样本量要够** — 不要 10 个用户就下结论
- **看对指标** — 不要只看转化率，看总收入（转化率 × ARPA）
- **长期影响** — 有些策略短期提升转化但长期伤害留存
- **一次只改一个变量** — 不然不知道是什么起的作用

## Enterprise Touch（PLG + 销售）

### 产品内线索生成

PLG 产品不是完全不要销售。好的 PLG 是：
- 小客户产品内自助转化
- 大客户销售主动跟进

**什么样的用户要转销售跟进？**

- 公司邮箱域名是大客户的
- 团队人数快速增长
- 用到了企业版功能的边界
- 主动询问企业版
- 高使用量 + 高健康度

**PQL（Product Qualified Lead）：**
> 产品使用数据表明有潜力成为付费大客户的用户。

**PQL 标准示例：**
- 团队 > 20 人
- 周活跃 > 5 天
- 接近免费版上限
- 使用了 3 个以上核心功能

PQL 出来了 → 销售主动联系 → 推动企业版转化。

## 常见陷阱

| 陷阱 | 表现 | 规避方法 |
|---|---|---|
| 价值指标没选对 | 收费和客户价值不同步，要么亏了要么客户跑了 | 深入理解客户价值，不断调整 |
| 免费到付费转化太低 | 1000 个免费用户只有 5 个付费 | 检查 Aha Moment、付费墙位置、价值感知 |
| 用量账单惊吓 | 客户月底收到超预期账单，怒而取消 | 用量预警 + 预算封顶 + 透明仪表盘 |
| 功能墙太早 | 用户还没用出价值就遇到付费墙 | 让用户先体验价值，再要钱 |
| 只看转化率不看收入 | 降价转化率上去了，总收入反而降了 | 看转化率 × ARPA，看总收入 |
| PLG 就是完全自动化 | 觉得 PLG 就是不要销售 | PLG + 销售配合，自助 + 人工双轨 |
| 转化漏斗不透明 | 不知道卡在哪一步，全靠感觉 | 完整埋点，漏斗分析，每个环节都有数 |
