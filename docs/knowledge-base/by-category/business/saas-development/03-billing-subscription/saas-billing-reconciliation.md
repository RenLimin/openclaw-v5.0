# 财务对账与收入确认 SOP

## 适用场景

- SaaS 计费系统与支付渠道、财务系统的对账
- 订阅收入的权责发生制确认
- 应收 / 预收 / 坏账的账务处理
- 月度 / 年度财务关账

---

## 核心原则

1. **一分钱都不能差** — 对账就是要精准，差一分钱也要找到原因
2. **日清月结** — 每日对账，月度关账，不要拖
3. **权责发生制** — 收入按服务期确认，不是按收款时间
4. **可追溯** — 每一笔账务都能追溯到原始交易
5. **自动化优先** — 对账是规则驱动的，能自动就不要人工

---

## 对账体系

### 对账层级

| 层级 | 对账内容 | 频率 | 负责方 |
|---|---|---|---|
| **L1 — 支付对账** | 系统支付记录 vs 支付渠道流水 | 每日 | 系统自动 |
| **L2 — 订单对账** | 订单 vs 支付 vs 发票 三者匹配 | 每日 | 系统自动 |
| **L3 — 收入对账** | 确认收入 vs 订单 vs 递延收入 | 月度 | 财务 + 系统 |
| **L4 — 总账对账** | 业务系统数据 vs 财务系统总账 | 月度 | 财务 |

### 支付对账（L1）

**对账双方：** 内部支付记录 ↔ 支付渠道交易流水

**对账字段：**
- 交易流水号
- 交易金额
- 交易时间
- 交易状态
- 手续费

**差异类型：**

| 差异类型 | 原因 | 处理方式 |
|---|---|---|
| **金额不一致** | 手续费计算差异、汇率差异 | 核实原因，手工调整 |
| **状态不一致** | 网络超时导致状态不同步 | 查询支付渠道最新状态，更新内部状态 |
| **单边账（渠道有我方无）** | 我方记录丢失 / 回调丢失 | 补录内部记录 |
| **单边账（我方有渠道无）** | 重复扣款 / 测试数据 | 核实后冲销 |
| **漏单** | 交易成功但未通知 | 补单 |

**对账流程：**
```
T+1 凌晨自动拉取支付渠道流水
    ↓
与内部支付记录逐笔匹配
    ↓
生成对账差异表
    ↓
自动处理可自动处理的差异
    ↓
人工处理剩余差异
    ↓
生成对账报告
```

### 订单对账（L2）

**三方匹配：** 订单 ↔ 支付 ↔ 发票

**匹配规则：**
- 一个订单对应一笔或多笔支付
- 一笔支付对应一张发票（或多张发票 / 合并发票）
- 订单金额 = 支付金额 ± 退款
- 支付金额 = 发票价税合计

**常见问题：**
- 支付了但没开票 → 补开发票
- 开了票但没收到钱 → 催收 / 检查支付状态
- 订单金额与发票金额不一致 → 查明原因（折扣、proration 等）

## 收入确认

### 基本概念

**权责发生制 vs 收付实现制：**

| 方式 | 确认时间 | 适用场景 |
|---|---|---|
| **权责发生制** | 服务提供时确认收入 | 企业会计准则（必须） |
| **收付实现制** | 收到钱时确认收入 | 小微企业、税务简化（部分地区） |

**SaaS 收入确认原则：**
- 订阅收入在服务期内**线性确认**（按月/天平均分摊）
- 一次性设置费 / 实施费：随服务期一起确认，或在服务交付时确认
- 用量计费：使用发生的当期确认
- 年付：12 个月平均确认

### 收入计算示例

**场景：** 客户年付 ¥11,988（含税），税率 6%，服务期 2026-01-01 至 2026-12-31

```
不含税金额 = ¥11,988 / 1.06 = ¥11,309.43
月确认收入 = ¥11,309.43 / 12 = ¥942.45
```

**每月确认：**
- 1 月：确认收入 ¥942.45
- 2 月：确认收入 ¥942.45
- ...
- 12 月：确认收入 ¥942.45

**递延收入（负债）：**
- 收款时：全额计入递延收入（预收账款）
- 每月：从递延收入转出当月确认的收入
- 年末：递延收入余额为 0

### 会计分录（简化版）

**收款时：**
```
借：银行存款       ¥11,988
  贷：预收账款     ¥11,309.43
      应交税费 - 销项税额  ¥678.57
```

**每月确认收入：**
```
借：预收账款       ¥942.45
  贷：主营业务收入  ¥942.45
```

### 特殊场景

**升级 / 降级：**
- 升级补差价：剩余服务期内重新分摊
- 降级不退款：当期收入不变，下期按新价格

**退款：**
- 冲减当期收入
- 已确认的收入部分按退回金额冲减

**免费试用：**
- 试用期不确认收入
- 转为付费后按付费期确认

**年付折扣：**
- 折扣作为收入抵减项
- 按折扣后的金额在服务期内分摊

## 关键财务指标

### SaaS 核心财务指标

| 指标 | 公式 | 说明 |
|---|---|---|
| **MRR** | 月经常性收入 | 当月所有活跃订阅的月费之和 |
| **ARR** | MRR × 12 | 年化经常性收入 |
| **NRR** | (期初 MRR + 增购 - 流失 - 降级) / 期初 MRR | 净收入留存率 |
| **GRR** | (期初 MRR - 流失 - 降级) / 期初 MRR | 毛收入留存率 |
| **递延收入** | 已收款但尚未确认的收入 | 资产负债表负债项 |
| **应收账款** | 已确认收入但未收款 | 资产负债表资产项 |
| **坏账准备** | 预计无法收回的账款 | 应收账款的备抵 |

### MRR 变动拆解

```
期初 MRR
  + 新客户 MRR（新增）
  + 扩展 MRR（增购 / 升级）
  - 流失 MRR（取消）
  - 收缩 MRR（降级）
──────────────────
= 期末 MRR
```

## 月度关账流程

### 关账时间表（T = 月末）

| 时间 | 任务 | 负责方 |
|---|---|---|
| T+1 | 月末数据截止，所有交易入账 | 系统自动 |
| T+1 | 完成支付对账（L1） | 系统 + 财务 |
| T+2 | 完成订单对账（L2） | 系统 + 财务 |
| T+3 | 计算当月收入确认 | 系统自动 |
| T+3 | 坏账准备计提 | 财务 |
| T+4 | 生成财务报表初稿 | 财务 |
| T+5 | 财务审核与调整 | 财务 |
| T+7 | 最终报表输出 | 财务 |

### 关账检查清单

- [ ] 所有支付流水已对账完成
- [ ] 所有发票已开具并核对
- [ ] 当月收入确认计算完成
- [ ] 递延收入余额正确
- [ ] 应收账款账龄分析完成
- [ ] 坏账准备计提完成
- [ ] MRR 变动表核对无误
- [ ] 与总账系统数据一致

## 系统集成

### 与财务系统集成

**需要同步的数据：**

| 数据 | 频率 | 方向 |
|---|---|---|
| 发票数据 | 实时 / 日 | 业务系统 → 财务系统 |
| 收入确认明细 | 月 | 业务系统 → 财务系统 |
| 退款数据 | 日 | 业务系统 → 财务系统 |
| 支付流水 | 日 | 支付渠道 → 财务系统 |

**常见财务系统：**
- 国内：用友、金蝶、浪潮
- 国际：NetSuite、SAP、QuickBooks、Xero

**集成方式：**
- API 对接（实时）
- 文件导入导出（CSV / Excel）
- 中间件 / iPaaS

## 常见陷阱

| 陷阱 | 表现 | 规避方法 |
|---|---|---|
| 收入确认错了 | 把年付的钱全算成当月收入 | 按权责发生制，服务期内分摊 |
| 对账差几分钱 | 四舍五入累计，总账差几分钱对不上 | 设置尾差调整项，小金额自动找平 |
| 税和收入混在一起 | 把含税金额当收入，收入虚高 | 严格区分不含税收入和税金 |
| 递延收入不对 | 每个月算的递延余额和总账对不上 | 按月核对，发现差异及时调 |
| 退款忘了冲收入 | 退了款但收入没冲，利润虚高 | 退款自动触发收入冲减分录 |
| 对账不及时 | 上个月的账还没对完，这个月又开始了 | 日清月结，设定明确的关账时间点 |
| 多币种混乱 | 外币业务的汇兑损益搞不定 | 统一用记账本位币，按月调汇 |
