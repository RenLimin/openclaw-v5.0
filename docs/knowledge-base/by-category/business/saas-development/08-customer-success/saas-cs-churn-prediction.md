# 客户流失预警与挽留 SOP

## 适用场景

- SaaS 客户流失的早期识别
- 不同流失风险等级的应对策略
- 客户挽留（Save Play）的标准化流程
- 流失原因分析与产品改进闭环

---

## 核心原则

1. **预防胜于治疗** — 最好的挽留是让客户不想走
2. **越早越好** — 流失前 90 天干预和流失前 7 天干预，效果天差地别
3. **对症下药** — 不同的流失原因用不同的挽留策略
4. **该放手时就放手** — 不是所有客户都值得挽留，价值低的可以让他走
5. **闭环改进** — 每一个流失的客户都是产品改进的输入

---

## 流失类型

### 按流失原因分类

| 类型 | 占比（参考） | 说明 | 可挽回度 |
|---|---|---|---|
| **产品未达标** | ~30% | 产品满足不了需求，缺功能 / 不好用 | 中 |
| **没被用起来** | ~25% | 买了但没人用，团队不 adoption | 高 |
| **价格敏感** | ~15% | 觉得贵，预算不够 | 中 |
| **竞品抢走** | ~15% | 竞品更好更便宜 | 低 |
| **客户自身原因** | ~10% | 客户倒闭、转型、并购 | 低 |
| **服务不好** | ~5% | 支持响应慢、解决不了问题 | 高 |

### 按客户价值分类

| 客户层级 | ARR | 挽留投入 | 优先级 |
|---|---|---|---|
| 战略客户 | > ¥500,000 | 高层介入 + 定制方案 | 最高 |
| 大客户 | ¥100,000-500,000 | CSM 负责人 + 产品支持 | 高 |
| 中客户 | ¥10,000-100,000 | CSM 标准挽留流程 | 中 |
| 小客户 | < ¥10,000 | 自动化挽留 + 优惠 | 低 |
| 免费用户 | 0 | 完全自动化 | 最低 |

## 流失预警信号

### 行为信号（使用数据）

| 信号 | 说明 | 风险等级 |
|---|---|---|
| 使用量持续下降 | 连续 3 周使用量下降 > 20% | 🟠 高 |
| 登录频率骤降 | 从每周 5 次降到每周 1 次 | 🟠 高 |
| 核心功能停用 | 之前常用的核心功能不用了 | 🔴 极高 |
| 管理员不登录了 | 管理员连续 2 周没登录 | 🔴 极高 |
| 席位减少 | 主动减少席位数 | 🟡 中 |
| 只看不操作 | 登录了但不做任何操作 | 🟡 中 |
| 导入数据后不用了 | 导入了数据就再也没回来 | 🟠 高 |

### 互动信号

| 信号 | 说明 | 风险等级 |
|---|---|---|
| CSM 联系不上 | 发邮件不回，打电话不接 | 🟠 高 |
| QBR 推延 | 季度业务回顾一推再推 | 🟡 中 |
| 负面反馈增加 | 工单 / 沟通中负面情绪增加 | 🟠 高 |
| 问竞品对比 | 开始问"你们和 XX 比怎么样" | 🟡 中 |
| 问导出功能 | 突然关心数据怎么导出去 | 🔴 极高 |
| 问取消流程 | 直接问怎么取消订阅 | 🔴 极高 |

### 商业信号

| 信号 | 说明 | 风险等级 |
|---|---|---|
| 付款逾期 | 该付钱了迟迟不付 | 🟠 高 |
| 合同到期前不回复 | 续约邮件发了没反应 | 🟠 高 |
| 客户公司融资 / 并购 | 可能换系统 | 🟡 中 |
| 客户联系人离职 | 对接人走了，新的对接人可能换产品 | 🟡 中 |
| 客户公司裁员 | 预算缩减，可能砍 SaaS 预算 | 🟡 中 |

### 健康分综合判断

参考《客户健康分 SOP》：
- 健康分 < 60 分 → 高风险
- 健康分连续 2 个月下降 → 预警
- 从健康掉到一般 → 关注

## 挽留流程（Save Play）

### 三级挽留机制

```
一级挽留：自动化（低风险 / 小客户）
   ↓ 失败
二级挽留：CSM 介入（中风险 / 中客户）
   ↓ 失败
三级挽留：高层介入（高风险 / 大客户）
   ↓ 失败
客户流失 → 流失后调研 → 闭环改进
```

### 一级挽留：自动化

**触发条件：** 健康分下降 / 使用量下降 / 小客户

**自动化挽留手段：**

| 手段 | 说明 | 适用场景 |
|---|---|---|
| 教育邮件 | "你可能不知道的 3 个功能" | 没用起来的客户 |
| 最佳实践内容 | "XX 公司如何用我们的产品提升效率" | 用得浅的客户 |
| 优惠激励 | 限时折扣 / 多送 2 个月 | 价格敏感客户 |
| 产品内提示 | 引导重新激活的 in-app 提示 | 不登录的客户 |
| 免费培训 | 邀请参加 webinar / 培训 | 不会用的客户 |

**自动化邮件序列示例：**
```
Day 0：检测到使用量下降 → 发送 "5 个技巧帮你更高效"
Day 3：→ 发送 "客户成功案例：XX 如何提升 30% 效率"
Day 7：→ 发送 "免费 webinar：新功能深度解析"
Day 14：→ 如果还没回来，发送优惠挽留
Day 21：→ CSM 人工介入（如果是有价值的客户）
```

### 二级挽留：CSM 介入

**触发条件：** 中高风险客户 / 中大型客户

**CSM 挽留步骤：**

#### Step 1：了解情况
- 分析客户的使用数据（哪里下滑了）
- 看历史互动记录（之前有没有什么问题）
- 了解客户最近的变化（联系人、公司动态）

#### Step 2：主动联系
- 电话 / 视频会议（比邮件有效）
- 开场不是"你是不是要走"，而是"最近怎么样，有什么可以帮你的"
- 真诚倾听，不推销

#### Step 3：诊断原因
用 SPIN 提问法挖掘真实原因：
- 现状：目前用得怎么样
- 问题：有没有遇到什么困难
- 影响：这些问题对你们有什么影响
- 需求：如果能解决，对你有什么价值

#### Step 4：制定挽救方案
根据原因定制方案：

| 流失原因 | 挽留方案 |
|---|---|
| 没用起来 | 重新 onboarding + 培训 + 1v1 辅导 |
| 缺功能 | 评估功能优先级，能做的给时间表，不能做的找替代方案 |
| 价格贵 | 降级套餐 / 年付优惠 / 特殊折扣 |
| 竞品 | 针对性对比，突出差异化价值 |
| 服务不好 | 道歉 + 升级处理 + 专属支持 |
| 客户自身原因 | 保持联系，等条件好了再回来 |

#### Step 5：执行与跟进
- 明确的挽救计划和时间线
- 每周跟进进度
- 2 周后评估效果
- 有效 → 持续跟进，恢复健康
- 无效 → 升级到三级挽留

### 三级挽留：高层介入

**触发条件：** 大客户 / 战略客户 / 二级挽留失败

**高层介入方式：**
- 我方高管 + 客户高管对话
- 定制化解决方案
- 特殊商务条款
- 产品路线图承诺（如果是功能问题）
- 成功保障计划

**注意：** 高层介入是最后手段，不能什么客户都让高管上。只有值得挽留的大客户才升级。

## 流失后处理

### 流失不是终点

**客户走了也要好好说再见：**
1. 取消流程简单顺畅（别搞复杂的取消流程恶心人）
2. 确认数据导出（让客户能带走自己的数据）
3. 流失原因调研（1-2 分钟的问卷）
4. 保持联系（Newsletter 可以继续收）

**为什么？**
- 客户可能还会回来（"Win Back"）
- 留个好印象，他会跟别人说"那个产品取消特别爽快"
- 流失原因是宝贵的产品改进输入

### 流失原因分析

**每季度流失复盘：**
1. 汇总本季度流失客户
2. 分类统计流失原因
3. 找出 Top 3 流失原因
4. 分配给产品 / 服务 / 销售等团队改进
5. 下季度复盘改进效果

## 挽留 ROI 评估

### 什么客户值得挽留

**计算挽留的 ROI：**
```
挽留价值 = 客户 LTV × 挽留成功概率
挽留成本 = CSM 投入时间 × 时薪 + 折扣成本

如果 挽留价值 > 挽留成本 × 3 → 值得挽留
```

**不值得挽留的客户：**
- 免费用户（用自动化就行）
- 小客户，问题特别多，服务成本高
- 不是目标客户，产品本来就不适合他们
- 恶意客户（薅羊毛、找麻烦的）

### 挽留效果衡量

| 指标 | 定义 | 目标 |
|---|---|---|
| 挽留成功率 | 成功挽留的客户 / 介入的客户 | > 30% |
| 挽留后留存 | 挽留成功后 6 个月还在的比例 | > 70% |
| 平均挽留成本 | 每挽留一个客户花多少钱 / 多少时间 | < 客户 2 个月 ARR |
| 挽回率（Win Back） | 流失后又回来的客户比例 | > 5% |

## 常见陷阱

| 陷阱 | 表现 | 规避方法 |
|---|---|---|
| 挽留全靠降价 | 一说要走就给折扣，客户学会了"威胁降价" | 先了解原因，价格是最后手段 |
| 什么客户都留 | 花大量时间挽留没价值的小客户 | ROI 评估，不值得的放他走 |
| 取消流程复杂 | 取消要打电话、要审核、要等，恶心客户 | 一键取消，爽快点，好聚好散 |
| 不做流失分析 | 客户走了就走了，不知道为什么 | 流失原因调研 + 季度复盘 + 产品改进 |
| 太晚了才行动 | 客户都提交取消了才开始挽留 | 提前预警，提前 90 天干预 |
| 全靠 CSM 个人能力 | 有的 CSM 挽留率高有的低，全靠经验 | 标准化挽留 playbook，培训 + 工具支持 |
| 挽留完就不管了 | 留住了人留不住心，过两个月还是走了 | 挽留成功后 3 个月密切跟进，真正恢复健康 |
