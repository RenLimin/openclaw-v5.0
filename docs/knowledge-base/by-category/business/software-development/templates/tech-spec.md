## 4. 详细设计

### 4.1 数据模型

```
Entity: Order
├── order_id: UUID (PK)
├── customer_id: UUID (FK)
├── status: ENUM
├── total_amount: DECIMAL
├── created_at: TIMESTAMP
└── updated_at: TIMESTAMP
```

### 4.2 API 设计

| 方法 | 路径 | 说明 | 请求/响应 |
|------|------|------|-----------|
| GET | /api/v1/orders | 列表 | ... |
| POST | /api/v1/orders | 创建 | ... |

### 4.3 关键流程

**时序图（核心场景）**：
```
Client → API Gateway → Service A → Service B → DB
         ↓              ↓
         Auth           Cache
```
