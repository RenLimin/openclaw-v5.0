# 数据安全

## 数据分级分类

| 级别 | 说明 | 示例 |
|------|------|------|
| 公开 | 可对外公开 | 产品介绍、公开报告 |
| 内部 | 仅内部使用 | 内部文档、流程规范 |
| 机密 | 泄露会造成损害 | 用户行为数据、商业策略 |
| 绝密 | 泄露会造成严重损害 | 密码、密钥、PII |

## 加密策略

| 场景 | 方案 |
|------|------|
| 传输加密 | TLS 1.3、证书固定 |
| 存储加密 | AES-256-GCM、信封加密 |
| 密码存储 | bcrypt/argon2（加盐 + 慢哈希） |
| 密钥管理 | KMS（AWS KMS / HashiCorp Vault） |
| 端到端加密 | 客户端加密、服务端无法解密 |

## 数据脱敏

| 类型 | 方法 | 适用 |
|------|------|------|
| 静态脱敏 | 生产数据脱敏后导入测试环境 | 测试数据准备 |
| 动态脱敏 | 查询时根据权限实时脱敏 | 生产环境查询 |
| 匿名化 | 移除/替换标识符 | 数据分析、机器学习 |

### 常见脱敏规则

| 数据 | 脱敏方式 |
|------|----------|
| 手机号 | 138****1234 |
| 身份证 | 110***********1234 |
| 银行卡 | 6222 **** **** 1234 |
| 邮箱 | a***@example.com |
| 姓名 | *三、李* |

## 访问控制

| 模型 | 说明 |
|------|------|
| RBAC | 基于角色（管理员/普通用户/访客） |
| ABAC | 基于属性（部门 + 级别 + 时间 + 位置） |
| ReBAC | 基于关系（Owner/Member/Viewer） |

## 数据生命周期

| 阶段 | 安全措施 |
|------|----------|
| 采集 | 最小必要、知情同意 |
| 存储 | 加密、访问控制 |
| 使用 | 脱敏、审计日志 |
| 传输 | TLS、完整性校验 |
| 归档 | 加密归档、访问审计 |
| 销毁 | 安全擦除、不可恢复 |
