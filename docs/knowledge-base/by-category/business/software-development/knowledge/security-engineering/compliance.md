# 合规体系

## 等保 2.0（网络安全等级保护）

| 等级 | 说明 | 适用 |
|------|------|------|
| 第一级 | 自主保护 | 一般信息系统 |
| 第二级 | 指导保护 | 非核心业务系统 |
| 第三级 | 监督保护 | 重要业务系统 |
| 第四级 | 强制保护 | 核心基础设施 |
| 第五级 | 专控保护 | 极端重要系统 |

### 等保 2.0 核心要求

| 领域 | 要求 |
|------|------|
| 安全物理环境 | 机房安全、电力、消防 |
| 安全通信网络 | 网络架构、通信传输、可信验证 |
| 安全区域边界 | 边界防护、访问控制、入侵防范 |
| 安全计算环境 | 身份鉴别、访问控制、安全审计 |
| 安全管理中心 | 系统管理、审计管理、集中管控 |
| 安全管理制度 | 策略、制度、规范 |
| 安全管理机构 | 人员、岗位、授权 |
| 安全管理人员 | 录用、离岗、培训 |
| 安全建设管理 | 定级、方案设计、工程实施 |
| 安全运维管理 | 环境管理、资产管理、应急响应 |

## GDPR（通用数据保护条例）

### 数据主体权利

| 权利 | 说明 |
|------|------|
| 知情权 | 告知数据用途 |
| 访问权 | 获取个人数据副本 |
| 更正权 | 修正不准确数据 |
| 删除权 | "被遗忘权" |
| 限制处理权 | 限制数据处理 |
| 数据可携带权 | 导出数据 |
| 反对权 | 反对自动化决策 |

### 合规要点

| 要求 | 说明 |
|------|------|
| 合法基础 | 同意、合同、法律义务、正当利益 |
| 隐私设计 | 默认隐私保护 |
| DPO | 数据保护官 |
| 泄露通知 | 72h 内通知监管机构 |
| DPIA | 隐私影响评估 |

## SOC 2

| 信任服务标准 | 说明 |
|--------------|------|
| 安全性 | 保护系统免受未授权访问 |
| 可用性 | 系统可用且可操作 |
| 处理完整性 | 处理完整、准确、及时 |
| 机密性 | 机密信息受保护 |
| 隐私性 | 个人信息收集、使用、保留合规 |

## PCI DSS（支付卡行业数据安全标准）

| 要求 | 说明 |
|------|------|
| 防火墙 | 保护持卡人数据环境 |
| 密码 | 不使用默认密码 |
| 数据保护 | 存储的持卡人数据加密 |
| 传输加密 | 开放网络传输加密 |
| 反病毒 | 定期更新反病毒软件 |
| 系统开发 | 安全开发和变更管理 |
| 访问控制 | 基于业务需要限制访问 |
| 唯一 ID | 每个用户唯一标识 |
| 物理访问 | 限制物理访问 |
| 日志 | 日志和审计跟踪 |
| 安全测试 | 定期测试安全系统 |
| 安全策略 | 维护信息安全策略 |
