# 零信任架构

## 核心原则

| 原则 | 说明 |
|------|------|
| 永不信任，始终验证 | 每次访问都需认证和授权 |
| 最小权限 | 只授予完成任务所需的最小权限 |
| 假设已被入侵 | 内部网络不等于安全网络 |
| 验证所有来源 | 用户、设备、应用、数据流 |
| 持续监控 | 基于风险的动态访问决策 |

## 传统边界 vs 零信任

| 维度 | 传统边界 | 零信任 |
|------|----------|--------|
| 信任模型 | 内网可信 | 永不信任 |
| 边界 | 防火墙/VPN | 身份 + 设备 + 上下文 |
| 访问控制 | 基于网络位置 | 基于身份和策略 |
| 横向移动 | 容易 | 微分段限制 |
| 可见性 | 有限 | 全流量审计 |

## 实施路径

### 阶段 1：身份为中心

| 措施 | 说明 |
|------|------|
| MFA | 所有用户强制多因素认证 |
| SSO | 统一身份认证 |
| 设备信任 | 设备健康检查 |

### 阶段 2：微分段

| 措施 | 说明 |
|------|------|
| 网络分段 | 服务间最小连通 |
| 应用分段 | 基于身份的访问控制 |
| 数据分段 | 按敏感度分级保护 |

### 阶段 3：持续验证

| 措施 | 说明 |
|------|------|
| 风险评估 | 基于上下文动态评分 |
| 自适应访问 | 风险高时要求额外验证 |
| 全流量审计 | 所有通信可审计 |

## 技术组件

| 组件 | 说明 |
|------|------|
| IdP | 身份提供商（Okta/Azure AD） |
| PDP | 策略决策点 |
| PEP | 策略执行点 |
| SIEM | 安全事件管理 |
| CASB | 云访问安全代理 |

## Google BeyondCorp 实践

| 实践 | 说明 |
|------|------|
| 无 VPN | 不依赖传统 VPN |
| 设备清单 | 所有设备登记管理 |
| 用户-设备绑定 | 访问权限绑定设备和用户 |
| 分层访问 | 根据信任级别分级访问 |
