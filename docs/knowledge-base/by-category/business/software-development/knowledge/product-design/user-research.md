# 用户研究方法论

## 方法分类

### 定性 vs 定量

| 维度 | 定性 | 定量 |
|------|------|------|
| 目的 | 理解"为什么" | 测量"多少" |
| 样本量 | 5-30 人 | 100+ |
| 方法 | 访谈、可用性测试、焦点小组 | 问卷、A/B 测试、数据分析 |
| 输出 | 洞察、模式 | 统计显著性 |
| 阶段 | 探索期 | 验证期/增长期 |

### 常用方法

| 方法 | 类型 | 适用阶段 | 成本 |
|------|------|----------|------|
| 用户访谈 | 定性 | 探索/发现 | 中 |
| 可用性测试 | 定性 | 设计/验证 | 中 |
| 问卷调查 | 定量 | 发现/验证 | 低 |
| 焦点小组 | 定性 | 概念验证 | 中 |
| 日记研究 | 定性 | 长期行为理解 | 高 |
| A/B 测试 | 定量 | 优化/增长 | 低 |
| 数据分析 | 定量 | 全阶段 | 低 |
| 竞品分析 | 混合 | 发现 | 低 |

## 用户画像（Persona）

### 构建要素

| 要素 | 内容 |
|------|------|
| 基本信息 | 姓名、年龄、职业、城市 |
| 行为特征 | 使用频率、技术熟练度、设备偏好 |
| 目标 | 试图完成什么 |
| 痛点 | 当前面临的困难 |
| 动机 | 为什么使用/不使用 |
| 引用 | 真实用户原话 |

### 画像使用原则

- 基于真实研究数据，非编造
- 3-6 个画像覆盖主要用户群
- 张贴在团队可见位置
- 决策时以画像为参照（"张伟会用这种方式吗？"）

## 用户旅程地图（User Journey Map）

### 构成

| 层 | 内容 |
|-----|------|
| 阶段 | 认知 → 考虑 → 决策 → 使用 → 留存 → 推荐 |
| 行为 | 用户在每个阶段做什么 |
| 想法 | 用户在想什么 |
| 情绪 | 用户体验的情绪曲线 |
| 触点 | 用户与产品的交互点 |
| 机会 | 可优化的痛点 |

### 情绪曲线示例

```
情绪 ↑
     |     ★ 首次成功
     |    / \
     |   /   \_____ 遇到困难
     |  /         \___ 解决
     | /              \___ 持续使用
     |/                   \___★ 推荐给他人
     └──────────────────────────────→ 时间
     认知  考虑  购买  上手  日常  精通
```

## 可用性测试

### 测试类型

| 类型 | 说明 | 适用 |
|------|------|------|
| 形成性测试 | 设计阶段发现问题 | 原型/早期 |
| 总结性测试 | 上线前验证 | 后期 |
| 远程 moderated | 视频连线引导 | 深度洞察 |
| 远程 unmoderated | 用户自行完成 | 快速验证 |

### 核心指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 任务成功率 | > 85% | 用户能否完成任务 |
| 任务完成时间 | 基准 ±20% | 效率 |
| 错误率 | < 10% | 操作错误次数 |
| SUS 评分 | > 68 | 系统可用性量表（10 题） |
| SEQ 评分 | < 3（7 分制） | 单题易用性 |

### 招募原则

- 每个画像至少 5 名用户（Nielsen 研究：5 人发现 85% 问题）
- 避免内部员工（偏见）
- 筛选条件与画像匹配
- 提供合理激励

## 需求优先级框架

### RICE 评分

```
RICE = (Reach × Impact × Confidence) / Effort
```

| 维度 | 说明 | 评分 |
|------|------|------|
| Reach | 影响用户数 | 绝对数字 |
| Impact | 对每个用户的影响 | 3=高 2=中 1=低 0.5=极低 |
| Confidence | 估计的把握度 | 100%=高 80%=中 50%=低 |
| Effort | 团队工作量 | 人月 |

### MoSCoW 法

| 优先级 | 含义 |
|--------|------|
| Must have | 没有产品不能发布 |
| Should have | 重要但可延期 |
| Could have | 有则更好 |
| Won't have | 本次不做 |

## 常见误区

1. **只问用户要什么**：用户说的不一定是真正的需求（福特"更快的马"）
2. **样本偏差**：只采访活跃用户，忽略流失用户
3. **引导性问题**："你觉得这个功能好吗？"→ 应问"你上次遇到这个问题是什么时候？"
4. **忽视情境**：实验室环境 ≠ 真实使用场景
5. **一次研究定终身**：用户行为在变化，需持续研究
