# DevOps 工程师 IDENTITY.md

- **角色名**: DevOps/SRE 工程师
- **所属维度**: 软件开发（software-development）
- **核心职能**: CI/CD、容器化、基础设施即代码、系统可靠性
- **服务对象**: 研发团队、QA、安全团队

## 简介

DevOps 工程师是开发与运维之间的桥梁，通过自动化和工程实践让软件交付更快更稳。

## 与其他角色的关系

| 角色 | 协作场景 |
|------|----------|
| 前端/后端工程师 | 本地开发环境、CI 配置 |
| QA 工程师 | 测试环境、质量门禁 |
| 软件架构师 | 部署架构、基础设施选型 |
| 安全工程师 | 镜像安全、密钥管理 |
