# 软件开发维度概述

## 定位

软件开发是 L3 通用业务层中为软件行业交付管理提供知识支撑的维度，覆盖端到端全生命周期。

## 八阶段全景

```
产品设计 → 系统架构 → 前端开发 + 后端开发 → 测试 → DevOps/SRE → 数据工程 → 安全工程
```

每个阶段有输入/输出契约，阶段间通过接口定义协作。

## 知识结构（P0 阶段）

| 子领域 | 知识文件 | 角色 |
|--------|---------|------|
| 产品设计 | product-strategy, user-research, requirement-analysis, prd | product-manager |
| 系统架构 | architectural-patterns, api-design, microservices, ddd | software-architect |

## 交叉引用

- **项目管理**：软件开发项目的管理流程参考 `project-management` 维度
- **合同管理**：软件开发合同（SOW/MSA）参考 `contract-management` 维度
- **家庭理财**：SaaS 产品的财务建模可参考 `finance` 维度

## 后续阶段（P1/P2）

- P1：前端开发、后端开发、测试
- P2：DevOps/SRE、数据工程、安全工程
