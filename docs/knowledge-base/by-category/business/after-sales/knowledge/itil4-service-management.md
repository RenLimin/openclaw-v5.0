# ITIL 4 服务管理

## 服务价值系统（SVS）

| 组件 | 说明 |
|------|------|
| 指导原则 | 7 项原则（聚焦价值、整体思考、迭代改进等） |
| 治理 | 评估、指导、监控 |
| 价值链 | 6 项活动（计划、改进、设计/转换、获取/构建、交付/支持） |
| 实践 | 34 项实践（通用/服务/技术管理） |
| 持续改进 | 贯穿所有层级 |

## 服务价值链活动

| 活动 | 说明 |
|------|------|
| 计划 | 确保全组织的共同理解 |
| 改进 | 持续改进产品/服务/实践 |
| 设计与转换 | 满足市场需求的设计和转换 |
| 获取/构建 | 获取和构建服务组件 |
| 交付与支持 | 确保服务的交付和支持 |
| 参与 | 理解利益相关者需求 |

## 核心实践

| 实践 | 说明 |
|------|------|
| 事件管理 | 恢复正常服务运营 |
| 问题管理 | 预防事件复发 |
| 变更管理 | 最大化成功变更 |
| 发布管理 | 使新/变更服务可用 |
| 服务台 | 捕获需求、事件、请求 |
