# SLA 管理

## 协议层级

| 协议 | 说明 |
|------|------|
| SLA（服务级别协议） | 服务提供商与客户之间的承诺 |
| OLA（运营级别协议） | 内部团队之间的支持协议 |
| UC（支持合同） | 外部供应商与提供商之间的合同 |

## SLA 指标

| 指标 | 说明 | 典型目标 |
|------|------|----------|
| 可用性 | 服务可访问时间占比 | 99.9% |
| 首次响应时间 | 工单创建到首次回复 | Sev1: 15min |
| 解决时间 | 工单创建到关闭 | Sev1: 4h |
| 客户满意度 | CSAT 评分 | > 4.0/5.0 |

## 度量与报告

| 报告 | 频率 | 内容 |
|------|------|------|
| SLA 达成率 | 月度 | 各指标达成情况 |
| 违约清单 | 月度 | 未达标项及原因 |
| 趋势分析 | 季度 | 改进趋势、预警 |

## 违约处理

1. **根因分析**：为什么违约？
2. **改进计划**：如何避免再次发生？
3. **客户沟通**：主动说明情况和补救措施
4. **服务积分**：按合同条款补偿
