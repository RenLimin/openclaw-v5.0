# 用户培训

## 分层培训

| 层级 | 对象 | 内容 | 方式 |
|------|------|------|------|
| 管理员 | IT 管理员 | 系统配置、用户管理、安全策略 | 深度工作坊 |
| 超级用户 | 部门 Key User | 高级功能、流程配置、问题排查 | 实操培训 |
| 普通用户 | 最终用户 | 日常操作、常见问题 | 视频教程 + FAQ |

## 培训材料

| 类型 | 用途 |
|------|------|
| 操作手册 | 按功能模块的详细步骤 |
| 视频教程 | 5-10 分钟的操作演示 |
| FAQ | 常见问题快速解答 |
| 快速参考卡 | 一页纸核心操作 |
| 沙箱环境 | 安全练习环境 |

## Kirkpatrick 四级评估

| 层级 | 评估内容 | 方法 |
|------|----------|------|
| L1 反应 | 学员满意度 | 课后问卷 |
| L2 学习 | 知识掌握 | 考核测试 |
| L3 行为 | 实际应用 | 跟踪使用情况 |
| L4 成果 | 业务影响 | 效率提升、错误率下降 |

## 认证体系

| 级别 | 要求 |
|------|------|
| 初级 | 完成基础培训 + 通过考核 |
| 中级 | 完成高级培训 + 实操评估 |
| 高级 | 完成管理员培训 + 指导他人 |
