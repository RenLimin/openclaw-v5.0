# 变革管理

## ADKAR 模型

| 阶段 | 说明 | 关键活动 |
|------|------|----------|
| Awareness | 认知 | 为什么变？不変会怎样？ |
| Desire | 意愿 | 我为什么要支持？对我有什么好处？ |
| Knowledge | 知识 | 如何使用新系统？ |
| Ability | 能力 | 实际操作、练习、指导 |
| Reinforcement | 巩固 | 持续支持、正向反馈、纠正 |

## 利益相关者管理

| 步骤 | 活动 |
|------|------|
| 识别 | 谁受影响？谁有决策权？ |
| 分析 | 影响力 × 态度矩阵 |
| 沟通 | 定制沟通策略 |
| 对齐 | 解决顾虑、获取承诺 |

## 阻力应对

| 阻力类型 | 应对策略 |
|----------|----------|
| 不理解 | 加强沟通和培训 |
| 不愿意 | 找到 WIIFM（我能得到什么） |
| 没能力 | 提供培训和辅导 |
| 恐惧 | 共情、数据证明、试点验证 |

## Kotter 8 步变革

1. 建立紧迫感
2. 组建变革团队
3. 确立愿景和策略
4. 沟通变革愿景
5. 授权行动
6. 创造短期成果
7. 巩固成果，继续变革
8. 将变革融入文化
