# [ADR-202609-026] L3 家庭及个人理财通用框架（FIN）建设与层级归属

## 1. 状态
**accepted** — 2026-09-03 起生效

## 2. 背景

Rex 要求建设"家庭及个人理财"系统，其中：
- **L3 通用业务层**：理财领域通用业务知识 + 核算引擎 + 理财建议规则
- **L4 专有业务层**：基于 Rex 家庭/个人数据的理财系统实例

**核心约束**：
1. 理财领域业务知识属于 L3（Rex 明确拍板）
2. 必须支持：个人银行借款/贷款核算、个人（商业）保险核算、定期获取实时利率
3. 必须支持：投资理财建议（资产配置、债务优化、财务健康诊断）
4. 符合系统架构设计逻辑（分层自治、契约稳定、运行时无关）
5. 避免 OpenClaw 系统冲突（不新建 cron、不绑定特定运行时）
6. 关键节点回顾已建设资产，避免幻觉

**业界调研结论**（两轮深度调研）：
- 贷款核算：标准 PMT 公式 + amortization schedule，中国市场 LPR 为基准
- 保险核算：现金价值/退保价值/IRR 计算，中国税延养老险 A/B/C 三类产品
- 资产配置：Rule of 100/110、标准普尔四象限、三桶分层、5/25 再平衡规则
- 债务优化：雪崩（利率优先）/ 雪球（余额优先）/ 混合策略
- 财务健康 KPI：储蓄率≥20%、DTI≤36%、流动性≥6 月、应急储备 3-6 月
- 利率 API：API Ninjas（22 国央行）、Trading Economics、央行官网爬取

## 3. 考虑的选项

### 选项 A: 全部塞进 L4（一层扁平）
- 思路：理财系统 = 专有业务，直接建 L4
- 优点：启动快
- 缺点：
  - 违反"L3 业务知识"的 Rex 拍板
  - 通用核算能力无法复用（如未来有企业理财需求）
  - 不符合架构分层原则
- 评估：❌ 违反架构决策

### 选项 B: L3 纯知识库（不建引擎）
- 思路：L3 只存理财知识/规则，计算全在 L4
- 优点：L3 轻量
- 缺点：
  - 核算逻辑（PMT、IRR、现金价值）是通用的，放 L4 会重写
  - 不符合"跨场景通用能力放 L3"原则
- 评估：❌ 粒度不够

### 选项 C: L3 通用引擎 + L4 家庭实例 — **采用**
- 思路：L3 建核算引擎 + 知识库 + 建议规则，L4 灌数据
- 优点：
  - 符合 Rex "理财知识在 L3" 的拍板
  - 核算引擎可复用（未来企业理财、其他家庭）
  - L4 只负责数据 + 展示，轻量
  - 符合分层自治、契约稳定原则
- 缺点：
  - 前期投入大（6 个 FIN 组件）
  - L3/L4 契约需精心设计
- 评估：✅ 符合架构、匹配需求

## 4. 决策

**采用选项 C：L3 通用理财引擎 + L4 家庭实例**。

**L3 组件清单**：

| 组件 ID | 名称 | 职责 |
|---|---|---|
| FIN-001 | 账户体系 | 复式记账引擎（资产/负债/收入/权益/费用） |
| FIN-002 | 贷款/借款核算 | 债务摊销引擎（等额本息/等额本金/先息后本/随借随还） |
| FIN-003 | 保险产品核算 | 保单估值引擎（现金价值/退保价值/IRR/红利演示） |
| FIN-004 | 利率服务 | 实时利率获取（LPR/央行基准/商业银行利率） |
| FIN-005 | 投资持仓核算 | 投资组合引擎（持仓/盈亏/年化收益/资产配比） |
| FIN-006 | 理财建议引擎 | 智能建议（现金流诊断/资产配置/债务优化/风险缺口） |

**L4 实例**：
- FIN-L4-PF01：Rex 家庭理财系统（基于 L3 引擎 + 家庭数据）

## 5. 后果

### 5.1 正面
- 通用能力复用：核算引擎不限于一个家庭/个人
- 分层清晰：L3 管计算，L4 管数据
- 可扩展：未来可加企业理财、税务规划等模块
- 知识沉淀：理财知识进入知识库，可被 AI agent 引用

### 5.2 负面
- 前期投入大：6 个 FIN 组件 + L4 实例
- 利率 API 依赖外部服务（需 API Key 或爬虫维护）
- 保险产品复杂度高（险种多、规则多）

### 5.3 风险
| 风险 | 缓解 |
|---|---|
| 利率 API 不可用 | 多源冗余（API Ninjas + 爬虫兜底） |
| 保险计算与实际偏差 | 标注"估算值"，建议用户核对保单 |
| L3/L4 契约不稳定 | 先定义最小契约，迭代扩展 |
| 与现有 L2 组件冲突 | 严格走 L1 抽象层，不直接调用运行时 |

## 7. 验证标准

1. **L3 引擎可独立运行**：传入参数即可得结果，不依赖 L4 数据
2. **L4 可继承 L3**：L4 实例通过灌数据就能产出报表/建议
3. **符合分层**：L3 不持有家庭数据，L4 不重写核算逻辑
4. **知识沉淀**：理财知识进入知识库，可被 AI agent 引用
5. **无系统冲突**：不新建 cron、不改运行时配置
