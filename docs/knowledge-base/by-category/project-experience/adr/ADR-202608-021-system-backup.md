# [ADR-202608-021] L2 系统备份

## 1. 状态
**accepted** — 2026-09-01 起生效

## 2. 背景

系统配置、凭据、会话、工作区数据需要定期备份，防止数据丢失。之前从未执行过系统备份，存在数据丢失风险。

## 3. 考虑的选项

### 选项 A: 手动备份（按需执行）
- 优点：灵活
- 缺点：依赖人工，容易遗忘

### 选项 B: 每日自动 Git 备份 + 手动备份
- 优点：自动化、版本化、可追溯
- 缺点：需要外部存储（不能在 ~/.openclaw 下）

### 选项 C: 云存储备份
- 优点：异地容灾
- 缺点：成本高、数据外发

## 4. 决策
我们选择 **选项 B**，因为需要在自动化和成本之间取得平衡。

## 5. 后果
### 5.1 正面
- 每日自动备份，无需人工干预
- Git 版本化，支持任意时间点恢复
- 手动备份用于关键操作前

### 5.2 负面
- 备份仓库需要外部存储
- 首次备份需要较长时间

### 5.3 风险
- 备份仓库损坏导致无法恢复

## 6. 实现计划
- [x] 创建外部 Git 备份仓库（~/backups/openclaw-auto）
- [x] 配置每日自动备份（openclaw backup enable --every 24h）
- [x] 执行首次备份
- [ ] 定期验证备份完整性

## 7. 验证标准
- 每日自动备份成功
- 备份可成功恢复
