# [ADR-202608-014] L2 错误自动处理

## 1. 状态
**accepted** (2026-08-24)

## 2. 背景

Agent 运行过程中产生各类错误(模型超时/compaction 失败/记忆降级/工具失败/上下文溢出),当前无自动处理机制,依赖人工发现和处理。08-24 压缩失效四环事故就是错误处理缺失的典型案例。

## 3. 考虑的选项

### 选项 A: 维持现状(错误散落在 EXP 中)
- 优点: 零工作量
- 缺点: 被动响应,事故重复发生

### 选项 B: 仅通知(检测 + 通知,不自愈)
- 优点: 简单,不会引入新问题
- 缺点: 所有错误都需人工处理,通知风暴

### 选项 C: 检测→分级→自愈闭环
- 优点: 自动处理大部分错误,只将无法自愈的升级给人类
- 缺点: 设计复杂度高,自愈可能引入新问题

## 4. 决策

选择 **选项 C** —— 检测→分级→自愈闭环。

理由:
1. 与 ADR-011 Error Contract 对齐(severity 分级)
2. 与溢出防护状态机互补(状态机防溢出,错误处理防其他故障)
3. 自愈失败有通知兜底,不会漏报

## 5. 后果

### 5.1 正面
- Sev3-4 错误 ≥80% 自动恢复,不打扰 Rex
- Sev1-2 错误及时通知,附带诊断信息
- 错误处理可追溯(每次自愈记录日志)

### 5.2 负面
- 自愈逻辑需要维护(新错误类型需新增规则)
- 误判风险(正常行为被判为错误)

### 5.3 风险
- 自愈循环 → 防范:重试上限 2 次
- 通知风暴 → 防范:同类合并 + cooldown

- 自愈成功率 Sev3-4 ≥ 80%
- 通知延迟 Sev1 ≤ 5min
- 误报率 < 5%
