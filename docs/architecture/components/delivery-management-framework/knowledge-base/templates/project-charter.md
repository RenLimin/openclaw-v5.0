# 项目章程模板

## 模板用途
项目正式启动的授权文件，明确项目目标、范围、关键干系人和高层级约束，是项目存在的"身份证"和"尚方宝剑"。

## 填写说明
| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | ✅ | 简洁清晰，不超过 20 字 |
| 项目编号 | ✅ | 按公司编码规则填写 |
| 项目发起人 | ✅ | 对项目资源和结果最终负责的高管 |
| 项目经理 | ✅ | 被授权管理项目的人 |
| 立项日期 | ✅ | 项目正式启动日期 |
| 计划完成日期 | ✅ | 预期交付日期（可包含缓冲） |
| 项目预算 | ✅ | 高层级预算范围 |
| 项目目标 | ✅ | SMART 原则，3-5 条核心目标 |
| 项目范围 | ✅ | 包含什么 / 不包含什么（In Scope / Out of Scope） |
| 关键干系人 | ✅ | 主要相关方及角色 |
| 成功标准 | ✅ | 怎么算项目成功，可量化 |
| 主要风险 | ⬜ | 高层级风险，1-3 条即可 |
| 批准签字 | ✅ | 发起人和项目经理签字 |

## 注意事项
1. 项目章程不是详细计划，是高层级的授权和共识文件，1-2 页即可
2. 范围部分一定要写 Out of Scope，明确边界比明确包含什么更重要
3. 成功标准必须可衡量，避免"提升用户体验"这种无法验证的表述
4. 项目章程获批后，任何重大变更需要走变更流程，不能随意修改
5. 项目经理在章程签署后才正式获得授权，之前的工作算预研或筹备
