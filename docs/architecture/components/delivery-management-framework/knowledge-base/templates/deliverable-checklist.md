# 交付物检查单模板

## 模板用途
在交付物提交/验收前，逐项检查是否满足质量标准和完成条件，确保交付的东西"拿得出手"，减少返工和来回扯皮。

## 填写说明
| 字段 | 必填 | 说明 |
|------|------|------|
| 交付物名称 | ✅ | 本次要交付的东西 |
| 检查项 | ✅ | 需要检查的具体条目 |
| 检查标准 | ✅ | 满足什么条件算通过 |
| 检查结果 | ✅ | ✅ 通过 / ❌ 不通过 / ⬜ 不适用 |
| 备注 | ⬜ | 不通过的原因、证据链接等 |
| 检查人 | ✅ | 谁做的检查 |
| 检查日期 | ✅ | 什么时候检查的 |

## 注意事项
1. **检查项要可操作**：每个检查项必须能明确判断"通过"或"不通过"，不能有歧义
2. **按交付物类型裁剪**：不同类型的交付物（代码、文档、设计稿等）检查项不同，按需裁剪
3. **不通过要有明确原因**：打 ❌ 的项必须写备注，说明哪里不满足、怎么改
4. **检查人不能是提交人自己**：交叉检查或 QA 检查，避免自审自批
5. **检查单本身就是交付物的一部分**：检查完成后归档，作为质量证据
6. **定期回顾检查项**：项目过程中发现的新问题，要补充到检查单里，持续完善
7. **"有条件通过"要谨慎使用**：只能用于影响较小且有明确整改计划的问题，高风险项必须整改完才能通过
