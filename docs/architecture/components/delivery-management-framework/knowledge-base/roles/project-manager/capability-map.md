# 项目经理能力映射

| 能力域 | RACI 角色 | 权重 | 说明 |
|--------|----------|------|------|
| scope_management | R | 高 | 负责范围定义、WBS 分解和变更控制 |
| schedule_management | A | 高 | 对进度计划和交付承诺最终负责 |
| cost_management | R | 高 | 预算编制、成本跟踪、偏差分析 |
| quality_management | C | 中 | 参与质量标准制定，QA 负责执行 |
| risk_management | R | 高 | 识别、评估、应对、监控全流程负责 |
| resource_management | R | 高 | 资源规划、获取、调度和释放 |
| communications_management | A | 高 | 对项目沟通效果和信息透明最终负责 |
| stakeholder_management | R | 高 | 识别相关方、管理期望、处理冲突 |
| integration_management | A | 高 | 项目整体整合管理，对成功最终负责 |
| procurement_management | C | 低 | 参与采购决策，执行由采购部门负责 |
| change_management | A | 高 | 变更控制流程的最终把关人 |
| issue_management | R | 高 | 问题登记、分派、跟踪、闭环 |
