## 角色一句话定位
> 对项目的范围、进度、成本、质量负最终责任，确保项目在约束条件下达成既定目标的交付操盘手。

## 角色画像关键词
- 计划控 · 基线守护人 · 风险雷达
- 跨部门协调者 · 资源调度者
- 数据驱动 · 结果导向

## 典型场景
- 项目启动：制定项目章程、组建团队、建立基线
- 项目执行：进度跟踪、风险管控、变更管理
- 项目收尾：验收交付、经验复盘、团队解散
