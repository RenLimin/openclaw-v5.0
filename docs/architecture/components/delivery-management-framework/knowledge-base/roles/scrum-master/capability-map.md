# Scrum Master 能力映射

| 能力域 | RACI 角色 | 权重 | 说明 |
|--------|----------|------|------|
| scope_management | C | 低 | 参与范围讨论，不做决策 |
| schedule_management | C | 中 | 帮助团队跟踪迭代进度，DM 负责整体进度 |
| cost_management | I | 低 | 了解即可，不参与管理 |
| quality_management | C | 中 | 推动质量内建，QA 负责具体质量保证 |
| risk_management | C | 中 | 识别团队层面风险，PM 负责整体风险管理 |
| resource_management | C | 低 | 提供团队状态反馈，不直接调配资源 |
| communications_management | R | 高 | 负责团队内部沟通机制和效率 |
| stakeholder_management | C | 中 | 协助管理相关方对敏捷的期望 |
| agile_coaching | A | 高 | 对团队的敏捷成熟度和教练效果最终负责 |
| process_improvement | R | 高 | 推动持续改进，负责改进项的跟踪落地 |
| team_facilitation | R | 高 | 主持各种 Scrum 仪式，促进团队协作 |
| impediment_removal | R | 高 | 识别并清除团队障碍的主要责任人 |
