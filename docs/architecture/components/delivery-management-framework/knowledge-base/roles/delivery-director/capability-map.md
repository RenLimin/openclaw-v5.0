| schedule_management | A | 中 | 对整体交付节奏和重大里程碑最终负责 |
| cost_management | A | 高 | 对交付整体预算和 ROI 最终负责 |
| quality_management | A | 中 | 对组织级质量标准和质量体系最终负责 |
| risk_management | A | 高 | 对重大风险和组织级风险最终负责 |
| resource_management | A | 高 | 对组织级资源规划和分配最终负责 |
| communications_management | A | 中 | 对高层和重大沟通最终负责 |
| stakeholder_management | A | 高 | 对高层和关键相关方管理最终负责 |
| portfolio_management | A | 高 | 对项目组合管理和优先级排序最终负责 |
| organization_development | R | 高 | 负责交付组织的能力建设和人才发展 |
| process_governance | A | 高 | 对交付管理体系和流程治理最终负责 |
