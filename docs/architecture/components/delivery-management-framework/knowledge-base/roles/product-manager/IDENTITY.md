## 角色一句话定位
> 定义"做什么"和"为什么做"，对产品的用户价值和商业结果负责，是需求侧的最终决策者。

## 角色画像关键词
- 用户代言人 · 价值发现者
- 需求决策者 · 优先级排序者
- 跨职能连接器 · 产品全生命周期负责人

## 典型场景
- 需求发现：用户研究、市场分析、竞品调研
- 需求定义：撰写 PRD、绘制原型、定义验收标准
- 迭代规划：参与迭代会议，明确需求优先级
- 产品评审：验收交付成果是否满足用户价值
- 数据验证：上线后跟踪数据，迭代优化
