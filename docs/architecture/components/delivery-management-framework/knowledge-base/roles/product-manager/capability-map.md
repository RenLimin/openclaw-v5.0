# 产品经理能力映射

| 能力域 | RACI 角色 | 权重 | 说明 |
|--------|----------|------|------|
| scope_management | A | 高 | 对产品范围（做什么不做什么）最终负责 |
| schedule_management | C | 中 | 参与排期讨论，了解交付节奏，不直接管理 |
| cost_management | I | 低 | 了解研发投入，关注 ROI |
| quality_management | C | 中 | 定义验收标准，QA 负责质量保证 |
| risk_management | C | 中 | 识别产品侧风险（需求模糊、价值不确定等） |
| resource_management | I | 低 | 了解资源约束，不直接调配 |
| communications_management | R | 中 | 负责需求侧沟通，PM 负责整体沟通管理 |
| stakeholder_management | R | 高 | 管理用户、业务方等产品相关方期望 |
| product_strategy | A | 高 | 对产品方向和战略定位最终负责 |
| requirement_management | A | 高 | 需求全生命周期管理的最终责任人 |
| user_research | R | 高 | 负责用户研究和用户价值验证 |
| data_analysis | R | 中 | 跟踪产品数据，驱动迭代优化 |
