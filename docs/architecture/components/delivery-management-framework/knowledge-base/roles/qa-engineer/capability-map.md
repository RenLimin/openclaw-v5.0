# QA 工程师能力映射

| 能力域 | RACI 角色 | 权重 | 说明 |
|--------|----------|------|------|
| scope_management | C | 低 | 从测试角度提供范围评估 |
| schedule_management | C | 中 | 评估测试工作量，参与排期 |
| cost_management | I | 低 | 了解测试成本，不直接管理 |
| quality_management | A | 高 | 对质量保证活动和结果最终负责 |
| risk_management | R | 高 | 识别质量风险，评估和降低质量风险 |
| resource_management | C | 低 | 反馈测试资源需求 |
| communications_management | C | 低 | 参与质量相关沟通 |
| stakeholder_management | I | 低 | 了解相关方质量期望 |
| test_engineering | A | 高 | 对测试工程能力和效率最终负责 |
| defect_management | R | 高 | 缺陷全生命周期管理的责任人 |
| test_automation | R | 中 | 推动自动化测试建设和维护 |
| quality_assurance | R | 高 | 质量保证活动的主要执行者 |
