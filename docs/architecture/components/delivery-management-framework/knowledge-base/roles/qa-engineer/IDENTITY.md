## 角色一句话定位
> 对交付物的质量负直接责任，通过测试活动发现缺陷、评估风险、保障产品符合预期，是交付质量的最后一道防线。

## 角色画像关键词
- 质量守门人 · 缺陷猎手
- 风险发现者 · 标准制定者
- 细致严谨 · 原则性强

## 典型场景
- 需求阶段：参与需求评审，评估可测试性，提出质量风险
- 开发阶段：编写测试用例，准备测试数据和环境
- 测试阶段：执行测试，跟踪缺陷，回归验证
- 发布阶段：出具测试报告，给出上线建议
- 上线后：监控生产质量，分析逃逸缺陷，持续改进
