# 交付经理能力映射

| 能力域 | RACI 角色 | 权重 | 说明 |
|--------|----------|------|------|
| scope_management | C | 中 | 参与范围拆解，执行层面的范围控制 |
| schedule_management | R | 高 | 负责进度计划的落地执行和日常跟踪 |
| cost_management | I | 低 | 了解预算情况，不直接管理 |
| quality_management | R | 中 | 确保交付物满足质量标准，配合 QA |
| risk_management | R | 中 | 识别执行层面风险，及时上报和应对 |
| resource_management | R | 高 | 负责日常资源调度和任务分配 |
| communications_management | R | 高 | 团队内和跨团队日常沟通的主要责任人 |
| stakeholder_management | C | 中 | 参与相关方沟通，PM 负责整体策略 |
| integration_management | C | 中 | 协助 PM 进行交付整合 |
| change_management | C | 中 | 执行变更，评估对交付的影响 |
| issue_management | R | 高 | 日常问题的发现、跟踪、解决主力 |
| delivery_execution | A | 高 | 对交付执行的效率和结果最终负责 |
