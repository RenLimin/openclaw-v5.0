# 项目管理裁剪指南

## 概述
**裁剪（Tailoring）** = 根据项目的具体上下文，选择适合的方法论、过程、工具和角色，而不是照搬全套模板。

**核心原则**：
- 没有"最佳实践"，只有"最合适"
- 裁剪不是降低标准，是精准匹配
- 裁剪决策要有依据，要记录，要复盘

## 裁剪维度

### 1. 生命周期维度
| 方法 | 适用场景 | DMS 状态机路径 |
|------|---------|---------------|
| **瀑布式** | 需求稳定、技术成熟、合规要求高 | planning → in_progress → review → completed |
| **迭代式** | 需求逐步清晰、需要反馈 | planning → in_progress → review → in_progress (循环) |
| **增量式** | 分模块交付、早期价值 | planning → in_progress → completed (多子项目并行) |
| **敏捷式** | 需求不确定、技术探索性强 | 短周期 sprint + 增量交付 |
| **混合式** | 部分需求稳定，部分不确定 | 核心功能瀑布 + 外围功能敏捷 |

### 2. 规模维度
| 规模 | 特征 | 裁剪建议 |
|------|------|---------|
| 小型（<3人，<1月） | 简单交付 | 简化流程、减少文档、扁平沟通 |
| 中型（3-10人，1-6月） | 标准项目 | 标准流程 + 按需裁剪 |
| 大型（>10人，>6月） | 多团队协作 | 完整流程 + 治理结构 + PMO |

### 3. 行业维度
| 行业 | 特殊要求 | 裁剪重点 |
|------|---------|---------|
| 金融/医疗 | 合规审计 | 文档完备、变更留痕、质量门禁 |
| 互联网/软件 | 快速迭代 | 敏捷实践、DevOps、快速反馈 |
| 建筑/工程 | 严格基线 | 瀑布流程、变更控制、EVM |
| 咨询/服务 | 人力密集 | 资源管理、SLA 管理、客户关系 |

### 4. 团队维度
| 因素 | 影响 | 裁剪策略 |
|------|------|---------|
| 地理分布 | 沟通成本增加 | 增加同步机制、文档优先 |
| 成熟度 | 新手 vs 专家 | 新手多 → 更规范的流程 |
| 跨职能 | 沟通复杂度高 | 强化 RACI、明确交付物 |

## 裁剪决策流程

```
1. 评估项目特征
   ├─ 需求确定性？
   ├─ 技术成熟度？
   ├─ 规模/复杂度？
   └─ 干系人期望？
      ↓
2. 选择生命周期模型
   ├─ 瀑布 / 迭代 / 增量 / 敏捷 / 混合
   └─ 定义阶段和关口
      ↓
3. 裁剪过程集
   ├─ 从标准过程库中选择
   ├─ 合并/简化非关键过程
   └─ 增加行业特殊过程
      ↓
4. 裁剪角色
   ├─ RACI 分配
   ├─ 兼职 vs 全职
   └─ 决策权限
      ↓
5. 裁剪文档
   ├─ 必需文档（合规/基线）
   ├─ 按需文档（沟通/协调）
   └─ 简化文档（小项目）
      ↓
6. 裁剪工具
   ├─ 项目管理工具
   ├─ 协作工具
   └─ 度量工具
      ↓
7. 记录裁剪决策（裁剪说明）
```

## 常见裁剪错误
1. **一刀切**：所有项目用同一套流程
2. **过度裁剪**：流程太轻导致失控
3. **裁剪不足**：流程太重导致效率低
4. **只裁不加**：只考虑简化，不考虑行业特殊需求
5. **不复盘**：裁剪后不评估效果，下次同样踩坑

## 与 DMS 框架的映射
DMS 框架的裁剪支持：
- **WorkflowScheme 引擎**：每个项目可以独立设置工作流方案
- **模块热插拔**：不需要的模块可以不注册
- **状态机可配置**：定义项目级别的状态流转路径
- **custom_fields**：为不同行业/项目类型扩展字段

### DMS 裁剪预置方案
| 方案 | 适用场景 | 模块组合 |
|------|---------|---------|
| 轻量交付 | 小项目、快速交付 | project + milestone + deliverable |
| 标准交付 | 中等复杂度项目 | 全部 5 模块 |
| 合规交付 | 审计/金融项目 | 标准 + contract_interface + sla_tracking |
| 敏捷交付 | 软件项目 | project + deliverable + raci + risk |
