# Bangcle 交付管理系统 BDMS Web UI 设计方案

## 设计目标

基于 Bangcle 官方 VI 规范（来自 WEB-001 Bangcle Web UI 设计系统），提供符合品牌规范的 BDMS Web UI，满足需求：
1. 工作台默认首页，展示核心数据卡片 + 图表 + 快捷操作 + 最近报表列表
2. 支持点击穿透，从卡片/表格可以跳转详情页查询明细
3. 统一端口 8787，后续迭代保持端口不变
4. 符合响应式设计，支持桌面/平板适配

## 色彩系统

严格遵循 WEB-001 Bangcle Web UI 设计规范：
- 主色：`#2D74BB` (梆梆蓝)
- 成功色：`#33ADA0` (青绿)
- 警告色：`#EFBA20` (金色)
- 错误色：`#DC3545` (红色)
- 页面背景：`#F0F2F5`
- 卡片背景：`#FFFFFF`
- 文字色：主 `#333333` / 二级 `#595757` / 三级 `#868686`
- 边框：`#E7E6E6`

## 页面设计

### 工作台（首页默认）

**布局从上到下**：
1. 面包屑导航 → 页面标题
2. **预警卡片** → 如果有待处理异常项目，显示提醒
3. **核心指标卡片行** → 四个核心指标（进行中项目/本月里程碑/本月确收金额/异常项目），点击可以穿透到对应列表页
4. **图表行** → 左：近6个月交付趋势线图 + 右：异常类型分布环形图
5. **快捷操作行** → 四个快捷操作卡片（生成交付月报/生成确收月报/新建项目/导入数据），点击直达对应功能页
6. **最近生成报表列表** → 表格展示最近生成的五个报表，点击直达详情页

## 交互规范

- 卡片悬停：上浮效果 + 主色边框
- 表格行悬停：浅蓝色背景
- 状态徽章：按状态配色（完成青绿/进行中蓝色/失败红色/警告金色）
- 点击穿透：所有数据卡片/表格行点击都可以跳转详情页查看

## 响应式适配

| 断点 | 策略 |
|---|---|
| ≥ 1200px (桌面大屏) | 侧边栏展开 + 4 列卡片 |
| ≥ 992px (桌面) | 侧边栏展开 + 3-4 列卡片 |
| ≥ 768px (平板) | 侧边栏可折叠（图标模式）+ 2 列卡片 |
| < 768px (手机) | 侧边栏全屏抽屉 + 单列卡片 |
