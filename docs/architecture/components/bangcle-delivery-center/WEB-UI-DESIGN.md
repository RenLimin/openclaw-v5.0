# BDMS Web UI 设计方案

> 组件 ID: BDMS-WEB-001 | 层级: L4 专有业务层 | 类型: Web UI 设计
> 统一端口: **8787**（后续迭代保持不变）
> 设计系统: WEB-001 Bangcle Web UI 设计系统 v1.0.0

## 1. 概述

### 1.1 产品定位

Bangcle 交付管理系统（BDMS）是梆梆安全内部交付管理平台，面向交付经理、项目经理、销售、管理层，提供：
- 交付进度可视化
- 月度交付报表自动生成与管理
- 确认收入报表自动生成与管理
- 项目交付全生命周期跟踪
- 数据统计与分析

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **品牌一致性** | 严格遵循 Bangcle VI 规范（WEB-001），与 PPT、官网、文档保持统一品牌感 |
| **专业高效** | 企业级管理系统风格，信息密度适中，操作高效，减少点击次数 |
| **数据驱动** | 以数据看板为核心，关键指标一目了然，支持下钻分析 |
| **响应式** | 适配 1920/1440/1366 等主流桌面分辨率，平板可用 |
| **可扩展** | 模块化设计，后续新增功能不破坏整体架构 |

### 1.3 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端框架 | FastAPI (≥0.104) | 高性能异步 Python Web 框架 |
| 模板引擎 | Jinja2 (≥3.1) | 服务端渲染，SEO 友好，首屏快 |
| 前端样式 | 原生 CSS + CSS 变量 | 基于 WEB-001 设计系统，不引入重型 UI 框架 |
| 前端交互 | 原生 JS + Fetch API | 轻量级，避免 React/Vue 等框架的构建复杂度 |
| 图表库 | ECharts 5 (CDN) | 数据可视化，丰富的图表类型 |
| 图标库 | @ant-design/icons (CDN) | 线性图标，与设计系统风格一致 |

### 1.4 统一端口与访问地址

| 项 | 值 | 说明 |
|----|----|------|
| **统一端口** | `8787` | 后续所有版本保持不变 |
| 本地访问 | `http://127.0.0.1:8787` | 开发/本地使用 |
| 内网访问 | `http://<服务器IP>:8787` | 内网部署使用 |
| 健康检查 | `http://127.0.0.1:8787/health` | 返回 JSON 状态 |
| API 前缀 | `/api/v1/` | 所有 REST API 统一前缀 |

> **为什么选 8787**：避开常用端口（8000/8080/3000/5173），好记且不易冲突；谐音「邦齐邦齐」，呼应 Bangcle 品牌。

## 4. 交互规范

### 4.1 加载状态

- 初始加载：骨架屏（Skeleton），与内容同构
- 操作加载：按钮 Loading 状态 + 禁用
- 数据刷新：顶部进度条（NProgress 风格，主色 `#2D74BB`）

### 4.2 表单交互

- 必填项：标签前红色 `*`
- 校验失败：输入框红色边框 + 下方红色提示文字
- 校验成功：输入框绿色边框（可选）
- 提交后：按钮 loading，成功后 Toast 提示 + 跳转/刷新

### 4.3 反馈提示

| 类型 | 形式 | 时长 |
|------|------|------|
| 操作成功 | 右上角 Toast 绿色 | 3 秒自动消失 |
| 操作失败 | 右上角 Toast 红色 | 5 秒自动消失 |
| 确认操作 | 居中 Modal 对话框 | 手动关闭 |
| 信息提示 | 页面内 Alert 提示 | 常驻，可手动关闭 |

### 4.4 表格交互

- 行悬停：浅蓝背景 `#E6F0FA30`
- 行选中：主色背景 `#E6F0FA` + 左侧 3px 主色竖条
- 列排序：点击表头切换升序/降序，箭头指示
- 固定列：左侧固定项目名列，右侧固定操作列
- 斑马纹：可选，奇数行白底偶数行浅灰底
- 分页：底部居中，显示总数 + 每页条数切换

## 6. 性能优化

| 优化项 | 方案 |
|--------|------|
| 首屏加载 | 服务端渲染，首屏直出 HTML |
| 静态资源 | CSS/JS 压缩 + 缓存（30 天） |
| 图标 | 使用 SVG Sprite 或字体图标，减少请求 |
| 图表 | ECharts 按需加载，只引入用到的图表类型 |
| 大表格 | 虚拟滚动（Virtual Scroll），万行数据不卡顿 |
| 图片 | WebP 格式 + 懒加载 |

## 7. 可访问性

- 文字对比度 ≥ 4.5:1（WCAG AA）
- 键盘导航：所有可交互元素可通过 Tab 键访问
- 语义化 HTML：正确使用 header/nav/main/article/section/footer
- ARIA 标签：图标按钮、状态徽章添加 aria-label
- 焦点样式：清晰可见的焦点轮廓（主色 2px）

## 8. 国际化（预留）

- 所有文案通过 i18n 函数输出，预留多语言能力
- 默认中文（zh-CN）
- 后续可扩展英文（en-US）
