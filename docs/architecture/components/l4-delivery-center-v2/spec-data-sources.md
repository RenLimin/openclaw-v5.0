## 三、主键与关联关系

各数据源之间通过以下字段关联：

```
ONES 履约项 (BI履约ID)  ──── 企微确收/验收 (BI履约ID)
       │
       │ 销售合同编号
       ↓
OA 合同台账 (合同编号！)
       │
       │ 合同编号
       ↓
工时填报 (合同编号)
```

| 关联键 | 左表 | 右表 | 基数 | 说明 |
|--------|------|------|------|------|
| BI履约ID | ONES 签约/POC/异常 | 企微确收/验收 | 1 : 0..N | 一个履约项可能有多个凭证（多次提交） |
| 销售合同编号 | ONES | OA 合同 | N : 1 | 多个履约项属于同一个合同 |
| 合同编号 | OA 合同 | 工时填报 | 1 : N | 一个合同有多个工时记录 |

## 四、数据清洗规则（初步）

1. **企微 CSV 空列过滤**：列名为 `Unnamed: N` 或全空的列全部丢弃
2. **日期字段统一**：所有日期字段统一解析为 `datetime.date`，格式 `YYYY-MM-DD`
3. **空值处理**：数值空值用 `None`/`NaN`，文本空值用空字符串
4. **合同编号校准**：去除末尾 `&` 及之后的内容（用于 JOIN），保留原始值用于展示
5. **金额单位统一**：签约金额统一为元（数值型）
6. **验收 CSV 第7列为空列**：直接跳过
7. **验收 CSV 第10列"深圳分公司-营销"**：疑似导出时数据错位，需要进一步确认列名含义后修正
