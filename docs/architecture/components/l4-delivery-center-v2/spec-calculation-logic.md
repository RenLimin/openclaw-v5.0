## 一、履约状态判定规则

### 1.1 9 种履约项统计状态（财报口径）

| 编号 | 状态名称 | 判断规则 |
|------|----------|----------|
| 1 | 正常交付 | 实施已完成 AND 交付邮件已归档 AND 未验收 AND 服务期未结束 → 正常交付 |
| 2 | 应交未交 | 实施进行中 AND 预估交付完成日期 < 报告截止日期 (2026-07-08) AND 未交付邮件 → 应交未交 |
| 3 | 交付异常 | 异常类型 == 履约项交付异常 → 交付异常 |
| 4 | 正常验收 | 验收文件已归档 AND 服务期未结束 → 正常验收 |
| 5 | 应验未验 | 交付邮件已归档 AND 预估验收完成日期 < 报告截止日期 AND 未验收文件 → 应验未验 |
| 6 | 验收异常 | 异常类型 == 履约项验收异常 → 验收异常 |
| 7 | 正常服务 | 验收文件已归档 AND 服务期未结束 AND 实际服务/授权结束日期 >= 报告截止日期 → 正常服务 |
| 8 | 应结未结 | 验收文件已归档 AND 实际服务/授权结束日期 < 报告截止日期 → 应结未结 |
| 9 | 已结项 | 验收文件已归档 AND 实际服务/授权结束日期 >= 报告截止日期 → 已结项（服务期已结束但未到结束日期） |

> ⚠️ 规则复用旧版资产 `status_engine.py` 中已验证实现，直接复用。

### 1.2 项目验收状态（财报口径）

分类规则：

| 状态分类 | 判断规则 |

## 二、考核计算规则

### 2.1 交付计划准确率

对于每个履约项：
```
差异 = 实际结项日期 - 基线-预估结项日期 （单位：自然日）
是否跨月 = 基线所在月份 != 实际所在月份
```

扣分规则：

| 条件 | 扣分 |
|------|------|
| 差异绝对值 < 15 天 且 不跨月 | 0 |
| 差异绝对值 >= 15 天 且 不跨月 | 0.5 |
| 跨月 | 1 |

### 2.2 按时交付率

和交付计划准确率**完全相同**，只是基于验收日期计算：
```
差异 = 实际验收完成日期 - 基线-预估验收完成日期 （单位：自然日）
是否跨月 = 基线所在月份 != 实际所在月份
```

扣分规则完全相同。

### 2.3 交付效率汇总

按 **项目经理 / 部门 / 中心** 三级汇总：
- 汇总 `交付计划准确率-考核扣分` 求和 → `交付计划准确性` 总分
- 汇总 `按时交付率-考核扣分` 求和 → `交付及时性` 总分
- 平均分 = 总分 / 项目数

> ⚠️ 规则复用旧版资产 `scoring_engine.py` 中已验证实现，直接复用。

## 五、异常台账计算规则

异常台账分三列块（合计、验收异常、交付异常），每个块结构相同：

对于每一年：
```
处理中 = 2025年之前存量 + 2025年新增 - 2025年已处理完毕
总计 = 所有行处理中求和
```

## 六、交接统计跨月比率规则

最终确认（已验证，沿用）：

- **明确回答"是"** → 计入跨月
- **其他情况**（明确"否"/空值/其他文本） → 全部计入不跨月
- 分母 = **总确收凭证数**（不是有效 CSV 行数），分子 = 跨月数
- 比率 = 分子 / 分母

> ✅ 这个口径已经验证，和手工报表对比误差 < 0.04%（四舍五入导致），完全一致。
