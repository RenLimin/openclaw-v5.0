- 筛选条件：状态 = (多项)，异常影响情况 = (多项)

### 3.8 交付效率统计（25 × 18）

三级汇总：

- 最细粒度：按项目经理汇总，每项目经理一行
- 第二级：按部门汇总，每部门一行
- 第三级：按中心汇总，每中心一行
- 每个汇总行：交付计划准确性（偏差率 / 平均偏差率）、交付及时性（偏差率 / 平均偏差率）
- 公式：`平均偏差率 = SUMIFS 偏差 / COUNTIFS 项数`
- 数据源：从签约 Sheet 取计算后的偏差和扣分。

### 3.9 交接统计（6 × 20）

三个独立 Pivot 并排：

#### 左侧：确收交接年月-合格率
- **行字段**：交接年月
- **列字段**：跨月交接 = 否 / 是 / 总计
- **值字段**：比率 = 计数 / 总计数

#### 中间：确收交接年月-跨月交接比率
- **行字段**：交接年月
- **列字段**：跨月交接 = 否 / 是 / 总计
- **值字段**：比率 = 计数 / 总计数

#### 右侧：验收交接年月-合格率
- **行字段**：交接年月
- **列字段**：跨月交接 = 否 / 是 / 总计
- **值字段**：比率 = 计数 / 总计数

**统计口径**（之前已修正，现在保留）：
- 跨月 = 明确回答"是" → 计入跨月
- 其他所有情况（"否"/空值） → 计入不跨月
- 比率 = 跨月计数 / 总确收凭证数

## 四、数据过滤与行数数差规则

### 4.1 过滤规则

所有明细 Sheet 统一按**报告月份的最后一天**截止过滤：

| Sheet | 过滤依据 | 过滤条件 | 说明 |
|-------|----------|----------|------|
| 签约 | 立项日期 | 立项日期 ≤ 报告月末 | 如 202606 = ≤ 2026-06-30 |
| POC&提前实施 | 立项日期 | 立项日期 ≤ 报告月末 | 同上 |
| 异常项目 | 异常报备日期 | 异常报备日期 ≤ 报告月末 | 异常项目无立项日期字段 |
| 确收交接 | 交接日期 | 交接日期 ≤ 报告月末 | 空日期行保留 |
| 验收交接 | 交接日期 | 交接日期 ≤ 报告月末 | 空日期行保留 |

### 4.2 行数差异说明

手工报表（`2026交付月报-20260630.xlsx`）的 ONES 原始数据导出日期为 **2026-07-08**，比报告月份（202606）晚了 8 天。因此：

- **签约、POC 行数会有少量差异**（一般几十到一百多行），属于 ONES 导出时点不同导致的数据快照差异。
- **异常项目**通常差异更小（1~3 条），也是时点差异。
- **确收/验收交接**差异来自企业微信导出时点不同。
- 这些差异**不是 bug**，是正常的数据快照差异，接受即可。

### 4.3 公式列实现方式

所有参考表里用 Excel 公式实现的列，生成器用 pandas 等价计算：

| Sheet | 公式列 | Excel 公式 | pandas 实现 |
|-------|--------|-----------|------------|
| 确收交接 | 项目经理所属区域 | `=VLOOKUP(J2,图例!A:B,2,FALSE)` | `df["项目经理"].map(pm_dept_map)`，找不到填 `#N/A` |
| 确收交接 | 跨月交接 | `=IF(ISERROR(FIND("是",P2)),"否","是")` | 含"是"→"是"，否则→"否" |
| 确收交接 | 是否合格 | `=IF(ISERROR(FIND("是",N2)),"否","是")` | 财务是否接收含"是"→"是"，否则→"否" |
| 验收交接 | 项目经理所属区域 | `=VLOOKUP(L2,图例!A:B,2,FALSE)` | 同上 |
| 验收交接 | 是否合格 | `=IF(ISERROR(FIND("是",S2)),"否","是")` | 是否接收含"是"→"是"，否则→"否" |
