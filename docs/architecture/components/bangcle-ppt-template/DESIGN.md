# Bangcle PPT 模板系统

> 组件 ID: CPT-012 | 层级: L4 专有业务层 | 类型: 设计系统

## 1. 概述

Bangcle PPT 模板系统是基于梆梆安全官方 VI 规范的 PPT 设计系统，从 `【PPT】2025梆梆安全模板（浅色系）.pptx`（19 页）和 `【PPT】2025梆梆安全模板（深色系）.pptx`（15 页）两套模板中提取并标准化。

- **浅色系模板**: 白底，适合正式汇报、对外宣讲
- **深色系模板**: 深蓝黑底（#00122B），适合发布会、产品展示
- **画布尺寸**: 13.33" × 7.50"（16:9，1280×720px @96dpi）
- **设计基调**: 科技蓝 + 稳重商务

- **字间距**: 默认（未设置特殊字距）

│  ┌───────────────────────────────┐  │
│  │  主标题区域                    │  │  ← 标题 + 英文副标题
│  │  （H1: 36pt + En-sub: 14pt）   │  │

│  │                               │  │
│  │     内容区域（核心）            │  │  ← 主视觉/数据/文字
│  │     （约 4.5" 高度）           │  │
│  │                               │  │
│  └───────────────────────────────┘  │
│  底部安全区: 0.3"                    │  ← 页码/页脚

### 4.2 栅格系统

- **左边界**: 0.54"（约 39pt）- 主标题左对齐基线

- **右边界**: 12.33" - 12.57"

- **典型卡片宽度**: 3.18"（三列）/ 3.78"（三列带阴影）/ 5.57"（两列）
- **卡片间距**: 约 0.6" - 0.8"

## 8. 使用指南

### 8.1 场景选择

| 场景 | 推荐色系 | 推荐页面组合 |
|------|---------|-------------|
| 内部汇报 / 周会 | 浅色 | 封面 → 目录 → 内容页 ×N → 结尾 |
| 对外宣讲 / 客户提案 | 浅色 + 深色过渡 | 浅色封面 → 目录 → 内容 → 深色章节页点缀 |
| 产品发布会 | 深色为主 | 深色封面 → 深色内容 → 数据页 → 结尾 |
| 技术方案 | 浅色为主 | 封面 → 目录 → 章节页 → 图文 → 架构图 → 数据 |
| 年终总结 | 浅色 + 时间轴 | 封面 → 目录 → 章节×4 → 数据 → 结尾 |

### 8.2 设计原则

1. **主色克制**: `#2D74BB` 只用于标题、重点和装饰，不要大面积填充
2. **留白优先**: 内容密度适中，保持科技感和呼吸感
3. **对齐严格**: 所有元素左对齐到 0.54" 基准线
4. **层级清晰**: 通过字号差（36→24→14）建立视觉层级
5. **配图一致**: 商务/科技风格，蓝色调优先

## 9. 与 L2 pptxgenjs-pro 的协同

```
┌─────────────────────────────────────────┐
│  L4: bangcle-ppt 技能（本组件）          │
│  - 设计规范（颜色/字体/布局）            │
│  - 页面类型模板代码                       │
│  - Bangcle VI 品牌约束                    │
├─────────────────────────────────────────┤
│  L2: pptxgenjs-pro（CPT-004）            │
│  - pptxgenjs 核心 API 封装               │
│  - 通用形状/文本/图表操作                │
│  - 模板文件加载与修改                    │
└─────────────────────────────────────────┘
```

**调用关系**:
- L4 bangcle-ppt → 调用 L2 pptxgenjs-pro 提供的底层 API
- L4 提供预设的页面类型和样式变量，L2 负责实际渲染
- 数据输入（标题、正文、图片路径）→ L4 模板组装 → L2 生成 PPTX 文件

**实现方式**:
- 颜色/字体通过 pptxgenjs 的 `defineLayout` 或直接在 shape 配置中指定
- 复杂布局通过多 shape 组合实现（与模板结构一致）
- Logo、装饰图等静态资产从模板文件中提取为独立 PNG
