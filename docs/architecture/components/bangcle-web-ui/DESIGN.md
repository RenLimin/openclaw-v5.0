# Bangcle Web UI 设计系统

> 组件 ID: WEB-001 | 层级: L4 专有业务层 | 类型: 设计系统

## 1. 概述

Bangcle Web UI 设计系统是基于梆梆安全官方 VI 规范（从 PPT 模板提取）适配到 Web 界面的设计系统，为 L4 层 Bangcle 交付管理系统提供统一的品牌视觉规范。

- **设计基调**: 科技蓝 + 稳重商务
- **定位**: 企业内部管理系统，稳定可靠、专业高效
- **基于**: 官方 PPT 模板 VI 规范 → 适配 Web 响应式布局

## 3. 字体系统

### 3.1 字体家族（Web 适配）

| 层级 | 优先字体 |  fallback |
|------|----------|----------|
| 所有文字 | 思源黑体 (Source Han Sans CN) | -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif |

> 为什么使用思源黑体：PPT 模板中所有文字均使用思源黑体，保持品牌一致性；思源黑体免费商用，覆盖全中文，屏幕显示清晰。

### 3.2 字重

| 层级 | 字重（CSS 数值） | 对应 PPT 字重 |
|------|----------------|---------------|
| 大标题/主标题 | 700 (Bold) | Heavy (900) |

| 小标题/卡片标题 | 500 (Medium) | Medium (500) |
| 正文 | 400 (Normal) | Medium (500) → Web 正文 400 更清晰 |
| 辅助说明/小字 | 400 (Normal) | Medium (500) |

### 3.4 行高与间距

- **正文行高**: 1.5 - 1.6 倍（Web 比 PPT 稍高，提升可读性）
- **标题行高**: 1.2 - 1.3 倍
- **标题与内容间距**: 0.5rem (8px) ~ 1rem (16px)，根据标题层级调整
- **段落间距**: 段前 0.5rem，段后 0.5rem
- **字间距**: 默认（0）

### 4.2 栅格系统

- 基于 Bootstrap 12 栅格系统适配
- 容器最大宽度: 1200px (桌面端)
- 间距:
  - 列间距 (gutter): 16px
  - 容器左右边距: 16px
- 断点:
  - xl: ≥ 1200px (桌面大屏)
  - lg: ≥ 992px (桌面)
  - md: ≥ 768px (平板)
  - sm: ≥ 576px (手机横屏)
  - xs: < 576px (手机竖屏)
- 响应式适配:
  - ≥ lg (992px): 侧边栏展开 + 内容区满宽
  - < lg: 侧边栏收起（可点击展开）+ 内容区满宽
  - < md: 侧边栏全屏遮罩展开

### 4.3 卡片布局规范

## 9. 设计原则

1. **主色克制**: `#2D74BB` 只用于标题、重点元素、主按钮、边框，不要大面积填充背景
2. **留白优先**: 内容密度适中，保持科技感和呼吸感，不要挤在一起
3. **层级清晰**: 通过字号、颜色、间距建立清晰视觉层级
4. **品牌一致**: 所有视觉元素遵循 VI 规范，保持与公司官网、PPT、文档一致的品牌感
5. **响应优先**: 适配桌面 → 平板 → 手机不同尺寸，保证在各种设备上可用
6. **可访问性**: 文字对比度符合 WCAG AA 标准，浅色模式正文对比度 ≥ 4.5:1

## 10. 主题切换（可选）

- 默认浅色模式，支持切换深色模式
- 深色模式基于 `#00122B` 深藏青背景，所有颜色根据规范适配
- 主题色变量统一存储在 CSS 变量（`--color-*`）中，切换无需修改组件代码
